Continuation · checked fixture K01 — Classical KD temperature and mixed loss

Checked continuation mechanism and declared fixture; this is not certification of every inherited claim.

Train against both hard labels and teacher probabilities under an explicit weighting convention.

Prerequisites: Entropy, cross-entropy, KL, and support, Softmax Jacobian and the CE logit gradient

Notation and assumptions

Fixed teacher, softened student/teacher logits divided by positive T. Alpha here weights hard CE. Mask and mean over valid target tokens separately.

Derivation and mechanism

  1. Compute hard CE using untempered student logits.
  2. Compute forward KL from softened teacher to softened student.
  3. Multiply soft KL by T² under this classical variant, then mix by alpha.
L=\alpha\mathrm{CE}_{hard}+(1-\alpha)T^2D_{KL}(p_T\Vert q_T)

Worked example

Equal teacher/student logits give zero soft KL at every T. Alpha1 recovers hard CE. Student logits[1,2], target1 gives ln(1+e^-1)≈.313262. T² belongs to this variant, not every distillation objective.

Limitations

  • Some sources reverse the alpha convention.
  • PyTorch KL inputs are log-probabilities; a default reduction may not be the intended token mean.

Connections to later concepts

  • F10 explains the hard CE gradient. K02 reverses the KL arguments and consequently changes both the sampling distribution and gradient.

Step 4.3 — Building the Complete Classical Knowledge-Distillation Loss

Plan node: I5 · chat order #35

We now have all the pieces:

\boxed{\text{hard labels}}
\boxed{\text{teacher soft targets}}
\boxed{\text{temperature }T}
\boxed{\text{KL divergence}}
\boxed{T^2\text{ correction}}

The next question is:

How do we combine all of these into one loss that actually trains the student?

The supplied chapter builds this progressively and gives the final classical KD objective as a combination of a hard-label cross-entropy term and a temperature-scaled soft-target KL term. (Source: Build a DeepSeek Model (From Scratch))

1. Why do we need two losses?

Suppose the teacher says:

P_T=[0.523,0.268,0.138,0.071].

This is rich information.

But suppose the teacher is wrong.

Then if we force the student to imitate the teacher blindly, the student can inherit the teacher's mistake.

So we want two sources of supervision:

Ground truth
\boxed{\text{What is actually correct}}
Teacher
\boxed{\text{How a strong model distributes its belief}}

Therefore:

\boxed{ \text{student learns correctness} + \text{student learns teacher structure} }

This is why the final classical distillation loss contains two components. The chapter calls the hard term the grounding signal and the soft term the dark-knowledge transfer signal. (Source: Build a DeepSeek Model (From Scratch))

2. Hard-label loss

Suppose the true class is:

y=0.

Student logits are:

z_S=[4.0,2.5,1.5,-0.5].

At ordinary temperature:

P_S=\operatorname{softmax}(z_S).

The chapter gives approximately:

\boxed{ P_S=[0.760,0.170,0.062,0.008] }

(Source: Build a DeepSeek Model (From Scratch))

Cross-entropy for the true class is:

\boxed{ L_{\text{hard}} = -\log P_S(y) }

Since:

P_S(0)\approx0.760,

we get:

L_{\text{hard}} = -\log(0.760) \approx \boxed{0.275}.

This is exactly the hard loss used in the chapter's worked example. (Source: Build a DeepSeek Model (From Scratch))

3. What does this term teach?

The hard loss says:

Put high probability on the actual correct answer.

If:

P_S(y)=0.99,

then:

-\log(0.99)\approx0.010.

Very good.

If:

P_S(y)=0.10,

then:

-\log(0.10)\approx2.303.

Bad.

Therefore:

\boxed{ L_{\text{hard}}\downarrow \Rightarrow P_S(\text{correct})\uparrow }

This is standard cross-entropy from ordinary supervised learning.

4. Soft-target loss

Now we use the teacher.

Teacher logits:

\boxed{ z_T=[5.0,3.0,1.0,-1.0] }

Student logits:

\boxed{ z_S=[4.0,2.5,1.5,-0.5] }

and:

T=3.

We divide both sets by 3.

Teacher:

z_T/T = [1.667,1.000,0.333,-0.333].

Student:

z_S/T = [1.333,0.833,0.500,-0.167].

5. Teacher soft targets

We already calculated:

\boxed{ P_T^T=[0.523,0.268,0.138,0.071] }

from Step 4.2. (Source: Build a DeepSeek Model (From Scratch))

6. Student soft targets

Apply softmax to:

[1.333,0.833,0.500,-0.167].

This gives approximately:

\boxed{ P_S^T=[0.442,0.268,0.192,0.099] }

which is the student's temperature-scaled distribution shown in the chapter. (Source: Build a DeepSeek Model (From Scratch))

Notice something interesting.

The student is already reasonably close to the teacher:

T:\quad[0.523,0.268,0.138,0.071]
S:\quad[0.442,0.268,0.192,0.099].

The largest disagreement is:

\text{cat: }0.523\text{ vs }0.442

and:

\text{fox: }0.138\text{ vs }0.192.

This is exactly the information the KL term will exploit.

7. KL divergence

We compare:

P_T^T

and:

P_S^T.

The KL divergence is:

\boxed{ D_{KL}(P_T^T\|P_S^T) = \sum_i P_T^T(i) \log \frac{P_T^T(i)} {P_S^T(i)} }

The chapter gives:

\boxed{ D_{KL}\approx0.0199 }

for this example. (Source: Build a DeepSeek Model (From Scratch))

8. Let's interpret the KL term

Suppose the teacher says:

[\text{cat}=0.523,\text{dog}=0.268,\text{fox}=0.138,\text{bird}=0.071].

The student says:

[\text{cat}=0.442,\text{dog}=0.268,\text{fox}=0.192,\text{bird}=0.099].

The student is wrong relative to the teacher in a distributional sense.

The KL penalty pushes:

0.442\rightarrow0.523

and:

0.192\rightarrow0.138

etc.

So the student's probability landscape begins to resemble the teacher's.

9. Apply the T^2 correction

We have:

T=3.

Therefore:

T^2=9.

Raw KL:

0.0199.

Multiply:

9(0.0199) = 0.1791.

Therefore:

\boxed{ L_{\text{soft}}\approx0.179 }

The chapter gives exactly this value. (Source: Build a DeepSeek Model (From Scratch))

10. Why does the hard loss use T=1?

This is an important detail.

The hard-label loss asks:

How well does the student predict the actual correct class?

Therefore the chapter computes:

\boxed{ L_{\text{hard}} = CE(z_S,y) }

using the student's ordinary logits:

T=1.

The soft-target loss, by contrast, uses:

\boxed{T>1}

because we intentionally want to soften the distributions.

The chapter explicitly specifies this separation. (Source: Build a DeepSeek Model (From Scratch))

11. Why not also temperature-scale the hard loss?

Because these are solving different objectives.

Hard loss
\boxed{ \text{“Be correct.”} }
Soft loss
\boxed{ \text{“Match the teacher's belief structure.”} }

The hard branch should retain ordinary supervised learning semantics.

The soft branch needs temperature to expose the dark knowledge.

12. Combine the two objectives

Now we need to decide how much to trust:

\text{ground truth}

versus:

\text{teacher}.

The chapter's implementation uses:

\boxed{ L= \alpha L_{\text{hard}} + (1-\alpha)T^2D_{KL}(P_T^T\|P_S^T) }

where:

0\le\alpha\le1.

(Source: Build a DeepSeek Model (From Scratch))

13. What does \alpha mean?

In this formula:

\boxed{\alpha=\text{hard-label weight}}

and therefore:

\boxed{1-\alpha=\text{soft-teacher weight}}.

For example:

\alpha=0.3.

Then:

1-\alpha=0.7.

So:

\boxed{ 30\%\text{ hard-label influence} + 70\%\text{ teacher-soft influence} }

The chapter describes this as a common example configuration. (Source: Build a DeepSeek Model (From Scratch))

14. Equivalent \alpha,\beta notation

You may also see:

\boxed{ L= \alpha L_{\text{hard}} + \beta T^2L_{\text{soft}} }

with:

\boxed{\alpha+\beta=1}

if normalized weights are used.

For the chapter's implementation:

\beta=1-\alpha.

So:

\alpha=0.3

means:

\beta=0.7.

This removes a common source of confusion.

15. Plug in the chapter's numbers

We have:

L_{\text{hard}}=0.275
L_{\text{soft}}=0.179
\alpha=0.3.

Then:

L = 0.3(0.275) + 0.7(0.179).

First term:

0.3(0.275) = 0.0825.

Second term:

0.7(0.179) = 0.1253.

Therefore:

L=0.0825+0.1253
\boxed{ L\approx0.208 }

which is the final value reported in the chapter. (Source: Build a DeepSeek Model (From Scratch))

16. IMPORTANT source note

The supplied chapter has an apparent textual inconsistency immediately after this calculation: it says the “soft loss” is 0.056 and the “hard loss” is 0.126, even though just before that it defines the raw hard loss as 0.275, the T^2-scaled soft loss as 0.179, and computes:

0.3(0.275)+0.7(0.179)\approx0.208.

Those displayed inputs themselves give 0.208, so I am using the formula and preceding numerical values rather than silently treating the later 0.056/0.126 sentence as a separate definition. (Source: Build a DeepSeek Model (From Scratch))

This is exactly the kind of source inconsistency worth recognizing rather than memorizing blindly.

17. What each term is doing

The total loss:

L= \underbrace{\alpha L_{\text{hard}}}_{\text{ground truth}} + \underbrace{(1-\alpha)T^2D_{KL}}_{\text{teacher}}

has two jobs.

First term
\alpha L_{\text{hard}}

says:

\boxed{ \text{“Do not forget what is actually correct.”} }
Second term
(1-\alpha)T^2D_{KL}

says:

\boxed{ \text{“Also behave like the knowledgeable teacher.”} }

That is the entire philosophy of classical distillation.

18. What happens if \alpha=1?

Then:

L = L_{\text{hard}}.

The teacher disappears from the objective.

Therefore:

\boxed{ \alpha=1 \Rightarrow \text{ordinary supervised training} }

No soft distillation.

19. What happens if \alpha=0?

Then:

L= T^2D_{KL}(P_T^T\|P_S^T).

So the student relies completely on the teacher's soft distribution.

Therefore:

\boxed{ \alpha=0 \Rightarrow \text{pure soft distillation} }

assuming the normalized weighting convention.

20. What happens if T=1?

Then:

T^2=1

and:

P_T^T=P_T, \qquad P_S^T=P_S.

You still have a teacher/student distribution-matching objective, but the teacher's distribution may be very peaked.

That brings us back to the weakness of Attempt #2:

\boxed{ T=1\Rightarrow\text{dark knowledge is weakly exposed} }

The chapter explicitly motivates using a larger T to reveal that information. (Source: Build a DeepSeek Model (From Scratch))

21. What if T is extremely large?

Then:

P_T^T\rightarrow \left[\frac1K,\ldots,\frac1K\right]

and:

P_S^T\rightarrow \left[\frac1K,\ldots,\frac1K\right].

So:

D_{KL}\rightarrow0.

Although we multiply by:

T^2,

the distributional information itself is being washed out.

Hence:

\boxed{ T\text{ must be chosen carefully} }

rather than simply made as large as possible.

22. Why T^2 and not T?

This is one of the most likely derivation questions.

Recall:

q_i^S = \operatorname{softmax}(z_i^S/T).

The derivative gets one 1/T from:

z/T.

At high T, the teacher and student probabilities also become closer to uniform, so:

q_i^S-p_i^T

shrinks by roughly another 1/T.

Therefore:

\boxed{ \text{gradient}\sim\frac1{T^2} }

and compensation uses:

\boxed{T^2}.

The chapter explicitly gives this derivation. (Source: Build a DeepSeek Model (From Scratch))

23. A simplified gradient derivation

For softmax cross-entropy-like matching, the student-logit gradient has the basic structure:

\frac{\partial L}{\partial z_i^S} \propto \frac1T (q_i^S-p_i^T).

For large T:

q_i^S-p_i^T \sim \frac1T.

Thus:

\frac{\partial L}{\partial z_i^S} \sim \frac1{T^2}.

Multiplication by T^2 gives:

T^2\frac{\partial L}{\partial z_i^S} \sim O(1).

This is the mathematical reason for the correction.

24. Full training pipeline

Now let's connect the mathematics to the actual training loop.

The supplied chapter's training process is:

Step 1 — input batch
(x,y)

enters.

Step 2 — teacher forward pass
t_{\text{logits}}=T(x)

with teacher frozen.

The implementation uses:

with torch.no_grad():
    t_logits = teacher(x)

because no teacher gradients are needed. (Source: Build a DeepSeek Model (From Scratch))

Step 3 — student forward pass
s_{\text{logits}}=S(x).

Student gradients are tracked.

Step 4 — hard loss
L_{\text{hard}} = CE(s_{\text{logits}},y).
Step 5 — temperature soft targets
P_T^T= \operatorname{softmax}(t_{\text{logits}}/T)
P_S^T= \operatorname{softmax}(s_{\text{logits}}/T).
Step 6 — KL
L_{KL} = D_{KL}(P_T^T\|P_S^T).
Step 7 — T^2
L_{\text{soft}} = T^2L_{KL}.
Step 8 — combine
\boxed{ L= \alpha L_{\text{hard}} + (1-\alpha)L_{\text{soft}} }
Step 9 — backpropagate
\nabla_{\theta_S}L.
Step 10 — optimizer update
\theta_S \leftarrow \theta_S-\eta\nabla_{\theta_S}L.

Teacher stays fixed.

The chapter lists essentially this exact sequence. (Source: Build a DeepSeek Model (From Scratch))

25. Why use log_softmax for the student in PyTorch?

The chapter's implementation is:

soft_teacher = F.softmax(
    teacher_logits / temperature,
    dim=-1
)

soft_student = F.log_softmax(
    student_logits / temperature,
    dim=-1
)

kl_loss = F.kl_div(
    soft_student,
    soft_teacher,
    reduction="batchmean"
)

(Source: Build a DeepSeek Model (From Scratch))

Why log probabilities?

Because the KL formula is:

D_{KL}(P_T\|P_S) = \sum_iP_T(i) \log\frac{P_T(i)}{P_S(i)}.

This requires:

\log P_S(i).

PyTorch's F.kl_div is designed to accept the student in log-probability form in this usage.

So the code corresponds directly to the mathematics.

26. Complete PyTorch implementation

Here is the complete classical KD loss in the source's style:

import torch
import torch.nn.functional as F

def distillation_loss(
    student_logits,
    teacher_logits,
    labels,
    temperature=3.0,
    alpha=0.3,
):
    # Teacher distribution at temperature T
    soft_teacher = F.softmax(
        teacher_logits / temperature,
        dim=-1
    )

    # Student log-probabilities at temperature T
    soft_student = F.log_softmax(
        student_logits / temperature,
        dim=-1
    )

    # Distribution-matching loss
    kl_loss = F.kl_div(
        soft_student,
        soft_teacher,
        reduction="batchmean"
    )

    # Ordinary hard-label cross-entropy
    hard_loss = F.cross_entropy(
        student_logits,
        labels
    )

    # Combined objective
    loss = (
        alpha * hard_loss
        + (1 - alpha)
        * (temperature ** 2)
        * kl_loss
    )

    return loss

This is directly based on the chapter's Listing 8.2. (Source: Build a DeepSeek Model (From Scratch))

27. Complete training loop

The corresponding architecture is:

def train_distill(
    teacher,
    student,
    loader,
    epochs=10,
    temperature=3.0,
    alpha=0.3,
    lr=1e-3,
):

    teacher.eval()

    optimizer = torch.optim.Adam(
        student.parameters(),
        lr=lr
    )

    for epoch in range(epochs):

        for x, y in loader:

            optimizer.zero_grad()

            # Teacher is frozen
            with torch.no_grad():
                teacher_logits = teacher(x)

            # Student is trainable
            student_logits = student(x)

            # Combined KD loss
            loss = distillation_loss(
                student_logits,
                teacher_logits,
                y,
                temperature=temperature,
                alpha=alpha
            )

            # Student gradients
            loss.backward()

            # Update student only
            optimizer.step()

This follows the source's training-loop structure. (Source: Build a DeepSeek Model (From Scratch))

32. Numerical exercise — zero KL

Suppose:

P_T=P_S.

Then:

D_{KL}(P_T\|P_S)=0.

Therefore:

\boxed{L_{\text{soft}}=0}.

Then the only remaining contribution is:

\boxed{ L=\alpha L_{\text{hard}} }

in the combined formula.

33. Numerical exercise — perfect hard prediction

Suppose the correct class receives:

P_S(y)=1.

Then:

L_{\text{hard}} = -\log1 = \boxed0.

But if the student distribution still differs from the teacher:

KL>0.

So the total loss does not necessarily become zero.

This demonstrates that the two branches really are independent objectives.

34. The deepest insight: teacher and ground truth are not redundant

You might ask:

“If the teacher knows the answer, why do we still need labels?”

Because the teacher may not be perfectly reliable.

The hard label provides:

\boxed{\text{objective correctness}}

while the teacher provides:

\boxed{\text{rich structure}}

The chapter explicitly describes the hard component as a safety net against blindly inheriting teacher errors or biases. (Source: Build a DeepSeek Model (From Scratch))

35. What happens when the teacher is uncertain?

This is where soft distillation is particularly interesting.

Suppose:

P_T=[0.40,0.35,0.20,0.05].

The teacher is unsure.

A hard-label student only receives:

[1,0,0,0].

But the soft-target student learns:

\boxed{ \text{class 1 is best, but class 2 is nearly as plausible} }

and:

\boxed{ \text{class 3 is also somewhat possible} }

This uncertainty structure is valuable information.

The chapter notes that the benefit of distillation is particularly strong on ambiguous examples where teacher probabilities reveal meaningful class relationships. (Source: Build a DeepSeek Model (From Scratch))

36. Why the student may outperform training from scratch

Suppose a student has limited capacity.

From hard labels alone, it must infer:

\text{which classes/tokens are related}

from many examples.

With a teacher, it receives those relationships directly.

Therefore:

\boxed{ \text{teacher supervision can make learning more sample-efficient} }

The chapter explains this as transferring relational information that would otherwise take many examples to discover. (Source: Build a DeepSeek Model (From Scratch))

37. But distillation cannot magically exceed the teacher

The student is approximating teacher behavior.

So broadly:

\boxed{ \text{distillation transfers existing teacher capability} }

rather than guaranteeing new capability beyond the teacher.

This becomes especially important when we later discuss DeepSeek-R1 Distill. The chapter explicitly makes this point: distillation is efficient transfer, while advancing beyond the teacher's frontier generally requires other training such as stronger models or RL. (Source: Build a DeepSeek Model (From Scratch))

38. Classical KD vs normal supervised learning

Normal training
\boxed{ L=CE(P_S,y) }

One supervision source.

Classical KD
\boxed{ L= \alpha CE(P_S,y) + (1-\alpha)T^2KL(P_T^T\|P_S^T) }

Two supervision sources.

That is the essential difference.

39. Classical KD vs DeepSeek-R1 Distill

This deserves repetition because it is central to the chapter.

Classical KD
\boxed{ \text{teacher logits} \rightarrow \text{temperature} \rightarrow \text{KL} \rightarrow \text{student} }
DeepSeek-R1 Distill
\boxed{ \text{teacher generates reasoning traces} \rightarrow \text{curate} \rightarrow \text{SFT student} }

The chapter explicitly calls this a fundamental difference in the two paradigms. (Source: Build a DeepSeek Model (From Scratch))

If:

\alpha\rightarrow1

then:

\boxed{ \text{hard labels dominate} }

If:

If:

T\uparrow

then:

\boxed{ \text{soft targets become flatter} }

44. Exam question: why not simply train on teacher's argmax token?

Because argmax gives:

\boxed{ \text{only the chosen answer} }

whereas soft targets give:

\boxed{ \text{the entire probability distribution} }

The latter contains the relative plausibility of alternatives.

That's the dark knowledge.

45. Master formula for the entire classical KD section

Everything can now be compressed into one equation:

\boxed{ L_{\text{KD}} = \alpha \underbrace{ CE(z_S,y) }_{\text{hard / correctness}} + (1-\alpha) T^2 \underbrace{ D_{KL} \left( \operatorname{softmax}(z_T/T) \middle\| \operatorname{softmax}(z_S/T) \right) }_{\text{soft / dark knowledge}} }

This is the formula you should be able to reconstruct from memory.
