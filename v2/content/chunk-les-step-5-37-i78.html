Compute content attention from a compact latent cache without rebuilding all full keys/values.

Prerequisites: KV cache MHA, GQA and MQA accounting, RoPE rotations and relative position, Transpose versus reshape

Notation and assumptions

One-head content-only fixture: Q:T×dh,C:S×dc,Uk:dc×dh,Uv:dc×dv. Positional contributions are excluded from this equality test.

Derivation and mechanism

  1. Expanded keys are CUk, so Q(CUk)^T=(QUk^T)C^T.
  2. After row softmax, expanded output A(CUv)=(AC)Uv.
  3. Add positional score contributions separately using the actual decoupled-RoPE contract.
Q(CU_K)^\top=(QU_K^\top)C^\top,\quad A(CU_V)=(AC)U_V

Worked example

Q=[[1,2],[3,4]],C=[[1,0],[0,1],[2,1]],Uk=[[1,2],[3,4]],Uv=[[2,0],[0,3]]. Both score paths yield[[5,11,21],[11,25,47]]. Both value paths match under independently computed attention weights.

Limitations

  • A position-dependent rotation between projections cannot generally be absorbed into one position-independent matrix.
  • Content-only equivalence does not verify the full MLA cache layout or a production kernel.

Connections to later concepts

  • T16 proves relative rotation identities; the positional path prevents naive position-independent absorption of the entire score computation.

Step 5.37 — MLA Mathematical Derivation and the Absorption Trick

Plan node: A1 · chat order #78

↩ Back to main text: Step 1.8 — Multi-Head Attention (MHA) · Step 1.13 — Stacking Transformer Blocks → Final Norm → Unembedding → Log

Now we do the part that is easy to memorize incorrectly but extremely important to understand:

\boxed{\text{Why does MLA actually allow us to cache only the compressed latent representation?}}

The answer is the absorption trick.

The source's central derivation is:

\boxed{ QK^\top \quad\longrightarrow\quad X(W_QW_{UK}^{\top})(XW_{D-KV})^\top }

The reason this works is simply the associativity of matrix multiplication. (Source: Build a DeepSeek Model (From Scratch))

5.37.1 Start from ordinary attention

We know standard attention begins with:

\boxed{ S=QK^\top }

followed by:

A=\operatorname{softmax}\left(\frac{S}{\sqrt{d_h}}\right)

and:

O=AV.

So the question is:

How can MLA change Q,K,V without changing the basic attention calculation?

The trick is to express K and V through a much smaller latent representation.

5.37.2 MLA's latent representation

Let the input representation be:

\boxed{ X\in\mathbb R^{T\times d} }

where:

  • T = number of tokens,
  • d = model hidden dimension.

The source uses the following conceptual projections:

\boxed{ Q=XW_Q }
\boxed{ c_{KV}=XW_{D-KV} }
\boxed{ K=c_{KV}W_{UK} }
\boxed{ V=c_{KV}W_{UV}. }

This is the pure MLA content path described in the book. (Source: Build a DeepSeek Model (From Scratch))

5.37.3 Why introduce c_{KV}?

Because:

\boxed{ d_{\text{latent}}\ll d_{\text{K/V representation}} }

in the intended design.

Instead of storing the full historical:

K,V,

we store:

\boxed{c_{KV}}.

So for a sequence of T tokens:

c_{KV}\in\mathbb R^{T\times d_{\text{latent}}}.

That becomes the cache.

5.37.4 The apparent problem

At first glance, we seem to have made inference more complicated.

We now have:

X \rightarrow c_{KV} \rightarrow K

instead of simply:

X\rightarrow K.

Why should this be faster?

Because the important question isn't:

\boxed{\text{How many matrix multiplications are there?}}

It is:

\boxed{\text{How much historical information must remain in memory?}}

The latent cache can be dramatically smaller.

5.37.5 Substitute Q and K into attention

Start with:

S=QK^\top.

Substitute:

Q=XW_Q

and:

K=c_{KV}W_{UK}.

Then:

S = (XW_Q)(c_{KV}W_{UK})^\top.

This is the point where the algebra begins.

5.37.6 Apply the transpose rule

We use:

\boxed{ (AB)^\top=B^\top A^\top }

Therefore:

(c_{KV}W_{UK})^\top = W_{UK}^\top c_{KV}^\top.

So:

S = XW_QW_{UK}^\top c_{KV}^\top.

This is the source's core expanded expression. (Source: Build a DeepSeek Model (From Scratch))

5.37.7 Now the magic appears

Look carefully:

\boxed{ S= X W_Q W_{UK}^{\top} c_{KV}^{\top} }

There are four factors.

Because matrix multiplication is associative:

ABC=(AB)C=A(BC).

We can regroup:

S= X \underbrace{(W_QW_{UK}^{\top})}_{\text{fixed}} c_{KV}^{\top}.

So:

\boxed{ S= XW_{QK}^{\text{abs}}c_{KV}^{\top} }

where, conceptually:

\boxed{ W_{QK}^{\text{abs}} = W_QW_{UK}^{\top}. }

This combined matrix can be precomputed because the model weights are fixed during inference. (Source: Build a DeepSeek Model (From Scratch))

5.37.8 What exactly has been “absorbed”?

The Key up-projection:

W_{UK}

has effectively been absorbed into the query path.

Instead of explicitly doing:

Q \rightarrow K \rightarrow QK^\top,

we can compute an absorbed query:

\boxed{ Q_{\text{abs}} = X(W_QW_{UK}^{\top}) }

and then:

\boxed{ S=Q_{\text{abs}}c_{KV}^{\top}. }

That is the absorption trick described in the source. (Source: Build a DeepSeek Model (From Scratch))

5.37.9 Why is this useful for caching?

Because the historical information now appears only through:

\boxed{ c_{KV}^{\top}. }

We no longer need the full historical:

\boxed{ K_{\text{history}} }

to calculate the content-based attention score.

We only need:

\boxed{ c_{KV,\text{history}}. }

Therefore:

\boxed{ \text{latent cache is sufficient} }

for this content-path score calculation.

This is precisely the source's conclusion. (Source: Build a DeepSeek Model (From Scratch))

5.37.10 This is the key sentence to understand

The historical Key information is not magically deleted.

It is represented implicitly through:

\boxed{ c_{KV} }

plus the learned projection:

\boxed{ W_{UK}. }

The algebra allows us to move W_{UK} to the query side, where it becomes a fixed matrix.

So:

\boxed{ \text{same mathematical score} }

can be computed with:

\boxed{ \text{much smaller historical state}. }

That is the essence of MLA.

5.37.11 Full shape derivation

Let's assign dimensions.

Let:

X\in\mathbb R^{T\times d}

and:

W_Q\in\mathbb R^{d\times d_h^{\text{total}}}.

Then:

Q=XW_Q \in \mathbb R^{T\times d_h^{\text{total}}}.

Now let:

W_{D-KV} \in \mathbb R^{d\times d_{\text{latent}}}.

Then:

c_{KV}=XW_{D-KV} \in \mathbb R^{T\times d_{\text{latent}}}.

Then:

W_{UK} \in \mathbb R^{d_{\text{latent}}\times d_h^{\text{total}}}.

Therefore:

K=c_{KV}W_{UK}

has:

(T\times d_{\text{latent}}) (d_{\text{latent}}\times d_h^{\text{total}})

giving:

\boxed{ K\in\mathbb R^{T\times d_h^{\text{total}}}. }

Exactly as required.

5.37.12 Check the absorbed matrix dimensions

We have:

W_Q\in\mathbb R^{d\times d_h}

and:

W_{UK}^\top \in \mathbb R^{d_h\times d_{\text{latent}}}.

Therefore:

\boxed{ W_QW_{UK}^\top \in \mathbb R^{d\times d_{\text{latent}}}. }

Then:

X (W_QW_{UK}^\top)

has:

(T\times d) (d\times d_{\text{latent}})

so:

\boxed{ Q_{\text{abs}} \in \mathbb R^{T\times d_{\text{latent}}}. }

Now:

Q_{\text{abs}}c_{KV}^\top

has:

(T\times d_{\text{latent}}) (d_{\text{latent}}\times T)

giving:

\boxed{ S\in\mathbb R^{T\times T}. }

Exactly the same attention-score shape as ordinary attention.

This is the tensor-shape heart of the trick.

5.37.13 Complete symbolic chain

The ordinary route is:

X \rightarrow Q
X \rightarrow K
QK^\top.

MLA route:

X \rightarrow c_{KV}

then:

X \rightarrow W_QW_{UK}^\top \rightarrow Q_{\text{abs}}

then:

\boxed{ S= Q_{\text{abs}}c_{KV}^\top. }

Thus:

\boxed{ K\text{ never needs to be stored in the historical cache}. }

5.37.14 Complete numerical example

Now let's actually calculate it.

Use a tiny example:

X= \begin{bmatrix} 1&2&0\\ 0&1&1 \end{bmatrix}

so:

X\in\mathbb R^{2\times3}.

Choose:

W_Q= \begin{bmatrix} 1&0\\ 0&1\\ 1&1 \end{bmatrix}

so:

W_Q\in\mathbb R^{3\times2}.

Choose:

W_{D-KV} = \begin{bmatrix} 1&0\\ 0&1\\ 1&-1 \end{bmatrix}

so:

W_{D-KV}\in\mathbb R^{3\times2}.

And:

W_{UK} = \begin{bmatrix} 1&2\\ 0&1 \end{bmatrix}

so:

W_{UK}\in\mathbb R^{2\times2}.

These are illustrative numbers, not values from the book.

5.37.15 Step A — Compute Q

Q=XW_Q.

First row:

[1,2,0] \begin{bmatrix} 1&0\\ 0&1\\ 1&1 \end{bmatrix} = [1,2].

Second row:

[0,1,1]W_Q = [1,2].

Therefore:

\boxed{ Q= \begin{bmatrix} 1&2\\ 1&2 \end{bmatrix}. }

5.37.16 Step B — Compute latent c_{KV}

c_{KV} = XW_{D-KV}.

First row:

[1,2,0] \begin{bmatrix} 1&0\\ 0&1\\ 1&-1 \end{bmatrix} = [1,2].

Second:

[0,1,1] \rightarrow [1,0].

So:

\boxed{ c_{KV} = \begin{bmatrix} 1&2\\ 1&0 \end{bmatrix}. }

This tiny matrix is what MLA would cache for this toy example.

5.37.17 Step C — Reconstruct K

K=c_{KV}W_{UK}.

So:

\begin{bmatrix} 1&2\\ 1&0 \end{bmatrix} \begin{bmatrix} 1&2\\ 0&1 \end{bmatrix} = \begin{bmatrix} 1&4\\ 1&2 \end{bmatrix}.

Thus:

\boxed{ K= \begin{bmatrix} 1&4\\ 1&2 \end{bmatrix}. }

5.37.18 Step D — Ordinary attention scores

Compute:

S=QK^\top.
K^\top = \begin{bmatrix} 1&1\\ 4&2 \end{bmatrix}.

Therefore:

S= \begin{bmatrix} 1&2\\ 1&2 \end{bmatrix} \begin{bmatrix} 1&1\\ 4&2 \end{bmatrix}

giving:

\boxed{ S= \begin{bmatrix} 9&5\\ 9&5 \end{bmatrix}. }

5.37.19 Now do it the MLA way

First compute:

W_QW_{UK}^\top.

Since:

W_{UK}^\top = \begin{bmatrix} 1&0\\ 2&1 \end{bmatrix},

we get:

W_QW_{UK}^\top = \begin{bmatrix} 1&0\\ 0&1\\ 1&1 \end{bmatrix} \begin{bmatrix} 1&0\\ 2&1 \end{bmatrix}.

Therefore:

\boxed{ W_QW_{UK}^\top = \begin{bmatrix} 1&0\\ 2&1\\ 3&1 \end{bmatrix}. }

5.37.20 Step E — Absorbed query

Now:

Q_{\text{abs}} = X(W_QW_{UK}^\top).

Therefore:

\begin{bmatrix} 1&2&0\\ 0&1&1 \end{bmatrix} \begin{bmatrix} 1&0\\ 2&1\\ 3&1 \end{bmatrix}

gives:

\boxed{ Q_{\text{abs}} = \begin{bmatrix} 5&2\\ 5&2 \end{bmatrix}. }

5.37.21 Step F — Multiply by latent cache

Now:

S_{\text{MLA}} = Q_{\text{abs}}c_{KV}^\top.

Since:

c_{KV}^\top = \begin{bmatrix} 1&1\\ 2&0 \end{bmatrix},

we get:

\begin{bmatrix} 5&2\\ 5&2 \end{bmatrix} \begin{bmatrix} 1&1\\ 2&0 \end{bmatrix}

which gives:

\boxed{ S_{\text{MLA}} = \begin{bmatrix} 9&5\\ 9&5 \end{bmatrix}. }

Compare:

S_{\text{ordinary}} = \begin{bmatrix} 9&5\\ 9&5 \end{bmatrix}

and:

S_{\text{MLA}} = \begin{bmatrix} 9&5\\ 9&5 \end{bmatrix}.

Therefore:

\boxed{ S_{\text{ordinary}}=S_{\text{MLA}}. }

This is the absorption trick demonstrated numerically.

5.37.22 Why this works

We did not approximate anything.

We simply used:

(AB)^\top=B^\top A^\top

and:

(ABC)=(AB)C=A(BC).

So the score is mathematically identical.

The compression comes from what must be retained across decoding steps, not from changing the underlying dot-product algebra. (Source: Build a DeepSeek Model (From Scratch))

5.37.23 Now the Value side

We have solved:

\boxed{ QK^\top }

but attention also requires:

\boxed{ O=AV. }

MLA defines:

V=c_{KV}W_{UV}.

So:

O = A(c_{KV}W_{UV}).

By associativity:

\boxed{ O=(Ac_{KV})W_{UV}. }

The source goes one step further by allowing the value projection to be absorbed into the final output projection. (Source: Build a DeepSeek Model (From Scratch))

5.37.24 Value-side absorption

Suppose the output projection is:

W_O.

Then the normal output is:

Y = A V W_O.

Substitute:

V=c_{KV}W_{UV}.

Then:

Y = A c_{KV}W_{UV}W_O.

Regroup:

\boxed{ Y = A c_{KV} (W_{UV}W_O). }

Since:

W_{UV}

and:

W_O

are fixed during inference, their product can also be precomputed.

Therefore the value-side path can work directly from:

\boxed{ c_{KV} }

rather than requiring us to persist the entire historical V matrix.

This is the source's second absorption step. (Source: Build a DeepSeek Model (From Scratch))

5.37.25 So MLA has two important algebraic savings

Score side
\boxed{ W_QW_{UK}^{\top} }

can be precomputed.

Value/output side
\boxed{ W_{UV}W_O }

can be precomputed.

Therefore the persistent historical state can remain centered on:

\boxed{ c_{KV}. }

This is the mathematical foundation of the latent cache.

5.37.26 Why the trick fails with standard RoPE

Now we arrive at the next problem.

RoPE applies a position-dependent rotation:

\boxed{ Q_r=\operatorname{RoPE}(Q,p_q) }
\boxed{ K_r=\operatorname{RoPE}(K,p_k). }

The key problem is that:

\boxed{ \operatorname{RoPE}(\cdot,p) }

depends on position p. (Source: Build a DeepSeek Model (From Scratch))

5.37.27 Recall what absorption needs

Absorption needs:

W_QW_{UK}^{\top}

to be a fixed matrix.

We want:

QK^\top = XW_QW_{UK}^{\top}c_{KV}^\top.

The reason this works is that:

W_Q

and:

W_{UK}

are position-independent.

5.37.28 Add RoPE naively

Suppose:

Q_r=R_{p_q}Q

and:

K_r=R_{p_k}K.

Then score becomes:

S = Q_rK_r^\top.

Substitute:

S= R_{p_q}Q (R_{p_k}K)^\top.

The key term now includes position-dependent rotations.

Schematically, the structure becomes:

\boxed{ R_{p_q} W_Q \cdots W_{UK}^{\top} R_{p_k}^{\top} }

rather than:

\boxed{ W_QW_{UK}^{\top} }.

The position-dependent operator is sitting between factors we want to combine.

The book calls this a barrier to absorption.

5.37.29 Why can't we precompute it?

Suppose token i is at position:

p_i=5.

Another token is at:

p_j=10.

Their RoPE transformations differ:

R_5\neq R_{10}.

Therefore there is no single fixed matrix:

W_QW_{UK}^{\top}

that captures all possible position-specific interactions in the same way.

So:

\boxed{ \text{position dependence destroys the fixed absorption factorization} }.

This is exactly the incompatibility identified by the source. (Source: Build a DeepSeek Model (From Scratch))

5.37.30 What happens if we simply rotate after decompression?

Then the model would need to reconstruct the full historical K vectors and rotate them according to their positions.

At every decoding step, that means revisiting the historical keys.

The source explicitly says this would undermine the inference benefit of MLA because the full rotated history would need to be recomputed. (Source: Build a DeepSeek Model (From Scratch))

So we have a conflict:

\boxed{ \text{MLA wants a compact position-agnostic cache} }

while:

\boxed{ \text{RoPE wants position-dependent key representations}. }

5.37.31 The DeepSeek solution

Instead of forcing:

\boxed{ \text{content} + \text{position} }

through one path, separate them.

The source's solution is:

\boxed{ \text{Content Path} }

plus:

\boxed{ \text{Position Path} }.

(Source: Build a DeepSeek Model (From Scratch))

5.37.32 Content Path

The content path uses pure MLA.

It produces:

\boxed{Q_c}
\boxed{K_c}
\boxed{V_c}.

The source gives:

Q_c=(XW_{DQ})W_{UQ}
K_c=(XW_{D-KV})W_{UK}
V_c=(XW_{D-KV})W_{UV}.

And crucially:

\boxed{\text{No RoPE}}

is applied on this path. (Source: Build a DeepSeek Model (From Scratch))

Therefore absorption remains possible.

5.37.33 Position Path

A separate path produces:

\boxed{Q_r}

and:

\boxed{K_r}

specifically for positional information.

RoPE is applied here.

So:

\boxed{ Q_r=\operatorname{RoPE}(Q_{r,\text{unrotated}}) }
\boxed{ K_r=\operatorname{RoPE}(K_{r,\text{unrotated}}) }.

The source explicitly says the position path does not depend on the c_{KV} latent cache. (Source: Build a DeepSeek Model (From Scratch))

5.37.34 Then combine the two scores

Content score:

\boxed{ S_c=Q_cK_c^\top }

or its absorbed equivalent.

Position score:

\boxed{ S_r=Q_rK_r^\top. }

Then:

\boxed{ S=S_c+S_r. }

This is the key architecture.

The source states that the final attention scores are the sum of the two paths. (Source: Build a DeepSeek Model (From Scratch))

5.37.35 Why is this elegant?

The two paths have different jobs.

Content path asks:
\boxed{\text{“What is this token?”}}
Position path asks:
\boxed{\text{“Where is this token relative to the other token?”}}

Then:

\boxed{ \text{semantic relevance} + \text{positional relevance} }

produces the final score.

This “what vs where” interpretation is the book's pedagogical framing of the two streams. (Source: Build a DeepSeek Model (From Scratch))

5.37.36 What gets cached now?

This is very important.

The final decoupled architecture stores two historical quantities:

\boxed{ c_{KV} }

for content,

and:

\boxed{ K_r }

for the rotated positional path.

The source therefore gives the cache-size term:

\boxed{ d_{\text{latent}}+d_{\text{rope}} }

instead of the MHA:

2nh

term. (Source: Build a DeepSeek Model (From Scratch))

5.37.37 Final decoupled cache formula

Under the book's 2-byte-value assumption:

\boxed{ M_{\text{MLA+RoPE}} = l\,b\,s\, (d_{\text{latent}}+d_{\text{rope}}) \times2 }

where the final 2 is bytes per 16-bit value.

Notice:

\boxed{ \text{there is no extra }2\text{ for separate K and V caches} }

because the cache contains:

\boxed{ \text{latent content state} + \text{rotated positional key state} }

rather than separate K and V matrices.

This is the source's architectural cache formula in simplified form. (Source: Build a DeepSeek Model (From Scratch))

5.37.38 Actual DeepSeek-scale numbers

The source uses:

n=128
h=128.

MHA cache-dimension factor:

2nh = 2(128)(128) = \boxed{32,768}.

For the decoupled MLA example:

d_{\text{latent}}=512

and:

d_{\text{rope}}=64.

Therefore:

d_{\text{latent}}+d_{\text{rope}} = 512+64 = \boxed{576}.

Ratio:

\frac{32768}{576} \approx \boxed{56.9}.

So the book rounds this to:

\boxed{\approx57\times}

cache reduction relative to MHA. (Source: Build a DeepSeek Model (From Scratch))

5.37.39 Numerical exam problem

Suppose:

n=64,\quad h=128.

Then MHA's K/V cache dimension factor:

2nh = 2(64)(128) = \boxed{16,384}.

Suppose MLA uses:

d_{\text{latent}}=512

and:

d_{\text{rope}}=64.

Then:

576.

Reduction:

\frac{16384}{576} \approx \boxed{28.44\times}.

This is an illustrative calculation.

5.37.40 One subtle point: 64× vs 57×

You may now see two numbers in your notes:

\boxed{64\times}

and:

\boxed{57\times}.

They are not contradictory.

Pure MLA simplified calculation
32768/512 = \boxed{64\times}.
MLA + decoupled RoPE
32768/(512+64) = 32768/576 \approx \boxed{57\times}.

The positional cache adds a small amount of extra state.

The source explicitly presents both calculations. (Source: Build a DeepSeek Model (From Scratch))

5.37.41 Why not cache Q?

During autoregressive decoding, the query belongs to the current token.

We only need the current query to compare against historical keys.

Historical queries are not needed in the same way.

Therefore the cache focuses on historical information needed for attention:

\boxed{ K/V\text{-side state} }

or, in MLA:

\boxed{ c_{KV}+K_r. }

This follows the standard causal-decoding structure and the source's cache descriptions.

5.37.42 Full inference loop with decoupled MLA

At a new token x_t:

Content path

Compute its latent:

c_{KV,t}=x_tW_{D-KV}.

Append:

c_{KV,t}

to the latent cache.

Compute absorbed content query.

Then:

S_c = Q_{c,\text{abs}}C_{KV}^{\top}.
Position path

Compute:

Q_{r,t}

and:

K_{r,t}.

Apply RoPE.

Append:

K_{r,t}

to the positional cache.

Then:

S_r=Q_{r,t}K_r^\top.
Combine
\boxed{ S=S_c+S_r }

then:

A=\operatorname{softmax} \left( \frac{S}{\sqrt{d_h}} \right)

and finally use the content Value path to produce the context.

This is the complete high-level flow described by the source's decoupled implementation. (Source: Build a DeepSeek Model (From Scratch))

5.37.43 Why the position path does not destroy MLA efficiency

Because the position path is deliberately small.

The source example uses:

d_{\text{rope}}=64

instead of:

nh=16,384.

So we retain only a compact positional representation.

Thus:

\boxed{ \text{small content cache} + \text{small positional cache} }

replaces:

\boxed{ \text{full K cache} + \text{full V cache}. }

That is the architectural trick.

5.37.45 The most important mathematical insight

The absorption trick is fundamentally:

\boxed{ (XW_Q) (c_{KV}W_{UK})^\top }
= \boxed{ XW_QW_{UK}^{\top}c_{KV}^{\top} }

because:

\boxed{ (AB)^\top=B^\top A^\top }

and:

\boxed{ ABC=(AB)C. }

Then:

\boxed{ W_QW_{UK}^{\top} }

is fixed during inference.

Therefore:

\boxed{ \text{historical state needed} = c_{KV}, }

not the full historical K.

That's the whole trick.

5.37.46 The most important architectural insight

RoPE then says:

\boxed{ \text{position must modify Q/K} }

and that breaks the fixed-factor assumption.

DeepSeek therefore says:

\boxed{ \text{Don't put position inside the compressed content path.} }

Instead:

\boxed{ \text{content path}+\text{position path}. }

Then:

\boxed{ S=S_c+S_r. }

That is decoupled RoPE. (Source: Build a DeepSeek Model (From Scratch))

5.37.47 Exam-style numerical: cache reduction

Given:
