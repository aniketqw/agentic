What is independently checked in this edition?

The complete original content is preserved and fingerprinted. All original and new TeX is parser-checked. New deterministic companions are run, including a finite-difference KL-gradient comparison, FP16 bit-pattern decoding, min-p edge cases, and group-reward normalization. Original derivations and programs are not all independently re-executed.

Browser layout/performance/accessibility/print testing is not certified by these static checks. The dated build report records the actual test scope. New qualifications flag source assumptions and the IndicQA count discrepancy without erasing the source.
