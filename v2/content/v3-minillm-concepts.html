Which distribution supplies the training examples?

Fix a teacher p and a student qθ for a prompt x. Classical soft-target KD compares token distributions on supplied prefixes. Sequence-level KD trains on complete teacher-generated targets. MiniLLM changes which distribution’s behavior is emphasized. Separating prefix sampling, target sampling, and per-token loss avoids treating all of these as identical implementations of one exact sequence objective.

\mathrm{KL}(p\|q)=\sum_y p(y)\log\frac{p(y)}{q(y)},\qquad \mathrm{KL}(q\|p)=\sum_y q(y)\log\frac{q(y)}{p(y)}

Forward KL takes its expectation under p; reverse KL takes its expectation under q. For an autoregressive sequence, p(y|x)=∏ₜp(yₜ|x,y<t), so log p(y|x)=Σₜlog p(yₜ|x,y<t). A teacher-forced token loss sees prefixes supplied by the dataset; a rollout objective also depends on which model generated those prefixes. This distinction is central to slides 11–12 and 19.

Individual contributions may be negative while the total KL is nonnegative. Swapping p and q changes both the weights and the log ratio. The reverse objective penalizes mass q assigns to regions where p is very small; the forward objective heavily penalizes q approaching zero where p has mass. If q=p is representable, both achieve zero there. “Mode-covering” and “mode-seeking” describe constrained approximations and optimization behavior, not a theorem that reverse KL must always discard a mode.

Understand the limitation of the one-bump illustration

Slide 14 constrains the student to one bump and illustrates two candidate distributions. The exact family of allowed bumps is not mathematically specified, so its printed “arg min” labels cannot be verified as global optima from the listed vectors alone. In particular, a zero q on positive teacher mass makes forward KL infinite. Keep the illustration as an intuition and reserve a numerical optimum claim for a fully specified family. Slide 18’s single-Gaussian fit to a separated Gaussian mixture supplies a more concrete version of that capacity restriction.

For the Gaussian case, minimizing forward KL over q=N(μ,σ²) is equivalent to minimizing cross-entropy E_p[(Y−μ)²/(2σ²)+log σ]+constant. Differentiating gives μ=E_p[Y] and σ²=Var_p[Y]. A separated target mixture therefore gives a wide fitted Gaussian between modes. Reverse KL uses E_q instead and can prefer one region; its result depends on separation, variance, and initialization. It is not guaranteed to choose a unique mode.

Bridge to RL, without skipping the needed mathematics

Slide 20’s difficulty is that the student samples the very sequences whose probabilities are being optimized. Backpropagating only through the teacher score of a discrete sampled token misses the derivative of the sampling distribution. The next optimization bridge uses the log-derivative identity after the RL foundations. Before that, retain this mental distinction: a fixed target sequence gives a supervised loss; a changing rollout distribution requires an expectation-aware gradient.

Complete executable companion: kl_gradient_examples.py · Python standard library
"""Exact finite-vocabulary reverse-KL gradient checked by finite differences."""
import math

def softmax(z):
    exp = [math.exp(v - max(z)) for v in z]
    return [v / sum(exp) for v in exp]

def kl(p, q):
    return sum(a * math.log(a / b) for a, b in zip(p, q) if a)

def reverse_kl_from_logits(z, teacher):
    return kl(softmax(z), teacher)

def gradient(z, teacher):
    q = softmax(z)
    ratios = [math.log(a / b) for a, b in zip(q, teacher)]
    average = sum(a * b for a, b in zip(q, ratios))
    return [a * (b - average) for a, b in zip(q, ratios)]

def main():
    p, q = [0.70, 0.25, 0.05], [0.40, 0.40, 0.20]
    z = [math.log(x) for x in q]
    g = gradient(z, p)
    finite = []
    epsilon = 1e-5
    for j in range(len(z)):
        plus, minus = z[:], z[:]
        plus[j] += epsilon
        minus[j] -= epsilon
        finite.append((reverse_kl_from_logits(plus, p) - reverse_kl_from_logits(minus, p)) / (2 * epsilon))
    assert max(abs(a-b) for a,b in zip(g, finite)) < 1e-8
    assert abs(sum(g)) < 1e-12
    assert math.isclose(kl(p, q), 0.2049154261873674, abs_tol=1e-9)
    assert math.isclose(kl(q, p), 0.2414140087481032, abs_tol=1e-9)
    updated = [v - 0.1*d for v,d in zip(z,g)]
    assert reverse_kl_from_logits(updated, p) < reverse_kl_from_logits(z, p)
    # Illustrative mixture/importance weights; no production rollout claim.
    mixture = [0.2*a + 0.8*b for a,b in zip(p,q)]
    weights = [b / m for b,m in zip(q,mixture)]
    assert math.isclose(sum(m*w for m,w in zip(mixture,weights)), 1)
    future_rewards = [-0.2, -0.6, -0.4]
    averages = [sum(future_rewards[t+1:])/len(future_rewards[t+1:])
                if future_rewards[t+1:] else 0.0 for t in range(3)]
    assert averages == [-0.5, -0.4, 0.0]
    print('KL[p||q]:', kl(p,q), 'KL[q||p]:', kl(q,p))
    print('analytic gradient:', g, 'finite differences:', finite)
    print('mixture:', mixture, 'importance weights:', weights)
    print('future-only average rewards:', averages)

if __name__ == '__main__':
    main()
