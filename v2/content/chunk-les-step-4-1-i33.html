Step 4.1 — Knowledge Distillation: Why, Teacher–Student Paradigm, Hard vs Soft Distillation

Plan node: I5 · chat order #33

We are now entering the Knowledge Distillation section.

The big question is:

How can a small model learn behavior that a much larger model has already learned, without having to rediscover everything from scratch?

The supplied Build a DeepSeek Model (From Scratch) chapter frames distillation as the final compression step after the reasoning model has been trained: a large teacher transfers useful behavior to a smaller student. It distinguishes hard distillation from soft distillation, and later connects this to the DeepSeek-R1 distilled models. (Source: Build a DeepSeek Model (From Scratch); Build a Reasoning Model (From Scratch))

1. First understand the deployment problem

Suppose we have a huge reasoning model.

In the chapter's DeepSeek example:

\boxed{671\text{ billion parameters}}

are in the full DeepSeek-R1 model.

Although the MoE model activates only a fraction of those parameters for a token, the full weights still need to be stored and accessible. The chapter gives approximately:

\boxed{1342\text{ GB}}

to store the 671B parameters in FP16. (Source: Build a DeepSeek Model (From Scratch))

That creates a problem.

A model can be:

\boxed{\text{very capable}}

but simultaneously:

\boxed{\text{very expensive to deploy}}.

We therefore want:

\boxed{ \text{large powerful teacher} \rightarrow \text{small capable student} }

2. What is knowledge distillation?

The chapter defines knowledge distillation as a model-compression technique in which a smaller student is trained to reproduce the behavior of a larger teacher, transferring its learned knowledge into a more compact model. (Source: Build a DeepSeek Model (From Scratch))

So we have:

Teacher
T

Large, capable, already trained.

Student
S

Smaller, cheaper, needs to learn.

The goal is not:

\boxed{S=T\text{ architecturally}}

The student can have a completely different and much smaller architecture.

Instead:

\boxed{ S(x)\approx T(x) }

in the behavior we care about.

3. Teacher is frozen

This is fundamental.

During distillation:

\boxed{\theta_T=\text{fixed}}

while:

\boxed{\theta_S=\text{trainable}}.

So the teacher is not learning from the student.

The direction is:

\boxed{ \text{teacher}\rightarrow\text{student} }

not:

\text{teacher}\leftrightarrow\text{student}.

The chapter explicitly describes the teacher as frozen. (Source: Build a DeepSeek Model (From Scratch))

4. Why not just train the student on the ordinary labels?

Suppose the correct class is:

\text{cat}.

A standard hard label is:

\boxed{ y=[1,0,0,0] }

for:

[\text{cat},\text{dog},\text{fox},\text{bird}].

What does the student learn?

Only:

Cat is the correct answer.

It does not directly receive information about:

  • whether dog is somewhat plausible,
  • whether fox is slightly plausible,
  • whether bird is almost impossible.

The teacher can provide that additional information.

5. Hard labels vs teacher probabilities

Imagine the teacher produces:

\boxed{ [0.86,\ 0.12,\ 0.015,\ 0.005] }

for:

[\text{cat},\text{dog},\text{fox},\text{bird}].

Now the student receives much richer information.

The teacher is effectively saying:

\text{cat} \gg \text{dog} > \text{fox} > \text{bird}.

The chapter calls the information contained in these relative probabilities dark knowledge. (Source: Build a DeepSeek Model (From Scratch))

6. Why is that useful?

Suppose two wrong classes are:

\text{dog}=0.12

and:

\text{bird}=0.005.

These probabilities communicate:

\boxed{ \text{dog is much closer to cat than bird is} }

according to what the teacher has learned.

A hard label throws that information away:

[1,0,0,0].

The teacher's output preserves the relational structure.

7. Think of the teacher as giving a richer answer

Hard label:

“The answer is cat.”

Soft teacher output:

“The answer is cat. Dog is somewhat plausible. Fox is much less plausible. Bird is almost impossible.”

So:

\boxed{ \text{hard label}=\text{answer} }

while:

\boxed{ \text{soft target}=\text{answer + relative alternatives} }

This is the central intuition behind classical distillation.

8. Hard distillation

The first approach is hard distillation.

The teacher generates an output sequence:

Y_T=(y_1,y_2,\ldots,y_m).

The student is trained to reproduce those tokens.

Mathematically, this is simply standard language-model cross-entropy:

\boxed{ L_{\text{hard}} = -\sum_t \log P_S(y_t\mid y_{<t},x) }

or averaged over tokens:

\boxed{ L_{\text{hard}} = -\frac1m \sum_t \log P_S(y_t\mid y_{<t},x) }

The student therefore sees:

\boxed{\text{teacher-generated text}}

as its supervision.

The chapter explicitly describes hard distillation as training on teacher-generated tokens and notes that this is essentially supervised fine-tuning on synthetic data. (Source: Build a Reasoning Model (From Scratch))

9. Example of hard distillation for an LLM

Prompt:

Solve 2x+4=10.

Teacher generates:

2x + 4 = 10
2x = 6
x = 3

Tokenized:

[t_1,t_2,t_3,\ldots,t_m].

Student training is just:

t_1\rightarrow t_2
t_1,t_2\rightarrow t_3

etc.

So the teacher's reasoning trace becomes a supervised training sequence.

10. Why hard distillation is attractive

You do not need access to:

\boxed{\text{teacher logits}}

You only need:

\boxed{\text{teacher-generated text}}.

Therefore the teacher can be used to create a dataset offline:

Teacher
   |
   | generate
   ▼
Synthetic dataset
   |
   ▼
Student SFT

The teacher can then be removed from the student-training process.

This becomes extremely important in the DeepSeek-R1 approach later.

11. Soft distillation

Now consider the more classical approach.

Instead of using only the teacher's selected token:

\boxed{y_t}

we use the teacher's complete probability distribution over the vocabulary.

Suppose the vocabulary has:

|V|=50,000.

At one position the teacher gives:

P_T(w_1),P_T(w_2),\ldots,P_T(w_{50,000}).

The student is trained to approximate this entire distribution.

So:

\boxed{ P_S(\cdot\mid x) \approx P_T(\cdot\mid x) }

12. Hard vs soft mathematically

Hard distillation

Student learns:

\boxed{ P_S(y_{\text{teacher}}) }

for the teacher-selected token.

Soft distillation

Student learns:

\boxed{ P_S(w)\approx P_T(w) \quad\forall w\in V }

The second contains much more information.

13. Why KL divergence appears

We need a mathematical way to compare:

P_T

and:

P_S.

The chapter uses:

\boxed{\text{KL divergence}}

for this purpose. (Source: Build a DeepSeek Model (From Scratch))

The teacher distribution is the reference:

P_T

and the student's goal is to make:

P_S

look like it.

The KL divergence is:

\boxed{ D_{KL}(P_T\|P_S) = \sum_i P_T(i) \log \frac{P_T(i)}{P_S(i)} }

and we minimize it with respect to the student's parameters.

14. Why direction matters

You may see:

D_{KL}(P_T\|P_S)

rather than:

D_{KL}(P_S\|P_T).

In the supplied chapter, the soft-target loss is explicitly described as:

\boxed{ KL(\text{teacher}\parallel\text{student}) }

and implemented using teacher probabilities and student log-probabilities. (Source: Build a DeepSeek Model (From Scratch))

That corresponds to the standard PyTorch-style computation:

soft_teacher = F.softmax(teacher_logits / T, dim=-1)
soft_student = F.log_softmax(student_logits / T, dim=-1)

kl_loss = F.kl_div(
    soft_student,
    soft_teacher,
    reduction="batchmean"
)

The important exam interpretation is:

\boxed{\text{teacher provides the target distribution}}

and:

\boxed{\text{student is adjusted to match it}}.

15. Tiny KL numerical example

Suppose:

P_T=[0.7,0.2,0.1]

and:

P_S=[0.6,0.3,0.1].

Then:

D_{KL}(P_T\|P_S) = 0.7\log\frac{0.7}{0.6} + 0.2\log\frac{0.2}{0.3} + 0.1\log\frac{0.1}{0.1}.

The final term is:

0.1\log1=0.

So:

D_{KL} \approx 0.7(0.1542)+0.2(-0.4055)
\approx0.108-0.081
\boxed{\approx0.027}.

The smaller the mismatch between teacher and student distributions, the smaller the KL divergence.

16. Why not simply use mean squared error on probabilities?

You could mathematically compare:

\sum_i(P_T(i)-P_S(i))^2.

But classical distillation uses KL divergence because we're comparing probability distributions, and KL gives a natural information-theoretic mismatch measure.

The supplied chapter specifically grounds soft distillation in KL divergence. (Source: Build a Reasoning Model (From Scratch))

17. Attempt #1: Ignore the teacher

The chapter builds its distillation loss progressively.

Attempt #1

Train the student exactly as a normal model:

\boxed{ L=L_{\text{hard}} }

with ground-truth labels.

This establishes the baseline.

The student learns, but must independently discover relationships that the teacher already knows. (Source: Build a DeepSeek Model (From Scratch))

18. Attempt #2: use teacher probabilities at T=1

A natural idea is:

L=D_{KL}(P_T\|P_S)

using ordinary softmax.

But there's a problem.

The teacher distribution may already be extremely peaked.

For the example from the chapter:

z=[5,3,1,-1].

At:

T=1

the teacher probabilities are approximately:

\boxed{ [0.865,\ 0.117,\ 0.016,\ 0.002] }

(Source: Build a DeepSeek Model (From Scratch))

Compare this with the hard target:

[1,0,0,0].

They're not identical, but they are quite similar in shape.

The probabilities:

0.016,\quad0.002

are tiny.

So much of the dark knowledge is still hidden.

The chapter calls this Attempt #2 and explains that the improvement over hard-label training is small. (Source: Build a DeepSeek Model (From Scratch))

19. Why are tiny probabilities a problem?

Suppose the teacher says:

P_T(\text{fox})=0.016.

That tells us fox is somewhat possible.

But the gradient signal associated with such a tiny value is much weaker than the dominant class signal.

Likewise:

P_T(\text{bird})=0.002

contains very little visible signal.

Thus the relative relationship:

\text{dog}>\text{fox}>\text{bird}

is technically present, but numerically compressed.

We need to soften the distribution.

That brings us to temperature.

20. A useful way to visualize the problem

At T=1:

cat  ████████████████████████████████████████ 86.5%
dog  █████                                11.7%
fox  █                                      1.6%
bird                                          0.2%

The teacher mostly says:

\boxed{\text{CAT}}

The relationships among the wrong classes are difficult for the student to exploit.

21. The student-teacher training flow

For classical soft distillation:

                     same input x
                    /             \
                   /               \
                  ▼                 ▼
           FROZEN TEACHER       STUDENT
                  |                 |
                  ▼                 ▼
            teacher logits     student logits
                  |                 |
               /T |              /T |
                ▼                  ▼
          teacher soft        student soft
          distribution        distribution
                  \                /
                   \              /
                    ▼            ▼
                       KL loss
                           +
                      hard CE loss
                           |
                           ▼
                       total loss
                           |
                           ▼
                    update STUDENT

Teacher:

\boxed{\text{no update}}

Student:

\boxed{\text{update}}

22. Hard distillation vs soft distillation

Property Hard distillation Soft distillation
Teacher output used generated tokens probability distribution
Teacher logits required? No Yes
Training objective standard CE KL divergence, often with hard CE
Information transferred selected answer/token sequence full distribution
Can reveal class/token relationships? limited yes
DeepSeek-R1 distilled models Yes Not the approach used

The last distinction is particularly important: the chapter explicitly says DeepSeek-R1's smaller distilled models use SFT on teacher-generated reasoning text, not classical soft-logit matching. (Source: Build a DeepSeek Model (From Scratch); Build a Reasoning Model (From Scratch))

23. Why DeepSeek's approach is different

Classical soft distillation:

\boxed{ \text{teacher logits} \rightarrow KL \rightarrow \text{student} }

DeepSeek-R1's distillation:

\boxed{ \text{teacher reasoning traces} \rightarrow \text{curated dataset} \rightarrow \text{student SFT} }

Therefore DeepSeek does not require simultaneous teacher/student forward passes during student training.

The chapter explicitly contrasts these two paradigms. (Source: Build a DeepSeek Model (From Scratch))

24. This gives us two very different data flows

Classical KD

For every training example:

x \rightarrow T(x)

and simultaneously:

x \rightarrow S(x).

Then compare them.

So:

\boxed{\text{teacher and student are active during training}}

The chapter highlights that this can be expensive because both models must be available. (Source: Build a DeepSeek Model (From Scratch))

DeepSeek hard distillation

First:

x \rightarrow T(x)

to create data.

Then:

D_{\text{teacher}}

is saved.

Afterward:

D_{\text{teacher}} \rightarrow S.

So:

\boxed{\text{teacher generation and student training are decoupled}}

25. A subtle but important point: what is actually transferred?

The teacher does not physically transfer:

W_T

into:

W_S.

There is no direct weight-copy operation.

Instead, the teacher provides supervision.

So:

\boxed{ \text{knowledge transfer} \neq \text{parameter transfer} }

This becomes especially important for DeepSeek-R1.

The smaller model already has its own parameters.

Teacher outputs influence how those parameters are trained.

26. Numerical example — information content of a hard target

Suppose four classes:

[cat,dog,fox,bird].

Hard label:

[1,0,0,0].

There is only one selected class.

Now teacher:

[0.865,0.117,0.016,0.002].

The student can learn not only:

cat=\text{correct}

but also:

dog>fox>bird.

Thus the teacher provides a richer structural signal per example.

This is the “dark knowledge” argument developed in the chapter. (Source: Build a DeepSeek Model (From Scratch))

27. Exam numerical — identify the method

Question

You have:

  • Teacher logits
  • Student logits
  • KL divergence
  • temperature T=4

What kind of distillation is this?

\boxed{\text{Soft distillation}}

because it matches the probability distributions.

Question

Teacher generates:

"Multiply both sides by 2..."

Student is trained using ordinary next-token cross-entropy.

What is this?

\boxed{\text{Hard distillation}}

28. Exam numerical — KL divergence

Given:

P_T=[0.8,0.2]

and:

P_S=[0.7,0.3].

Then:

D_{KL}(P_T\|P_S) = 0.8\log\frac{0.8}{0.7} + 0.2\log\frac{0.2}{0.3}.

Approx:

0.8(0.1335)+0.2(-0.4055)
=0.1068-0.0811
\boxed{\approx0.0257}.

A student distribution closer to the teacher gives a smaller KL value.

29. Exam question — which model gets gradients?

Classical KD:

\boxed{ \nabla_{\theta_T}L=0 }

because teacher is frozen.

Student:

\boxed{ \nabla_{\theta_S}L\neq0 }

and the optimizer updates:

\boxed{\theta_S}.

30. One crucial DeepSeek distinction

Don't say:

“DeepSeek-R1-Distill is classical knowledge distillation using KL divergence.”

According to the supplied chapter, that is not how the distilled R1 models were trained.

The chapter explicitly states:

\boxed{ \text{DeepSeek-R1 Distill} = \text{teacher-generated reasoning traces} + \text{SFT} }

with:

\boxed{\text{no temperature scaling}}

and:

\boxed{\text{no KL-divergence logit matching}}.

(Source: Build a DeepSeek Model (From Scratch))

This distinction is extremely likely to matter in an exam because the chapter intentionally presents the two paradigms side-by-side.

31. First-stage mental model

At this point, don't yet worry about the complete loss formula.

Just lock in:

\boxed{ \begin{array}{c} \text{Teacher = large + frozen}\\ \downarrow\\ \text{produce richer supervision}\\ \downarrow\\ \text{Student = small + trainable}\\ \downarrow\\ \text{learn teacher behavior} \end{array} }

Then distinguish:

\boxed{ \text{Hard KD = teacher-generated tokens} }

versus:

\boxed{ \text{Soft KD = teacher probability distribution} }

And:

\boxed{ \text{DeepSeek-R1 Distill = hard/text-based SFT approach} }

32. Master formulas for Step 4.1

Hard distillation
\boxed{ L_{\text{hard}} = -\sum_t \log P_S(y_t^T|y_{<t}^T,x) }

where y_t^T is the teacher-generated token.

34. Where we are going next

We have deliberately stopped before temperature, because temperature is the mathematical mechanism that solves the main weakness of Attempt #2.

The progression is:

\boxed{ \text{Hard labels} }

↓

\boxed{ \text{Teacher softmax at }T=1 }

↓

\boxed{ \text{still too peaked} }

↓

\boxed{ \text{Temperature }T>1 }

↓

\boxed{ \text{dark knowledge becomes visible} }

↓

\boxed{ \text{KL divergence} }

↓

\boxed{ T^2\text{ gradient correction} }

↓

\boxed{ L= \alpha L_{\text{hard}} + \beta T^2L_{\text{soft}} }

The supplied chapter gives the key example where T=3 transforms the teacher distribution into approximately:

\boxed{ [0.523,\ 0.268,\ 0.138,\ 0.071] }

making the inter-class relationships much more visible. (Source: Build a DeepSeek Model (From Scratch))
