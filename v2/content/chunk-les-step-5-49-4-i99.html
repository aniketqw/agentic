Step 5.49.4 — Pillar 4: Mantissa Over Exponents

Plan node: A4 · chat order #99

↩ Back to main text: Step 3.5 — Quantization → QLoRA · Step 3.6B — GGUF, K-Quants, QAT, BitNet, and 1.58-bit LLMs

We now reach the fourth pillar of DeepSeek's FP8 framework:

\boxed{\text{Mantissa over Exponents}}

This pillar looks like a simple choice between:

\boxed{E4M3}

and:

\boxed{E5M2},

but it is actually where the previous pillars come together.

The source's key argument is:

\boxed{ \text{Fine-grained quantization handles dynamic range locally} }

so DeepSeek can prefer the FP8 format with:

\boxed{\text{more mantissa bits}}

rather than sacrificing precision for additional exponent bits. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.1 First: decode the notation

The notation:

\boxed{E4M3}

means:

  • E4: 4 exponent bits,
  • M3: 3 mantissa bits.

Because FP8 has 8 total bits:

1\text{ sign}+4\text{ exponent}+3\text{ mantissa} = \boxed{8}.

Similarly:

\boxed{E5M2}

means:

1+5+2 = \boxed{8}.

The source explicitly gives these two configurations. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.2 The fundamental trade-off

Recall:

\boxed{ \text{Exponent}\rightarrow\text{dynamic range} }

and:

\boxed{ \text{Mantissa}\rightarrow\text{precision}. }

Therefore:

E5M2
5\text{ exponent bits}
2\text{ mantissa bits}.

So:

\boxed{ \text{more range} }

but:

\boxed{ \text{less precision}. }
E4M3
4\text{ exponent bits}
3\text{ mantissa bits}.

Therefore:

\boxed{ \text{less range} }

but:

\boxed{ \text{more precision}. }

This is exactly the trade-off given by the source. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.3 Why does one extra exponent bit matter?

Suppose a format has E exponent bits.

There are:

\boxed{2^E}

possible bit patterns for the exponent field.

So:

E4
2^4=16

possible exponent encodings.

E5
2^5=32

possible exponent encodings.

Thus E5 gives twice as many exponent encodings as E4.

This is a mathematical consequence of the bit allocation. The source's point is that this gives E5M2 a wider dynamic range. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.4 What does the extra mantissa bit give us?

Similarly:

M2
2^2=4

possible mantissa bit patterns.

M3
2^3=8.

So E4M3 has twice as many mantissa patterns as E5M2.

Conceptually:

\boxed{ M3\Rightarrow\text{finer representation within a local scale}. }

That is why E4M3 has higher precision according to the source. (Source: Build a DeepSeek Model (From Scratch))

Be careful: these counts are the raw number of bit patterns in the mantissa field, not the total number of floating-point values, because floating-point encodings also involve sign, exponent conventions, special values, and normalization.

5.49.4.5 Simple ruler analogy

Imagine two rulers that both have the same overall physical length.

E5M2-like ruler

More flexibility to represent very large/small magnitudes, but fewer fine subdivisions.

E4M3-like ruler

More fine subdivisions, but a smaller total numerical range.

Therefore:

\boxed{ E5M2=\text{range-oriented} }
\boxed{ E4M3=\text{precision-oriented}. }

5.49.4.6 Why would anyone prefer E5M2 for gradients?

Now think about training.

Gradients can sometimes contain:

\boxed{\text{large outliers}}.

Suppose a gradient tensor contains:

[0.002,\;0.004,\;0.01,\;100].

A format with greater dynamic range is attractive because:

100

is much larger than:

0.002.

The source describes the conventional strategy as:

\boxed{ E4M3\text{ for forward propagation} }

and:

\boxed{ E5M2\text{ for backward propagation}. }

The reasoning is that gradients can have larger values/outliers and therefore need greater dynamic range. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.7 The conventional approach

Conceptually:

Forward:
BF16/FP8 E4M3
        │
        ▼
 more precision

Backward:
FP8 E5M2
        │
        ▼
 more dynamic range

Thus:

\boxed{ Fprop\rightarrow E4M3 }
\boxed{ Dgrad,Wgrad\rightarrow E5M2 }

under the conventional strategy described by the source. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.8 Then DeepSeek asks a different question

The source's argument is essentially:

Do we still need the larger dynamic range of E5M2 if we have already solved the outlier problem using fine-grained quantization?

This connects directly to Pillar 2.

Recall:

\boxed{ \text{Pillar 2: split values into small groups/blocks}. }

Each region gets:

\boxed{\text{its own scaling factor}}.

Therefore the dynamic range inside one local block is much easier to manage.

5.49.4.9 Why fine-grained scaling changes the E4M3 decision

Suppose one global tensor contains:

[0.1,\;0.2,\;0.3,\;1000].

The global maximum:

\alpha=1000.

That is a terrible situation for a narrow-range format.

But now divide the values into groups:

G_1=[0.1,0.2,0.3]

and:

G_2=[1000].

Then:

\alpha_1=0.3

and:

\alpha_2=1000.

Each group is scaled independently.

Therefore the small group does not need to accommodate the 1000 outlier.

So:

\boxed{ \text{local scaling reduces the dynamic-range burden}. }

This is precisely the mechanism the source uses to justify E4M3. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.10 DeepSeek's choice

The source says DeepSeek therefore uses:

\boxed{ E4M3 }

uniformly for:

\boxed{ \text{both forward and backward operations}. }

This includes:

\boxed{ Fprop,\ Dgrad,\ Wgrad. }

The source calls this a powerful simplification made possible by fine-grained quantization. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.11 Why is E4M3 called “higher precision”?

Because:

E4M3

has:

3\text{ mantissa bits}

while:

E5M2

has:

2.

Thus:

\boxed{ \text{E4M3 allocates one more bit to the mantissa}. }

The source interprets this as better precision. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.12 What is lost?

One exponent bit.

Therefore:

5\text{ exponent bits} \rightarrow 4\text{ exponent bits}.

So:

\boxed{ \text{less dynamic range}. }

DeepSeek accepts this because Pillar 2 helps control local dynamic range.

So the relationship is:

\boxed{ \text{Fine-grained scaling} \Rightarrow \text{less need for global range} }

therefore:

\boxed{ \text{more mantissa bits can be prioritized}. }

5.49.4.13 This is the most important connection in the FP8 chapter

The four pillars now form a chain:

\boxed{ \text{Mixed Precision} }

says:

Use FP8 where it is worthwhile.

Then:

\boxed{ \text{Fine-Grained Quantization} }

says:

Don't let an outlier destroy everybody else's scale.

Then:

\boxed{ \text{Increasing Accumulation Precision} }

says:

Don't lose information while adding huge numbers of low-precision products.

Then:

\boxed{ \text{Mantissa over Exponents} }

says:

Because local scaling controls range, use the extra bit for precision.

This is why the source calls these innovations synergistic. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.14 A numerical bit-allocation question

Suppose you have an FP8 format.

Total bits:

8.

One is sign:

1.

Therefore:

8-1=7

bits remain for:

\text{exponent + mantissa}.
E5M2
5+2=7.
E4M3
4+3=7.

So both use exactly:

\boxed{8\text{ bits}}.

They simply distribute the same 7 non-sign bits differently.

5.49.4.15 Compare the fields

Format Sign Exponent Mantissa Primary emphasis
E5M2 1 5 2 Dynamic range
E4M3 1 4 3 Precision

This is exactly the source's conceptual comparison. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.16 Exam numerical — field pattern count

E5M2

Exponent field:

2^5=32

bit patterns.

Mantissa field:

2^2=4.
E4M3

Exponent:

2^4=16.

Mantissa:

2^3=8.

So:

\boxed{ E5M2: 32\text{ exponent patterns},4\text{ mantissa patterns} }
\boxed{ E4M3:16\text{ exponent patterns},8\text{ mantissa patterns}. }

The actual representable numerical range requires the precise FP8 encoding convention; the source does not provide those encoding details, so we should not invent exact min/max numbers here.

5.49.4.17 Why one extra mantissa bit matters

Suppose two nearby values need to be distinguished.

Imagine the ideal values:

1.000

and:

1.125.

A format with more mantissa precision has more representational granularity around that scale.

Thus:

\boxed{ \text{more mantissa bits}\rightarrow\text{smaller gaps between nearby values} }

within a given exponent scale.

This is what the source means by higher precision. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.18 Why this matters during training

Suppose a weight update requires a small difference:

W_{\text{new}} = W_{\text{old}}-\Delta.

If the numerical format is too coarse, small distinctions in:

\Delta

may be lost.

Therefore more mantissa bits can help preserve fine-grained numerical information.

This is general floating-point reasoning; the source specifically argues that the extra mantissa bit of E4M3 is desirable after fine-grained scaling has controlled dynamic range. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.19 Why gradients create the tension

The backward pass involves:

\frac{\partial L}{\partial X}

and:

\frac{\partial L}{\partial W}.

Gradients can contain unusually large values.

Hence:

\boxed{ \text{more exponent bits can protect against overflow}. }

But:

\boxed{ \text{more mantissa bits improve precision}. }

The conventional solution is therefore:

Fprop:E4M3
Backward:E5M2.

DeepSeek instead uses fine-grained quantization to mitigate the outlier/range problem and then chooses:

\boxed{ E4M3\text{ throughout}. }

(Source: Build a DeepSeek Model (From Scratch))

5.49.4.20 Let's connect it numerically to Pillar 2

Suppose a tensor has:

1000

as a huge outlier.

Global scaling requires a range capable of handling:

[-1000,1000].

Suppose another local group ranges only:

[-0.5,0.5].

With separate scaling:

\boxed{ G_1\rightarrow[-1000,1000] }

and:

\boxed{ G_2\rightarrow[-0.5,0.5]. }

The low-magnitude group no longer has to share the same scale.

Therefore the effective local dynamic range is far smaller.

This is why E4M3's reduced global range can be made workable by fine-grained scaling.

5.49.4.21 A conceptual inequality

Suppose:

R_{\text{global}} = \frac{x_{\max}}{x_{\min}}

is enormous.

After grouping, we get:

R_g = \frac{x_{\max,g}}{x_{\min,g}}

for each local group.

Typically:

\boxed{ R_g\ll R_{\text{global}} }

for many groups containing no extreme outlier.

That is the underlying reason local scaling reduces the burden on the floating-point format.

This is an inference from the source's grouping argument.

5.49.4.22 Why “mantissa over exponents”?

It does not mean:

\boxed{ \text{ignore exponents}. }

It means:

\boxed{ \text{within the 8-bit budget, prioritize precision once range is adequately controlled}. }

So the allocation becomes:

4E+3M

instead of:

5E+2M.

That single bit is moved:

\boxed{ E\rightarrow M. }

5.49.4.23 One-bit transfer

Starting with:

E5M2.

Move one bit from exponent to mantissa:

5E2M \rightarrow 4E3M.

So:

\boxed{ \Delta E=-1 }

and:

\boxed{ \Delta M=+1. }

Total remains:

\boxed8.

This is the mathematical essence of the design choice.

5.49.4.24 Why can this be better for a neural network?

Because neural-network training needs more than merely avoiding overflow.

It also needs to preserve small numerical differences.

So if range is sufficiently controlled:

\boxed{ \text{precision becomes the more valuable resource}. }

The source explicitly frames DeepSeek's E4M3 choice as preserving higher precision throughout training. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.25 Source-specific claim

The source says the DeepSeek paper explains the benefit of smaller element groups as effectively sharing exponent information among grouped elements, thereby mitigating the limited dynamic range. (Source: Build a DeepSeek Model (From Scratch))

Conceptually:

Global scaling

small value ────────────────┐
small value ────────────────┤
small value ────────────────┤──► same global scale
HUGE outlier ───────────────┘


Fine-grained scaling

small values ──► Group A ──► Scale A
small values ──► Group B ──► Scale B
HUGE outlier ──► Group C ──► Scale C

Thus the huge value in Group C doesn't determine the scale of Groups A and B.

5.49.4.26 Exam question

Why not use E5M2 everywhere?

Because:

E5M2

sacrifices a mantissa bit to gain exponent range.

If fine-grained quantization already controls local dynamic range, the source argues that the additional range is less necessary, while the extra mantissa bit provides more useful precision.

Therefore:

\boxed{ E4M3 }

is preferred.

(Source: Build a DeepSeek Model (From Scratch))

5.49.4.27 Exam question

Why not use E4M3 everywhere without fine-grained quantization?

Because its smaller exponent allocation means less dynamic range.

If a large outlier determines the scale of an entire tensor, the limited range/precision can cause severe numerical problems.

So:

\boxed{ E4M3\text{ and fine-grained scaling work together}. }

The source explicitly presents the E4M3 choice as enabled by the earlier fine-grained approach. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.28 Four pillars now interact

Let's put them together:

\boxed{ \text{Pillar 1} = \text{Mixed Precision} }

decides:

\text{FP8 is used for bulk GEMMs}.
\boxed{ \text{Pillar 2} = \text{Fine-Grained Scaling} }

decides:

\text{each local region gets its own scale}.
\boxed{ \text{Pillar 3} = \text{Accumulation Promotion} }

decides:

\text{long sums are protected with FP32}.
\boxed{ \text{Pillar 4} = \text{E4M3} }

decides:

\text{use the extra FP8 bit for precision rather than range}.

5.49.4.29 Numerical design question

Suppose you can choose between two FP8 formats.

Option A
E5M2.
Option B
E4M3.

You know the application already uses strong local scaling, so local values are well controlled.

Which format provides greater mantissa capacity?

E4M3: \boxed{3\text{ mantissa bits}}

versus:

E5M2: \boxed{2}.

Therefore:

\boxed{E4M3}.

This follows directly from the source's stated design rationale. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.30 Numerical question: percentage of FP8 bits

For E4M3:

Mantissa fraction of all 8 bits:

\frac38 = \boxed{37.5\%}.

Exponent fraction:

\frac48 = \boxed{50\%}.

Sign:

\frac18 = \boxed{12.5\%}.

For E5M2:

Mantissa:

\frac28 = \boxed{25\%}.

Exponent:

\frac58 = \boxed{62.5\%}.

So E4M3 allocates:

\boxed{12.5\text{ percentage points more of the total format to mantissa}}

and E5M2 allocates that bit to exponent.

5.49.4.31 Important exam trap

Do not say:

\boxed{ E4M3\text{ has greater dynamic range than E5M2}. }

Wrong.

The source explicitly says:

\boxed{ E5M2>\text{dynamic range} }

and:

\boxed{ E4M3>\text{precision}. }

(Source: Build a DeepSeek Model (From Scratch))

5.49.4.32 Another exam trap

Do not say:

\boxed{ \text{E5M2 is more precise}. }

For the source's comparison:

\boxed{ E4M3 }

has more mantissa bits and therefore higher precision.

5.49.4.33 The deeper systems insight

Pillar 4 is not an isolated choice.

It is an example of a broader engineering pattern:

\boxed{ \text{solve the range problem elsewhere} \rightarrow \text{free the representation budget for precision}. }

DeepSeek does exactly this:

\boxed{ \text{Fine-grained scaling} \rightarrow \text{local range control} }

then:

\boxed{ \text{E4M3} \rightarrow \text{more precision}. }

This is why the source says the FP8 techniques work synergistically. (Source: Build a DeepSeek Model (From Scratch))

5.49.4.35 What remains?

There is one final FP8 pillar:

\boxed{\text{Pillar 5 — Online Quantization}}.

We already know how a scale is calculated:

\alpha=\max|x|.

But there is another question:

\boxed{ \text{When should we calculate }\alpha? }

Should we use:

\text{yesterday's statistics}

or:

\boxed{ \text{the current tensor itself}? }

DeepSeek's answer is:

\boxed{\text{Online Quantization}}.

The source describes this as calculating the scaling factor from the current tensor/batch rather than relying on historical maxima. (Source: Build a DeepSeek Model (From Scratch))
