Step 4.7 — The Three Progressive Distillation Attempts

Plan node: I5 · chat order #39

We are now going back to the section where the chapter builds the classical distillation objective from the simplest possible baseline to the final loss.

This is important because the formulas make much more sense when you understand why each modification was introduced.

The source explicitly presents this as three progressive approaches: hard-label training, teacher-output matching at T=1, and temperature-scaled soft targets; the complete hard+soft loss is then built from those ideas. (Source: Build a DeepSeek Model (From Scratch))

1. The overall evolution

Think of the progression as:

\boxed{ \text{Attempt 1} \rightarrow \text{Attempt 2} \rightarrow \text{Attempt 3} \rightarrow \text{Complete KD loss} }

with:

\boxed{ \text{Hard labels} }

then:

\boxed{ \text{Teacher probabilities at }T=1 }

then:

\boxed{ \text{Teacher probabilities at higher }T }

and finally:

\boxed{ \text{Hard loss + temperature-scaled soft loss} }

The reason for every step is the key thing to understand.

2. Attempt #1 — Ignore the teacher completely

Suppose the true class is:

\text{cat}.

The hard label is represented as:

\boxed{ y=[1,0,0,0] }

for:

[\text{cat},\text{dog},\text{fox},\text{bird}].

The student predicts:

P_S=[p_1,p_2,p_3,p_4].

The loss is ordinary cross-entropy:

\boxed{ L_{\text{hard}} = -\sum_i y_i\log p_i }

Since only the correct class has y_i=1:

\boxed{ L_{\text{hard}} = -\log P_S(\text{cat}) }

Nothing about the teacher is used.

The source calls this the baseline and notes that the student must independently discover relationships between classes. (Source: Build a DeepSeek Model (From Scratch))

3. What information does hard labeling give?

Suppose:

y=[1,0,0,0].

The student knows:

\boxed{\text{cat is correct}}

but receives no explicit information about:

\text{dog}

versus:

\text{fox}

versus:

\text{bird}.

In the source's simplified information-theoretic framing, each example provides roughly one bit of directional information. (Source: Build a DeepSeek Model (From Scratch))

The important conceptual message is not the exact bit count; it is:

\boxed{ \text{hard labels tell you the answer, not the teacher's uncertainty structure} }

4. Example of what the student does NOT know

Suppose the image is a cat.

Teacher knows:

P_T= [0.865,0.117,0.016,0.002].

This says:

\text{cat} > \text{dog} > \text{fox} > \text{bird}.

The hard label only says:

[1,0,0,0].

So the hard-label student does not directly receive:

\boxed{ \text{cat is much more similar to dog than to bird} }

That structure is the teacher's additional knowledge.

5. Why Attempt #1 is limited

Suppose we want the student to discover that:

\text{cat}\sim\text{dog}

more than:

\text{cat}\sim\text{bird}.

With only hard labels, the student has to infer that indirectly from many examples.

That is:

\text{many examples} \rightarrow \text{statistical pattern} \rightarrow \text{learn relationships}.

The teacher has already learned these relationships.

So why make the student rediscover them?

That question motivates Attempt #2.

6. Attempt #2 — Use the teacher's probabilities

Now we say:

Instead of giving only the one-hot label, why not train the student to reproduce the teacher's output probabilities?

Teacher produces:

P_T=[0.865,0.117,0.016,0.002].

Now the student has access to:

\boxed{ \text{the entire teacher distribution} }

rather than:

\boxed{ \text{just the correct class} }.

This is already a major improvement conceptually.

The source describes this as the second attempt. (Source: Build a DeepSeek Model (From Scratch))

7. But Attempt #2 has a problem

The teacher's distribution at ordinary temperature is:

\boxed{ [0.865,0.117,0.016,0.002] }

Look at the last two values:

0.016

and:

0.002.

They are tiny.

The teacher technically contains information about fox and bird, but the signal is extremely small.

The source describes this as the distribution being almost as peaked as the hard label. (Source: Build a DeepSeek Model (From Scratch))

8. Why is that bad?

Suppose we compare:

\text{cat}=0.865

to:

\text{fox}=0.016.

The ratio is:

\frac{0.865}{0.016} \approx54.1.

So the cat probability is roughly 54 times larger.

And:

\frac{0.865}{0.002} = 432.5.

So the cat probability is more than 400 times larger than bird.

Thus the contribution from very small classes is tiny compared with the dominant class.

The source specifically explains this in terms of gradient magnitudes. (Source: Build a DeepSeek Model (From Scratch))

9. Gradient intuition for Attempt #2

For a teacher-target matching objective, the teacher probability influences the strength of the learning signal.

At T=1:

P_T(\text{fox})=0.016.

At T=1:

P_T(\text{bird})=0.002.

Therefore the student receives very weak pressure to learn those subtle distinctions.

The source gives the useful comparison:

\boxed{ 0.016\text{ is about }50\times\text{ smaller than }0.865 }

and:

\boxed{ 0.002\text{ is about }400\times\text{ smaller} }

in the relevant gradient intuition. (Source: Build a DeepSeek Model (From Scratch))

10. So Attempt #2 solves one problem but creates another

Attempt #1

Problem:

\boxed{ \text{no teacher information} }
Attempt #2

Improvement:

\boxed{ \text{teacher information is present} }

But:

\boxed{ \text{most teacher information is buried in tiny probabilities} }

So the next question is:

How do we make those small probabilities more informative?

This leads directly to temperature.

11. Attempt #3 — Temperature-scaled teacher targets

Instead of:

P_T=\operatorname{softmax}(z_T),

we calculate:

\boxed{ P_T^T = \operatorname{softmax}(z_T/T) }

with:

T>1.

The source uses:

\boxed{T=3}

as the central example. (Source: Build a DeepSeek Model (From Scratch))

12. Use the same teacher logits

Teacher logits:

z_T=[5,3,1,-1].

At:

T=1

we have:

\boxed{ [0.865,0.117,0.016,0.002] }

At:

T=3

we get:

\boxed{ [0.523,0.268,0.138,0.071] }

The source provides exactly these values. (Source: Build a DeepSeek Model (From Scratch))

13. Look at what happened

At T=1:

\text{fox}=0.016

At T=3:

\text{fox}=0.138.

Increase:

\frac{0.138}{0.016} = \boxed{8.625}.

So the fox signal becomes about:

\boxed{8.6\times}

larger.

14. What happened to bird?

At T=1:

\text{bird}=0.002.

At T=3:

\text{bird}=0.071.

Ratio:

\frac{0.071}{0.002} = \boxed{35.5}.

So the bird probability becomes about:

\boxed{35\times}

larger.

This is why the source says temperature makes previously tiny probabilities meaningfully visible. (Source: Build a DeepSeek Model (From Scratch))

15. What information is revealed?

At T=3:

[0.523,0.268,0.138,0.071].

Now the student sees:

\boxed{ \text{cat} > \text{dog} > \text{fox} > \text{bird} }

with meaningful probability differences.

The source calls this:

\boxed{\text{dark knowledge}}

and describes the resulting relationship as:

\text{cat}\rightarrow\text{dog}\rightarrow\text{fox}\rightarrow\text{bird}.

(Source: Build a DeepSeek Model (From Scratch))

16. What does “dark knowledge” really mean?

It is not mysterious knowledge hidden somewhere inside the model.

It means:

\boxed{ \text{information contained in the relative probabilities of alternatives} }

The hard label says:

\boxed{\text{cat}}

The soft target says:

\boxed{ \text{cat strongly preferred, dog somewhat plausible, fox less plausible, bird unlikely} }

So the teacher gives the student a structured ranking of alternatives.

17. Critical property: ranking does not change

At T=1:

5>3>1>-1.

At T=3:

5/3>3/3>1/3>-1/3.

So:

\boxed{ \text{ordering remains unchanged} }

Temperature changes the sharpness, not the ranking.

That is crucial.

18. Why T=3, not T=100?

Because too much smoothing destroys useful information.

The source describes a Goldilocks zone:

T=1

→ too sharp.

Approximately:

T=2\text{ to }5

→ useful dark knowledge.

Very high:

T\gtrsim10

→ distribution becomes too flat and useful distinctions can disappear. (Source: Build a DeepSeek Model (From Scratch))

19. Numerical comparison of temperatures

Teacher logits:

[5,3,1,-1].

The source gives:

Temperature Distribution
T=1 [0.865,0.117,0.016,0.002]
T=2 [0.644,0.237,0.087,0.032]
T=3 [0.523,0.268,0.138,0.071]
T=5 [0.413,0.277,0.186,0.124]
T=10 [0.329,0.270,0.221,0.181]

(Source: Build a DeepSeek Model (From Scratch))

Look carefully.

At:

T=10

the distribution is getting close to:

[0.25,0.25,0.25,0.25].

So now the teacher is almost saying:

“I am not very sure; everything is fairly plausible.”

That loses some useful distinctions.

20. There is another subtle point: student size matters

The source connects temperature choice to student capacity.

Very small student:

1B-3B

is given as benefiting from roughly:

T=2\text{ or }3.

Medium:

7B-14B

around:

T=3\text{ or }4.

Larger:

32B-70B

can benefit from:

T=4\text{ or }5.

(Source: Build a DeepSeek Model (From Scratch))

The reasoning is:

\boxed{ \text{more capable student} \rightarrow \text{can absorb richer soft information} }

whereas a tiny student may be overwhelmed by overly diffuse targets.

21. Now we have a better signal

At this point:

\boxed{ \text{Attempt \#3 gives us rich teacher information} }

But there is still a question.

Should we throw away the ground-truth hard label completely?

The answer is:

\boxed{\text{No}}

and this takes us to the complete KD loss.

22. Why not use only the soft target?

Suppose the teacher makes a mistake.

Ground truth says:

\text{cat}.

But the teacher says:

P_T^T=[0.4,0.35,0.2,0.05].

The student could become overly influenced by the teacher's mistake or uncertainty.

The hard label gives a direct correctness constraint.

Therefore:

\boxed{ \text{ground truth provides grounding} }

while:

\boxed{ \text{teacher distribution provides knowledge transfer} }

This is exactly how the source motivates the final objective. (Source: Build a DeepSeek Model (From Scratch))

23. Complete loss

Now we combine:

L_{\text{hard}}

and:

L_{\text{soft}}.

The source gives:

\boxed{ L= \alpha L_{\text{hard}} + \beta T^2 KL(P_T^T\|P_S^T) }

with:

\alpha+\beta=1

under the normalized weighting convention. (Source: Build a DeepSeek Model (From Scratch))

The implementation writes this as:

\boxed{ L= \alpha L_{\text{hard}} + (1-\alpha)T^2KL }

which is the same when:

\beta=1-\alpha.

24. Why T^2 appears only now

We previously established:

P_T^T=\operatorname{softmax}(z_T/T)

and:

P_S^T=\operatorname{softmax}(z_S/T).

Increasing T weakens the gradients.

The source gives the relationship:

\frac{\partial L_{\text{soft}}}{\partial z_S} \propto \frac1T(P_S^T-P_T^T)

and explains that the probability gap itself shrinks approximately like 1/T, giving:

\boxed{ \text{gradient}\sim\frac1{T^2} }

so:

\boxed{ \times T^2 }

restores a comparable scale. (Source: Build a DeepSeek Model (From Scratch))

25. The progression is now mathematically complete

Let's put all four stages together.

Attempt 1

\boxed{ L=CE(\text{student},\text{ground truth}) }

Problem:

\text{no teacher knowledge}.

Attempt 2

\boxed{ \text{match teacher probabilities at }T=1 }

Problem:

\text{teacher distribution too peaked}.

Attempt 3

\boxed{ \text{match teacher probabilities at }T>1 }

Improvement:

\text{dark knowledge becomes visible}.

Complete objective

\boxed{ L= \alpha L_{\text{hard}} + \beta T^2KL(P_T^T\|P_S^T) }

Now we have:

\boxed{ \text{correctness + teacher structure} }

27. What each attempt teaches us

This is probably the most useful table to memorize.

Attempt What student sees Main problem
1 hard ground truth teacher knowledge completely ignored
2 teacher probabilities at T=1 probabilities are too peaked
3 teacher probabilities at T>1 rich information is exposed
Final hard CE + T^2-scaled KL combines correctness + teacher knowledge

28. The design logic

The chapter's reasoning can be expressed as:

\boxed{ \text{Why use teacher?} }

Because hard labels lose information.

Then:

\boxed{ \text{Why use temperature?} }

Because teacher probabilities at T=1 hide most of the useful information in tiny values.

Then:

\boxed{ \text{Why keep hard labels?} }

Because teacher guidance should not replace objective correctness.

Then:

\boxed{ \text{Why }T^2? }

Because temperature weakens the soft-loss gradient.

That is the whole derivation logic.

Correct probability:

Suppose:

Suppose:

T=5

and:

34. Exam conceptual question

Why is Attempt #2 only slightly better than Attempt #1?

Because teacher probabilities at:

T=1

are still highly concentrated on the top class:

[0.865,0.117,0.016,0.002].

The small probabilities corresponding to alternative classes create very weak gradients, so much of the teacher's relational knowledge remains effectively hidden. (Source: Build a DeepSeek Model (From Scratch))

35. Exam conceptual question

Why does temperature help?

Because:

z/T

compresses logit differences before softmax.

This makes lower-probability alternatives receive larger probabilities.

Thus:

\boxed{ \text{small teacher probabilities become trainable signals} }

while preserving ranking.

36. Exam conceptual question

Why not use T=1000?

Because the distribution becomes nearly uniform.

Then:

P_T^T \approx [1/V,\ldots,1/V].

You lose the useful relative structure between alternatives.

The source therefore describes a middle temperature range as more useful than extreme smoothing. (Source: Build a DeepSeek Model (From Scratch))

37. Exam conceptual question

Why does the complete loss use two terms?

Because:

L_{\text{hard}}

provides:

\boxed{\text{correctness}}

while:

KL

provides:

\boxed{\text{teacher's relational information}}

The source explicitly describes these as grounding and knowledge transfer. (Source: Build a DeepSeek Model (From Scratch))

38. One very useful mental analogy

Think of the teacher as an expert professor.

Hard label

Professor says:

The answer is A.

Soft target

Professor says:

The answer is A with high confidence, B is somewhat plausible, C is less plausible, D is almost impossible.

Temperature-scaled soft target

Professor slows down and explains the uncertainty more clearly:

A is strongest, but B is considerably more plausible than C, and C is considerably more plausible than D.

Combined objective

Student is told:

Learn the correct answer from the ground truth, but also learn the expert's reasoning structure.

That is the intuition behind the math.

39. Important source boundary

Everything we just did is about classical knowledge distillation.

The later DeepSeek-R1 approach changes the mechanism:

\boxed{ \text{R1 hard/text distillation} = \text{teacher-generated reasoning traces + SFT} }

not:

\boxed{ \text{temperature-scaled KL} }

The source explicitly contrasts these two paradigms. (Source: Build a DeepSeek Model (From Scratch))

So do not combine them into one formula.

42. The single most important progression

Memorize this:

\boxed{ \text{Hard labels} \rightarrow \text{Teacher probabilities} \rightarrow \text{Temperature-softened teacher probabilities} \rightarrow \text{Hard + soft weighted loss} }

And understand why:

\boxed{ \text{not enough information} \rightarrow \text{information too concentrated} \rightarrow \text{information exposed} \rightarrow \text{information + correctness combined} }

That is the logic of the chapter's entire classical KD construction. (Source: Build a DeepSeek Model (From Scratch))
