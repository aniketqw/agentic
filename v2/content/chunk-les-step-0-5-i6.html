Why this matters

An objective averaged over possible outcomes is a weighted sum. It differs from an unweighted sample mean unless the weights justify that mean.

Prerequisites: Stable softmax and log-softmax

Symbols, shapes and assumptions

The values xᵢ are weighted by a normalized PMF pᵢ. Population variance uses those probabilities, not an unbiased sample denominator n-1.

Derivation or mechanism

  1. Compute μ=Σpᵢxᵢ.
  2. Subtract μ from each possible value.
  3. Square each difference and take the same weighted average. Equivalently use E[X²]-μ².
\mu=\mathbb E[X]=\sum_i p_i x_i
\mathrm{Var}(X)=\sum_i p_i(x_i-\mu)^2=\mathbb E[X^2]-\mu^2

Worked numerical

For values [0,1,3] with probabilities [0.2,0.5,0.3], μ=0+0.5+0.9=1.4. E[X²]=0+0.5+2.7=3.2, so variance=3.2-1.96=1.24. Attention applies a weighted average to each value-vector component.

Edge cases and limits

  • For vector-valued outcomes, the expectation is componentwise; covariance carries cross-component information.
  • Correlated samples do not justify independent-sample success formulas.

Connections

  • T04 treats attention output as a weighted combination.
  • Policy-gradient expectations and group statistics need their own sampling assumptions.

STEP 0.5 — EXPECTATION

Plan node: I0 · chat order #6

Weighted Average → Expected Value → Conditional Expectation → Variance → Why E[\cdot] Appears Everywhere in Attention and RL

We have now established:

\text{vectors} \rightarrow \text{matrices} \rightarrow \text{probabilities} \rightarrow \text{softmax} \rightarrow \text{entropy / CE / KL} \rightarrow \text{gradients / backpropagation}

The next mathematical primitive in your master cheatsheet is:

\boxed{E[f(X)]}

The cheatsheet gives the discrete definition:

\boxed{ E[f(X)] = \sum_x P(x)f(x) }

and your RL material later uses expectation directly in objectives such as:

J(\theta)=E_{\tau\sim\pi_\theta}[R(\tau)].

So this is the bridge from basic probability to attention and reinforcement learning. (Source: MASTER_Mathematical_Cheatsheet_All_Lecture_PDFs; Build a Reasoning Model (From Scratch))

0.5.1 Start with something you already know: an average

Suppose marks are:

60,70,80

The ordinary average is:

\frac{60+70+80}{3}=70

Each value receives equal weight:

\frac13,\frac13,\frac13

So we can rewrite it as:

\frac13(60)+\frac13(70)+\frac13(80)

That is already a weighted average.

0.5.2 Expected value is a probability-weighted average

Suppose instead the outcomes have different probabilities.

For a random variable X:

Outcome x Probability P(X=x)
10 0.2
20 0.5
40 0.3

Then the expected value is:

E[X] = 10(0.2)+20(0.5)+40(0.3)
=2+10+12
\boxed{E[X]=24}

So:

\boxed{ \text{Expectation}= \text{average weighted by probability} }

This is the most important intuition.

0.5.3 Expectation does NOT necessarily mean a value you will actually observe

This is an important subtlety.

We got:

E[X]=24

But 24 is not one of our possible outcomes.

The outcomes are:

10,\;20,\;40

Expectation is the long-run weighted average, not necessarily a possible single outcome.

Imagine repeating the random experiment many times. The average observed value tends toward the expected value under the usual conditions.

0.5.4 Random variable

A random variable X is a variable whose value depends on a random outcome.

For our example:

X\in\{10,20,40\}

with probabilities:

P(X=10)=0.2
P(X=20)=0.5
P(X=40)=0.3

Then:

E[X] = \sum_x P(X=x)x

which is the special case of the more general formula:

\boxed{ E[f(X)] = \sum_xP(X=x)f(X) }

from your mathematical cheatsheet. (Source: MASTER_Mathematical_Cheatsheet_All_Lecture_PDFs)

0.5.5 Why do we need f(X)?

Because often we don't want the expectation of X itself.

We may want:

E[X^2]

or:

E[|X|]

or:

E[\log X]

or:

E[R]

or:

E[A(X)]

The general form handles all of these:

\boxed{ E[f(X)] = \sum_xP(x)f(x) }

0.5.6 Numerical example with f(X)=X^2

Use:

X= \{1,2,3\}

with:

P=[0.2,0.5,0.3]

First:

E[X] = 1(0.2)+2(0.5)+3(0.3)
=2.1

Now:

E[X^2] = 1^2(0.2)+2^2(0.5)+3^2(0.3)
=0.2+2+2.7
\boxed{E[X^2]=4.9}

Notice:

E[X^2]\neq(E[X])^2

Here:

(E[X])^2=2.1^2=4.41

while:

E[X^2]=4.9

This distinction will become important when we study variance.

0.5.7 Expectation and probability distributions

Suppose:

P=[0.1,0.2,0.7]

and values:

x=[2,5,10]

Then:

E[X] = 0.1(2)+0.2(5)+0.7(10)
=0.2+1+7
\boxed{E[X]=8.2}

So the probability distribution acts as the weighting mechanism.

This is a recurring pattern throughout machine learning:

\boxed{ \text{distribution} \rightarrow \text{weights} \rightarrow \text{weighted average} }

0.5.8 This should immediately remind you of attention

Remember:

A=\operatorname{softmax}(S)

Each row of A contains weights:

a_1,a_2,\ldots,a_n

such that:

a_i\ge0

and:

\sum_i a_i=1

Then attention computes:

\boxed{ O=\sum_i a_iV_i }

That is mathematically a weighted average of the value vectors.

For one query:

o= a_1v_1+a_2v_2+\cdots+a_nv_n

This is extremely closely related to expectation:

E[V] = \sum_iP(i)V_i

So a powerful mental model is:

\boxed{ \text{Attention output} \approx \text{expectation of values under the attention distribution} }

The supplied attention handbook describes attention as a weighted combination of values, with softmax turning scores into normalized weights and AV producing the output. (Source: Understanding_Attention_Handbook_01)

0.5.9 Concrete attention example

Suppose there are three value vectors:

V_1= \begin{bmatrix} 1\\ 0 \end{bmatrix}, \quad V_2= \begin{bmatrix} 0\\ 2 \end{bmatrix}, \quad V_3= \begin{bmatrix} 3\\ 1 \end{bmatrix}

and attention weights:

A=[0.2,0.5,0.3]

Then:

O = 0.2V_1+0.5V_2+0.3V_3

Compute the first component:

0.2(1)+0.5(0)+0.3(3) = 1.1

Second component:

0.2(0)+0.5(2)+0.3(1) = 1.3

Therefore:

\boxed{ O= \begin{bmatrix} 1.1\\ 1.3 \end{bmatrix} }

The attention mechanism has effectively computed:

"Take the expected value representation under the distribution of attention weights."

That's an excellent mathematical interpretation.

0.5.10 But attention weights are not literally an event probability

Be precise here.

We can mathematically treat:

[a_1,\ldots,a_n]

as a normalized distribution over positions.

That allows us to use expectation-like language.

But that does not mean:

"There is a real-world random event where token 2 occurs with probability 0.5."

These are learned coefficients used for aggregation.

The attention handbook explicitly distinguishes normalized attention weights from stronger claims about semantic interpretation or explanation. (Source: Understanding_Attention_Handbook_01)

0.5.11 Expectation of a constant

If:

X=c

always, then:

E[X]=c

Example:

X=5

with probability 1.

Then:

E[X]=1(5)=5

So:

\boxed{E[c]=c}

0.5.12 Linearity of expectation

One of the most useful properties is:

\boxed{ E[aX+bY] = aE[X]+bE[Y] }

for constants a,b.

And more generally:

\boxed{ E[X+Y]=E[X]+E[Y] }

This is true even when X and Y are not independent.

That is a very useful fact in probability and reinforcement learning.

0.5.13 Numerical example

Suppose:

E[X]=4
E[Y]=7

Find:

E[3X+2Y+5]

By linearity:

E[3X+2Y+5] = 3E[X]+2E[Y]+5
=3(4)+2(7)+5
=12+14+5
\boxed{31}

No need to enumerate every possible combination of X and Y.

0.5.14 Why linearity is so useful in machine learning

Suppose we have many token losses:

L_1,L_2,\ldots,L_n

and define:

L=\frac1n\sum_tL_t

We can reason about their expected value using linearity.

Similarly, in RL we may have total reward:

R=r_1+r_2+\cdots+r_T

and expectation can be decomposed:

E[R] = E[r_1]+\cdots+E[r_T]

This becomes very useful when reasoning about returns and policy objectives.

0.5.15 Expected reward

Now enter reinforcement learning.

Suppose an agent can produce three possible trajectories:

Trajectory Probability Reward
\tau_1 0.2 10
\tau_2 0.5 4
\tau_3 0.3 -2

Expected reward:

E[R] = 0.2(10)+0.5(4)+0.3(-2)
=2+2-0.6
\boxed{E[R]=3.4}

The agent's objective is not:

"Always get the reward of the single best trajectory."

It is often formulated as:

maximize expected reward under the policy.

Your supplied reasoning-model material introduces the policy objective in exactly this expectation form, and the master cheatsheet records:

\boxed{ J(\theta)=E_{\tau\sim\pi_\theta}[R(\tau)] }

. (Source: Build a Reasoning Model (From Scratch); MASTER_Mathematical_Cheatsheet_All_Lecture_PDFs_v2)

0.5.16 Why the subscript \tau\sim\pi_\theta?

This notation:

E_{\tau\sim\pi_\theta}[R(\tau)]

means:

Take trajectories \tau generated according to policy \pi_\theta, and average their rewards.

So:

  • \tau = trajectory / generated response
  • \pi_\theta = policy parameterized by \theta
  • R(\tau) = reward of trajectory
  • E = average weighted according to the policy's distribution over trajectories

This is why expectation is fundamental to RL.

0.5.17 LLM as a probability policy

For an LLM:

\pi_\theta(y_t\mid x,y_{<t})

means:

probability of choosing token y_t, given the prompt and previous generated tokens.

So the model's token probability distribution becomes an RL policy.

The supplied master cheatsheet makes this explicit:

s_t=(x,y_{<t})
a_t=y_t
\pi_\theta(y_t\mid x,y_{<t})

. (Source: MASTER_Mathematical_Cheatsheet_All_Lecture_PDFs_v2)

Therefore:

LLM probability distribution
          ↓
      policy πθ
          ↓
   generate actions/tokens
          ↓
      trajectory τ
          ↓
        reward
          ↓
 expected reward E[R]

0.5.18 Conditional expectation

Now we need another concept.

Sometimes the expected value changes depending on known information.

For example:

What is the expected reward given the current state?

This is:

\boxed{ E[X\mid Y=y] }

called conditional expectation.

In a discrete case:

\boxed{ E[X\mid Y=y] = \sum_x xP(X=x\mid Y=y) }

The important idea is:

First restrict the distribution using the known condition, then calculate the weighted average.

0.5.19 Simple example

Suppose today's weather Y is known to be rainy.

Possible temperature X:

Temperature P(X\mid Rain)
15 0.2
20 0.5
25 0.3

Then:

E[X\mid Rain] = 15(0.2)+20(0.5)+25(0.3)
=3+10+7.5
\boxed{E[X\mid Rain]=20.5}

We did not use the unconditional temperature distribution.

We used:

P(X\mid Rain)

0.5.20 Why conditional expectation matters for LLMs

An LLM constantly computes conditional distributions.

For next-token prediction:

P(y_t\mid x,y_{<t})

The model is essentially saying:

Given this context, what is the distribution over possible next tokens?

Then we can conceptually calculate expected quantities under that distribution.

This same conditioning structure appears in:

\pi_\theta(y_t\mid x,y_{<t})

during RL.

So expectation and conditional probability are naturally connected.

0.5.21 From token-level expectation to sequence-level expectation

Suppose the model generates a sequence:

y_1,y_2,\ldots,y_T

The probability of that sequence is:

P_\theta(y_{1:T}\mid x) = \prod_{t=1}^{T} P_\theta(y_t\mid x,y_{<t})

The model samples sequences according to this distribution.

Then RL can evaluate:

E_{y\sim\pi_\theta}[R(y)]

So:

\boxed{ \text{token probabilities} \rightarrow \text{sequence distribution} \rightarrow \text{expected reward} }

That is the mathematical bridge into RL.

0.5.22 Variance

Expectation tells us the center of a distribution.

But it doesn't tell us how spread out it is.

For that we use variance.

\boxed{ \operatorname{Var}(X) = E[(X-E[X])^2] }

Your supplied lecture material uses this exact expectation-based definition when discussing bias-variance. (Source: 5. Linear Regression)

0.5.23 Why square the difference?

Suppose:

E[X]=10

and outcomes are:

8,\;10,\;12

The deviations are:

-2,\;0,\;+2

If we simply averaged deviations:

\frac{-2+0+2}{3}=0

we would incorrectly conclude there is no spread.

So we square:

(-2)^2=4
0^2=0
2^2=4

which gives a positive measure of spread.

0.5.24 Standard deviation

Variance is in squared units.

So we often take the square root:

\boxed{ \sigma_X=\sqrt{\operatorname{Var}(X)} }

This returns the spread to the same units as X.

0.5.25 Why does variance matter for our later RL lessons?

Because RL training estimates expectations from sampled trajectories.

Sampling introduces noise.

We therefore care about:

\boxed{\text{variance of the gradient estimate}}

This motivates concepts such as:

  • baselines
  • advantage functions
  • group normalization
  • PPO stabilization
  • GRPO's relative normalization

Your master cheatsheet explicitly notes that the advantage subtracts a baseline to reduce variance under standard conditions, and GRPO normalizes group rewards using their standard deviation. (Source: MASTER_Mathematical_Cheatsheet_All_Lecture_PDFs_v2)

So today's simple expectation/variance lesson directly prepares us for GRPO.

0.5.26 Expected return in RL

Suppose an agent receives rewards:

r_1,r_2,r_3,\ldots

A discounted return is:

\boxed{ G_t= \sum_{k=0}^{T-t-1} \gamma^k r_{t+k+1} }

where:

0\le\gamma\le1

and \gamma determines how much future rewards are discounted.

Your master cheatsheet includes exactly this return definition. (Source: MASTER_Mathematical_Cheatsheet_All_Lecture_PDFs_v2)

Then RL often cares about:

E[G_t]

or expected cumulative reward.

So expectation is now appearing again.

0.5.27 Why discounting?

Suppose:

\gamma=0.9

and future rewards are:

10,\;10,\;10

Then:

G = 10+ 0.9(10)+ 0.9^2(10)
= 10+9+8.1
\boxed{G=27.1}

The later rewards still matter, but less.

This gives a way to encode the idea:

Near-term consequences matter more than very distant consequences.

We will derive RL returns much more rigorously later; for now the key point is that expectation will be applied over these returns.

0.5.28 Monte Carlo estimation of expectation

Here is another concept you absolutely need.

Suppose:

E[X]

is difficult to calculate exactly.

We can sample:

x_1,x_2,\ldots,x_N

and estimate:

\boxed{ E[X] \approx \frac1N\sum_{i=1}^{N}x_i }

This is the sample mean.

For example, suppose rewards from five sampled responses are:

[8,6,10,4,7]

Then estimated expected reward:

\hat E[R] = \frac{8+6+10+4+7}{5}
= \frac{35}{5}
\boxed{\hat E[R]=7}

This is how sampled rollouts become useful in RL.

0.5.29 This is exactly the bridge to policy gradients

The RL slides explain the key difficulty:

We want to optimize an expectation over sampled outputs, but directly differentiating through a discrete token sample is not available.

They then use the score-function identity:

\boxed{ \nabla_\theta E_{y\sim p_\theta}[A(y)] = E_{y\sim p_\theta} [ A(y)\nabla_\theta\log p_\theta(y) ] }

This is the mathematical foundation of policy-gradient methods. (Source: rl-grpo-slides)

Don't worry about deriving this yet.

Just recognize its structure:

\boxed{ \nabla(\text{expectation}) = \text{expectation of something} }

We will derive this from first principles in the RL section.

0.5.30 The deep connection to attention

Attention:

O=AV

can be written row-wise as:

o_i=\sum_j a_{ij}v_j

Because:

\sum_j a_{ij}=1

this resembles:

E[V\mid \text{query }i]

under the attention distribution.

Therefore:

\boxed{ \text{Attention} = \text{learned weighted aggregation} \approx \text{expectation under learned weights} }

This is not claiming that attention is formally a stochastic process during ordinary forward inference; it is an extremely useful mathematical interpretation of the weighted aggregation.

0.5.31 The deep connection to RL

RL:

J(\theta)=E_{\tau\sim\pi_\theta}[R(\tau)]

means:

\boxed{ \text{average reward over trajectories sampled from the policy} }

So attention and RL both use the same fundamental mathematical structure:

\boxed{ \sum_i (\text{weight}_i)(\text{quantity}_i) }

The difference is what the weights represent.

Attention

Weights:

a_{ij}

represent learned attention coefficients over positions.

RL

Weights:

\pi_\theta(\tau)

represent the probability that the policy generates a trajectory.

This is one of the most useful unifying observations in this curriculum.

0.5.32 One equation to remember

At the highest level:

\boxed{ E[f(X)] = \text{probability-weighted average of }f(X) }

Everything else is an application.

0.5.35 VERY IMPORTANT distinctions

Do not confuse:

E[X]

with:

P(X)

Probability tells us:

how likely an outcome is.

Expectation tells us:

the probability-weighted average of a quantity.

Likewise don't confuse:

E[X]

with:

E[X^2]

or:

E[X\mid Y]

These answer different questions.

0.5.36 One complete example

Suppose an LLM has three possible responses:

y_1,y_2,y_3

with probabilities:

\pi(y_1)=0.2
\pi(y_2)=0.5
\pi(y_3)=0.3

Suppose rewards are:

R(y_1)=10
R(y_2)=4
R(y_3)=-2

Then:

E[R] = 0.2(10)+0.5(4)+0.3(-2)
=3.4

The RL objective says:

Adjust the model so that responses with high reward become more likely, thereby increasing expected reward.

That single example is the conceptual precursor to:

\boxed{ \text{policy gradient} \rightarrow \text{PPO} \rightarrow \text{GRPO} }
