Motivation

Separate exact divergence, sampled estimator values and gradient contracts before attributing an observed RL collapse to KL.

Prerequisites

  • KL support and expectation; group-centered advantages.
  • Policy/reference/old-policy distinctions and response masks.

Notation and units

  • q: current student/policy; p: reference distribution.
  • k3=p/q-1-ln(p/q).
  • A_i=(r_i-mean(r))/(population_std(r)+epsilon).

Assumptions

  • Positive common support and samples drawn from q for the stated k3 expectation identity.
  • Nonnegative KL coefficient and reward maximization convention. Group normalization uses population standard deviation.

Step-by-step derivation

  1. Compute exact KL as sum q_i*ln(q_i/p_i). An individual sampled log ratio can be negative while the weighted sum is nonnegative.
  2. Let u=p_i/q_i. k3=u-1-ln(u)>=0 by log(u)<=u-1. Sum q_i*(u-1)=sum p_i-sum q_i=0, hence E_q[k3]=KL(q||p).
  3. Samples from an old policy change the sampling measure; exact current-policy expectation then requires an appropriate ratio. Matching values does not establish gradients after stop-gradient operations.
  4. If rewards have no gradient, maximizing E_q[r]-beta*KL(q||p), beta>0, moves toward the reference, whose distribution need not be uniform.
  5. All equal group rewards give zero centered numerators, so epsilon makes the normalized advantages zero rather than undefined. A constant format bonus cancels too.
  6. Per-token versus summed response KL changes how lengths affect the loss. Inspect sign, masks, sum/mean units and coefficients before treating length or collapse as a universal property.

    A single sampled log-probability difference must not be mistaken for a nonnegative exact divergence.

    Prerequisites: Entropy, cross-entropy, KL, and support, Clipped surrogate and advantage sign

    Notation and assumptions

    Current categorical q, reference p, full common support. Samples must be drawn from q for the stated expectations. k3=p/q-1-ln(p/q).

    Derivation and mechanism

    1. Exact KL sums q ln(q/p) over the complete support.
    2. A sampled ln(q/p) can be negative.
    3. k3 is nonnegative per outcome; its q-expectation equals reverse KL under the declared support assumptions.
    k_3=e^{\log p-\log q}-1-(\log p-\log q)

    Worked example

    q=[.8,.2],p=[.5,.5]. At outcome1, ln(.2/.5)<0, although exact KL is positive. The checker sums both q-weighted k3 values and verifies equality to the exact KL.

    Limitations

    • Old-policy samples require appropriate importance treatment.
    • Detached ratios, KL coefficients and length normalization change gradients; matching value expectations is not proof of matching gradients.

    Connections to later concepts

    • K02 uses reverse KL as the distillation objective; a KL regularizer in RL has a different role and reduction contract.

    Separate the reported failure from the mathematical regularizer

    Slide 29 reports collapse shortly after step 50 in one training setup, and slide 30 lists possible remedies and work that omits KL for math RL. Retain that experimental observation while checking the assumptions behind its explanation. A positive regularization coefficient penalizing KL(q‖p_ref) pushes toward p_ref at its exact optimum; it does not generally push toward a uniform distribution. Uniform output requires additional assumptions or implementation behavior.

    J(\theta)=\mathbb E_{q_\theta}[r]-\beta\mathrm{KL}(q_\theta\|p_{\mathrm{ref}}),\quad\beta\ge0

    If reward contributes no gradient, maximizing this J minimizes divergence from the reference. A wrong sign, a biased sampled estimator, absent masks, or mismatched sum/mean normalization can behave differently. Likewise a correctly signed summed penalty can grow with response length and penalize long outputs; a universal assertion that KL incentivizes longer outputs cannot be inferred without the implementation’s sign and units.

    Zero group variation removes the relative reward signal

    A_i=\frac{r_i-\bar r}{\sigma_r+\varepsilon}

    For [0,0,0,0], every numerator is zero and every advantage is zero. For [1,1,0,0], population mean=.5, standard deviation=.5, and advantages are approximately [1,1,−1,−1]. A constant format bonus added to every response leaves all advantages zero; it helps only if the resulting total rewards differ within the group. Choose variance/epsilon conventions explicitly, and distinguish no relative learning signal from an undefined computation.

    Before dropping KL, compare its magnitude with the reward objective, inspect per-token versus per-response averaging, verify response-only masks and importance weighting, and inspect generated lengths and entropy. These checks explain the slide’s recommendations without converting a math-RL observation into a universal rule for all RLHF. The named newer systems remain source-reported examples here; their separate training implementations are not independently reproduced.

    """Toy voting, verifier selection, GRPO normalization, and source arithmetic."""
import math
from collections import Counter

def advantages(rewards, epsilon=1e-8):
    mean = sum(rewards) / len(rewards)
    std = math.sqrt(sum((r-mean)**2 for r in rewards) / len(rewards))
    return [(r-mean)/(std+epsilon) for r in rewards]

def main():
    assert advantages([0,0,0,0]) == [0,0,0,0]
    a = advantages([1,1,0,0])
    assert max(abs(x-y) for x,y in zip(a,[1,1,-1,-1])) < 1e-7
    assert math.isclose((151.4 - 71.8)/151.4*100, 52.57595772787319)
    total, answerable, unanswerable = 18579, 13283, 5292
    assert total - (answerable + unanswerable) == 4
    # Fictional answers: majority voting can select a wrong answer.
    answers = ['41','41','42']
    majority = Counter(answers).most_common(1)[0][0]
    verified = [x for x in answers if x == '42']
    assert majority == '41' and verified == ['42']
    assert math.isclose(1 - (1 - 0.4)**4, 0.8704)
    print('GRPO advantages:', a)
    print('GPTQ slide reduction:', round((151.4-71.8)/151.4*100,4), '%')
    print('IndicQA discrepancy:', total-answerable-unanswerable)
    print('majority:', majority, 'verifier-selected:', verified[0])
    print('independent toy probability of any correct sample:', 0.8704)

if __name__ == '__main__':
    main()
