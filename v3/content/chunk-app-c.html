Appendix C — Step 1 Mathematical Cheatsheet (the in-chat formula map)

The formula map for Part 1 (Transformers), as written in the chat before the Step 1 lessons began. It lists, section by section, every formula the Part 1 lessons derive.

This is not yet the deep teaching.

This is the formula map of the entire Step 1, so that before we start explaining Slide 1.1, you can see where the mathematics is going.

The Transformer slide deck itself defines the decoder-only Transformer as attention between positions, MLP processing within positions, additive residual updates, and a causal mask.

Raschka’s book gives us the much richer first-principles implementation path through tokenization, attention, causal masking, MHA, Transformer blocks, and GPT.

1. TOKEN SEQUENCE

Start with text:

\text{text} \rightarrow \text{tokens} \rightarrow (x_1,x_2,\ldots,x_n).

Each token is represented by an ID:

x_t\in\{0,1,\ldots,|V|-1\}.

where:

  • V = vocabulary
  • |V| = vocabulary size
  • n = sequence length.

2. TOKEN EMBEDDING

Embedding matrix:

W_E\in\mathbb R^{|V|\times d}.

Token x_t selects one row:

e_t=W_E[x_t].

Stacking all token embeddings:

X= \begin{bmatrix} e_1^\top\\ e_2^\top\\ \vdots\\ e_n^\top \end{bmatrix} \in \mathbb R^{n\times d}.

So:

\boxed{ \text{Token ID} \rightarrow \text{row lookup} \rightarrow d\text{-dimensional vector} }

This is exactly the embedding construction used in the Transformer slides.

3. POSITIONAL INFORMATION

Because self-attention alone does not inherently encode ordering, positional information is added.

Simplified formulation:

P\in\mathbb R^{n\times d}
X\leftarrow X+P.

Therefore:

X_{t} = e_t+p_t.

The slide also identifies RoPE as the modern alternative to this simple additive formulation. (Source: transformers-slides)

4. RESIDUAL STREAM

For one token:

x\in\mathbb R^d.

Attention update:

x' = x+\operatorname{Attention}(\operatorname{Norm}(x)).

MLP update:

x'' = x'+\operatorname{MLP}(\operatorname{Norm}(x')).

For all tokens:

X\in\mathbb R^{n\times d}.

The conceptual structure is:

\boxed{ X \rightarrow \text{Norm} \rightarrow \text{Attention} \rightarrow + X \rightarrow \text{Norm} \rightarrow \text{MLP} \rightarrow + }

The slides describe this residual stream as the shared representation into which each sub-layer writes its contribution.

5. QUERY, KEY, VALUE

Learned matrices:

W_Q\in\mathbb R^{d\times d_k}
W_K\in\mathbb R^{d\times d_k}
W_V\in\mathbb R^{d\times d_v}.

Projection:

Q=XW_Q
K=XW_K
V=XW_V.

Therefore:

Q,K\in\mathbb R^{n\times d_k}
V\in\mathbb R^{n\times d_v}.

This is directly represented in the slides, and Raschka's implementation walks through the same computation explicitly. (Source: transformers-slides; Build a Large Language Model (From Scratch))

6. QUERY-KEY SIMILARITY

For token i attending to token j:

s_{ij} = q_i^\top k_j.

Matrix form:

S=QK^\top.

Dimensions:

(n\times d_k)(d_k\times n) = n\times n.

Thus:

\boxed{ S\in\mathbb R^{n\times n} }

and

S_{ij}=q_i^\top k_j.

7. WHY SCALE BY \sqrt{d_k}?

The scaled score is:

S= \frac{QK^\top}{\sqrt{d_k}}.

The basic statistical intuition is:

q^\top k = \sum_{r=1}^{d_k}q_rk_r.

Under approximately independent, zero-mean, unit-variance components:

\operatorname{Var}(q^\top k) \approx d_k.

Therefore:

\operatorname{Std}(q^\top k) \approx\sqrt{d_k}.

So:

\frac{q^\top k}{\sqrt{d_k}}

keeps the score scale much more stable as d_k increases.

The book explicitly explains the purpose as preventing large dot products from pushing softmax toward saturation and producing very small gradients. (Source: Build a Large Language Model (From Scratch))

8. CAUSAL MASK

Mask:

M_{ij} = \begin{cases} 0,&j\le i\\ -\infty,&j>i. \end{cases}

Therefore:

S' = \frac{QK^\top}{\sqrt{d_k}}+M.

The future positions become:

e^{-\infty}=0.

Hence their attention probability becomes zero.

This is the mathematical mechanism by which the decoder prevents looking into the future. (Source: transformers-slides)

9. SOFTMAX ATTENTION WEIGHTS

For each row:

A_{ij} = \frac{e^{S'_{ij}}} {\sum_{j'=1}^{n}e^{S'_{ij'}}}.

Therefore:

A_{ij}\ge0

and

\sum_jA_{ij}=1.

Thus:

A_i

is a probability distribution over the tokens that token i is allowed to attend to.

10. CONTEXT VECTOR

For token i:

o_i = \sum_{j=1}^{n} A_{ij}v_j.

Matrix form:

O=AV.

Dimensions:

(n\times n)(n\times d_v) = n\times d_v.

Thus:

\boxed{ O\in\mathbb R^{n\times d_v} }

Raschka's book explicitly implements the context vector as the attention-weighted combination of value vectors. (Source: Build a Large Language Model (From Scratch))

11. COMPLETE SINGLE-HEAD ATTENTION

Put everything together:

\boxed{ \operatorname{Attention}(Q,K,V) = \operatorname{softmax} \left( \frac{QK^\top}{\sqrt{d_k}}+M \right)V }

This is the central equation of Step 1.

12. MULTI-HEAD ATTENTION

For head h:

Q_h=XW_Q^{(h)}
K_h=XW_K^{(h)}
V_h=XW_V^{(h)}.

Then:

H_h = \operatorname{Attention}(Q_h,K_h,V_h).

Concatenate:

H = \operatorname{Concat} (H_1,H_2,\ldots,H_H).

Output projection:

O=HW_O.

Therefore:

\boxed{ \operatorname{MHA}(X) = \operatorname{Concat} (\operatorname{head}_1,\ldots,\operatorname{head}_H) W_O }

The Transformer slides and Raschka implementation agree on this structure. (Source: transformers-slides; Build a Large Language Model (From Scratch))

13. HEAD DIMENSION

If model width is d and there are H heads:

d_k=d_v=\frac dH.

Thus:

H\cdot d_k=d.

Example:

d=768,\qquad H=12

gives:

d_k=64.

14. LAYER NORMALIZATION

For one token vector:

x=(x_1,\ldots,x_d).

Mean:

\mu = \frac1d\sum_{i=1}^{d}x_i.

Variance:

\sigma^2 = \frac1d \sum_{i=1}^{d}(x_i-\mu)^2.

Normalize:

\hat x_i = \frac{x_i-\mu} {\sqrt{\sigma^2+\epsilon}}.

Learned affine transformation:

\boxed{ \operatorname{LN}(x) = \gamma\odot\hat x+\beta }

where:

\gamma,\beta\in\mathbb R^d.

Raschka's implementation computes the mean and variance over the final embedding dimension and learns scale and shift parameters. (Source: Build a Large Language Model (From Scratch))

15. RMSNorm

The Transformer slide also mentions RMSNorm.

\operatorname{RMS}(x) = \sqrt{\frac1d\sum_i x_i^2+\epsilon}.

Then:

\boxed{ \operatorname{RMSNorm}(x) = \gamma\odot \frac{x}{\operatorname{RMS}(x)} }

Difference:

\text{LayerNorm} = \text{center + scale}

while

\text{RMSNorm} = \text{scale without mean-centering}.

16. FEED-FORWARD NETWORK

The slide gives:

\boxed{ \operatorname{FFN}(x) = W_2\phi(W_1x+b_1)+b_2 }

with:

x\in\mathbb R^d
W_1\in\mathbb R^{d_{ff}\times d}
W_2\in\mathbb R^{d\times d_{ff}}.

Typically:

d_{ff}=4d.

The crucial distinction:

\boxed{ Attention =\text{mix information across positions} }
\boxed{ FFN =\text{nonlinear processing within each position} }

which the Transformer deck emphasizes. (Source: transformers-slides)

17. GELU

Exact GELU:

\boxed{ \operatorname{GELU}(x) = x\Phi(x) }

where:

\Phi(x) = \frac1{\sqrt{2\pi}} \int_{-\infty}^{x} e^{-t^2/2}\,dt.

Common approximation used by GPT-style models:

\boxed{ \operatorname{GELU}(x) \approx \frac12x \left[ 1+ \tanh \left( \sqrt{\frac2\pi} (x+0.044715x^3) \right) \right] }

Raschka's book explicitly gives both the probabilistic definition and the GPT-2-style approximation. (Source: Build a Large Language Model (From Scratch))

18. PRE-LAYER-NORM TRANSFORMER BLOCK

Attention sub-block:

h = x+ \operatorname{MHA}(\operatorname{LN}(x)).

FFN sub-block:

y = h+ \operatorname{FFN}(\operatorname{LN}(h)).

Therefore:

\boxed{ y = h+ \operatorname{FFN}(\operatorname{LN}(h)) }

with:

h= x+ \operatorname{MHA}(\operatorname{LN}(x)).

Raschka's implementation explicitly uses this Pre-LN ordering. (Source: Build a Large Language Model (From Scratch))

19. STACK L BLOCKS

X^{(0)} = \text{embedding + position}.

For layer l:

X^{(l)} = \operatorname{Block}_l(X^{(l-1)}).

Then:

X^{(L)} = \operatorname{Block}_L \circ\cdots\circ \operatorname{Block}_1 (X^{(0)}).

The slide summarizes this simply as:

\boxed{\text{same Transformer block repeated }L\text{ times}}

(Source: transformers-slides)

20. FINAL NORMALIZATION

H= \operatorname{LN}(X^{(L)}).

Dimensions remain:

H\in\mathbb R^{n\times d}.

21. UNEMBEDDING

Vocabulary projection:

W_U\in\mathbb R^{d\times|V|}.

Then:

\boxed{ Z=HW_U }

with:

Z\in\mathbb R^{n\times|V|}.

Each row:

z_t\in\mathbb R^{|V|}

contains one raw score/logit for every vocabulary token.

The Transformer slides describe this as the mirror operation to the embedding lookup. (Source: transformers-slides)

22. LOGITS → PROBABILITIES

For token i:

p_i = \frac{e^{z_i}} {\sum_j e^{z_j}}.

Thus:

\boxed{ p_t = \operatorname{softmax}(z_t) }

and:

p_t(i) = P(x_{t+1}=i\mid x_{\le t}).

This is where Step 1 hands off to Step 2: Decoding.

23. AUTOREGRESSIVE LANGUAGE MODEL PROBABILITY

For a sequence:

P_\theta(x_1,\ldots,x_n) = \prod_{t=1}^{n} P_\theta(x_t|x_{<t}).

This chain rule will later become extremely important in:

  • decoding
  • knowledge distillation
  • RL
  • GRPO.

24. NEXT-TOKEN LOSS

For target x_t:

L_t = -\log P_\theta(x_t|x_{<t}).

Average:

\boxed{ L = -\frac1n \sum_{t=1}^{n} \log P_\theta(x_t|x_{<t}) }

This is the language-model negative log-likelihood / cross-entropy objective.

The Transformer slides formulate training exactly in terms of next-token probabilities and average negative log probability.

25. ONE-HOT CROSS-ENTROPY FORM

If the target distribution is one-hot y:

L_t = -\sum_{v\in V} y_{t,v} \log p_{t,v}.

Since:

y_{t,v^*}=1

only for the correct token:

L_t = -\log p_{t,v^*}.

This becomes the exact bridge to MiniLLM's soft-target distillation later.

26. PARAMETER COUNT — CORE TRANSFORMER

For one attention projection:

W_Q:d\times d

contains:

d^2

parameters.

Four attention matrices:

W_Q,W_K,W_V,W_O

give approximately:

4d^2.

FFN:

W_1:d_{ff}\times d
W_2:d\times d_{ff}

giving:

2dd_{ff}.

If:

d_{ff}=4d,

then:

2dd_{ff}=8d^2.

Therefore the FFN has roughly twice the parameter count of the four attention projections:

\boxed{ 8d^2:4d^2=2:1 }

which is also visible in Raschka's implementation/analysis. (Source: Build a Large Language Model (From Scratch))

27. ATTENTION COMPUTATIONAL COMPLEXITY

The central matrix:

QK^\top

costs approximately:

O(n^2d_k).

Then:

AV

costs approximately:

O(n^2d_v).

So the dominant attention complexity behaves approximately as:

\boxed{O(n^2d)}

with respect to sequence length.

This becomes extremely important when we reach:

\text{KV cache} \rightarrow \text{MQA} \rightarrow \text{GQA} \rightarrow \text{MLA}.

That is exactly why the DeepSeek book makes KV cache its first technical chapter after introducing the standard Transformer foundation.

28. THE ENTIRE STEP 1 IN ONE EQUATION

Everything eventually collapses into:

\boxed{ P_\theta(x_{t+1}|x_{\le t}) = \operatorname{softmax} \left[ W_U \,\operatorname{Block}^{(L)} \left( \cdots \operatorname{Block}^{(1)} (X+P) \right)_t \right] }

where every block contains:

\boxed{ \operatorname{Block}(x) = h+ \operatorname{FFN}(\operatorname{Norm}(h)) }

and

\boxed{ h= x+ \operatorname{MHA}(\operatorname{Norm}(x)) }

and each head contains:

\boxed{ \operatorname{Attention} = \operatorname{softmax} \left( \frac{QK^\top}{\sqrt{d_k}} +M \right)V }

with:

Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V.

For a single sequence:

For a batch:

X\in\mathbb R^{B\times n\times d}.

Raschka's implementation explicitly works with this three-dimensional batch representation, including the transformations into multi-head shapes. (Source: Build a Large Language Model (From Scratch))
