Motivation

Read each reported result with its source version, metric, denominator and ablation label attached, and implement inspectable versions of calibration and diversity statistics.

Prerequisites

  • Percent versus percentage-point changes.
  • Prediction confidence, reference metrics and n-gram counting.

Notation and units

  • ECE=sum_b(n_b/N)*abs(accuracy_b-confidence_b).
  • Distinct-n=unique within-response n-grams / all within-response n-grams.
  • Validation Rouge-L row labels refer specifically to MiniLLM v4 Table4.

Assumptions

  • ECE bins are [low,high), with the final bin including1; confidence and correctness arrays are paired.
  • Distinct4 aggregation is across a corpus without crossing response boundaries. A zero denominator returns an undefined statistic, not a fabricated zero.

Step-by-step derivation

  1. Assign each confidence to exactly one bin. Count n_b, then compute its mean confidence and fraction correct. Weight each absolute gap by n_b/N.
  2. Extract contiguous four-token tuples separately within each response. Count total tuples and distinct tuples, then divide. Short responses contribute none.
  3. Ablation changes compare the same metric and experiment setting. Subtract removed-component row from the full27.4 row; this gives a score-point drop, not a universal component ranking.
  4. The supplied slide26 model rows must be read with their student/teacher family labels. ROUGE-L, human preference, calibration and distinct4 measure different properties and should not be averaged as interchangeable accuracy measures.

\mathrm{ECE}=\sum_{b=1}^{B}\frac{|I_b|}{N}\left|\mathrm{acc}(I_b)-\mathrm{conf}(I_b)\right|

Here I_b is a confidence bin, N the total evaluated predictions, accuracy the fraction correct, and confidence the bin’s mean predicted confidence. Derived toy example: two equal-size bins with accuracies [.8,.5] and confidences [.9,.7] give ECE=.5(.1)+.5(.2)=.15. Distinct-4 divides unique generated 4-grams by total generated 4-grams under a declared aggregation scheme; short outputs need explicit handling. Neither statistic identifies the complete causal explanation for a result.
