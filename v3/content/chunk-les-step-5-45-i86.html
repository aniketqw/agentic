Notation and units

Mastery answers and retained exercise context

  1. Are displayed4/1labels zero-based? No; they are one-based E4/E1names; actual indices3/0.
  2. Why count gates and slots separately? Loads measure discrete assignment count; gates weight expert outputs.
  3. Are all sixteen gates separate outputs? No; two expert contributions accumulate for each of the eight token rows.
  4. Can rounding change top-k? Yes; especially ties and near-ties. Freeze and report the tie breaker.
  5. What are expert1/2update directions for loads900/1100withmean1024? Positive(124/1024)andnegative(−76/1024), respectively.
  6. Inherited exercise 5.45.42 Exam-level question 1: Suppose: B=8,\quad S=1024, N=64,\quad k=8. Find: Number of tokens 8\times1024 = \boxed{8192}. Router shape \boxed{8192\times64}. Step 5.45 — Full 8-Token × 4-Expert Routing Trace

Plan node: A2 · chat order #86

↩ Back to main text: Step 1.10 — Position-Wise Feed-Forward Network (FFN / MLP)

Now we will do the entire routing computation by hand.

This is the step where the previously separate ideas become one concrete calculation:

\boxed{ X \rightarrow \text{router logits} \rightarrow +b \rightarrow Top\text{-}K \rightarrow \text{gates} \rightarrow \text{dispatch} \rightarrow \text{expert outputs} \rightarrow \text{weighted aggregation} \rightarrow \text{shared path} \rightarrow \text{residual} }

The source's implementation follows this same sequence: router → bias → Top-K → softmax → sparse dispatch → weighted accumulation. (Source: Build a DeepSeek Model (From Scratch))

The numerical values below are our illustrative example, chosen so every calculation can be done explicitly. They are not claimed to be DeepSeek's learned weights.

5.45.1 Step 1 — Create 8 token representations

Let:

B=2,\qquad S=4,\qquad D=2.

Therefore:

T=B\times S=8

tokens.

We'll use:

X= \begin{bmatrix} 1&0\\ 0&1\\ 1&1\\ 2&1\\ 1&2\\ 2&0\\ 0&2\\ 2&2 \end{bmatrix}

So:

\boxed{ X\in\mathbb R^{8\times2} }

after flattening.

Originally it came from:

2\times4\times2.

5.45.2 Step 2 — Define the router

Use:

N=4

routed experts.

Let the mathematical router matrix be:

W_R= \begin{bmatrix} 1&0&1.2&2\\ 0&1&1.5&-0.5 \end{bmatrix}.

Thus:

W_R\in\mathbb R^{2\times4}.

The source describes the same concept using an input matrix multiplied by a learned routing matrix to produce the expert-selector/logit matrix. (Source: Build a DeepSeek Model (From Scratch))

5.45.3 Step 3 — Compute router logits

We calculate:

L=XW_R.

For token 1:

x_1=[1,0].

Therefore:

[1,0] \begin{bmatrix} 1&0&1.2&2\\ 0&1&1.5&-0.5 \end{bmatrix}

gives:

\boxed{[1,0,1.2,2]}.

5.45.31 Important source-code nuance about the residual

There is a small but important implementation distinction in the source that you should understand.

In the chapter-4 complete MoE implementation, the final return is:

return x + shared_out + routed_out

(Source: Build a DeepSeek Model (From Scratch))

But in the later TransformerBlock implementation, the block itself does:

x = x + self.feed_forward(self.norm2(x))

so the MoE implementation returns the transformation while the Transformer block owns the residual connection.

These are two ways of organizing the same residual structure.

So don't accidentally implement:

x+\text{MoE}(x)

inside the MoE and then again add another residual around the whole MoE in a way that duplicates the residual.

The important architectural structure is:

\boxed{ \text{residual around the MoE sub-block} }.

5.45.45 Exam-level question 4

Suppose:

T=5000,\quad N=20,\quad k=4.

Total assignments:

5000\times4 = \boxed{20,000}.

Ideal average:

20,000/20 = \boxed{1000}.

If one expert gets:

1400

assignments:

v= \frac{1000-1400}{1000} = \boxed{-0.4}.

Therefore:

\boxed{\text{its bias decreases}}.
