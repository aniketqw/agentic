Motivation

Interpret evidence without converting a benchmark comparison into an unsupported claim about intelligence or parameter counts.

Prerequisites

  • Autoregressive conditional likelihood
  • SFT response masking
  • Data validation and held-out evaluation

Notation and units

  • x prompt; y=(y1…ym) retained teacher response
  • L=-sum log Pstudent(yt|x, y<t)/m
  • N samples; k candidates/prompt; p candidate acceptance

Assumptions

  • Synthetic data is explicitly distinguished from ground truth
  • Reported DeepSeek experiments are historical source results, not reruns
  • IID acceptance only for binomial toy calculations

  1. Keep checkpoint identities, prompt format, decoding settings, dataset split and metric definitions attached to each score.
  2. For scores A, B, difference A-B is percentagepoints; relative gain100(A-B)/B is percent.

Step 4.8 — Empirical Evidence: Does Distillation Actually Work?

Plan node: I5 · chat order #40

Up to now, we have derived the mechanisms.

Now we ask the scientific question:

\boxed{\text{Does adding the teacher actually improve the student?}}

The supplied Build a DeepSeek Model chapter answers this in two layers:

  1. a controlled teacher/student toy experiment for classical KD;
  2. the much more important DeepSeek-R1 distilled-model results at scale. (Source: Build a DeepSeek Model (From Scratch))

We will go from the small experiment first, then move to the real DeepSeek results.

1. The controlled experiment

The chapter proposes training the same student architecture in three different ways:

\boxed{\text{Baseline}}
\boxed{\text{Distillation}}
\boxed{\text{Teacher}}

This is important because we want to isolate the effect of the training method rather than accidentally changing the model architecture. (Source: Build a DeepSeek Model (From Scratch))

2. Experiment A — Baseline student

The student receives only:

(x,y)

where:

  • x = input
  • y = ground-truth label.

The loss is:

\boxed{ L_{\text{baseline}} = CE(z_S,y) }

This corresponds to Attempt #1.

The teacher is completely absent.

3. Experiment B — Distilled student

Now the same student architecture receives:

\text{ground truth}

plus:

\text{teacher soft targets}.

Using the chapter's complete loss:

\boxed{ L= \alpha L_{\text{hard}} + (1-\alpha)T^2KL(P_T^T\|P_S^T) }

with the chapter's example:

T=3, \qquad \alpha=0.3.

So the student is learning from both:

\boxed{\text{correct answer}}

and:

\boxed{\text{teacher's probability structure}}.

(Source: Build a DeepSeek Model (From Scratch))

Correction: Teacher performance is a practical reference, not a formal upper bound on student held-out accuracy. Hard labels, regularization and different pretraining can let a student surpass the teacher on a particular metric.

Complete grounded review

4. Experiment C — Teacher upper bound

We also evaluate the teacher itself.

Why?

Because otherwise a student score is difficult to interpret.

Suppose:

\text{student}=80\%.

Is that good?

It depends.

If teacher is:

81\%

then the student is excellent.

If teacher is:

99\%

then there is still a large gap.

Therefore:

\boxed{ \text{teacher performance = practical upper reference} }

The chapter explicitly calls this the upper bound in the controlled comparison. (Source: Build a DeepSeek Model (From Scratch))

5. What does the source report?

The chapter says the same student architecture shows the following consistent pattern:

\boxed{ \text{Distilled student} > \text{Hard-label baseline} }

but:

\boxed{ \text{Distilled student} < \text{Teacher} }

So:

Teacher
   ↑
   |
Distilled Student
   ↑
   |
Hard-label Baseline

This is exactly the behavior we would hope for.

The chapter says the advantage is particularly pronounced on ambiguous or difficult examples, while the difference is smaller on easy, unambiguous examples. (Source: Build a DeepSeek Model (From Scratch))

6. Why should the gain be larger on ambiguous examples?

This directly follows from what we learned about dark knowledge.

Suppose the teacher sees an easy example:

P_T=[0.99,0.005,0.003,0.002].

There isn't much useful uncertainty to transfer.

But suppose the teacher sees a difficult example:

P_T=[0.45,0.35,0.15,0.05].

Now the teacher communicates much more structure:

\text{class 1 is best}

but:

\text{class 2 is also quite plausible}.

The student learns more from this richer distribution.

The source explicitly identifies this as the situation where dark knowledge gives the largest benefit. (Source: Build a DeepSeek Model (From Scratch))

7. This gives us a very important principle

\boxed{ \text{Distillation gain} \approx \text{value of teacher's additional information} }

When the teacher has nothing nuanced to add:

\text{gain small}.

When the teacher encodes complicated relationships:

\text{gain large}.

This is the practical meaning of dark knowledge.

8. Why the distilled student does not reach the teacher

Suppose:

\theta_T

represents a huge teacher parameter space.

The student has:

\theta_S

with much smaller capacity.

Even if we provide excellent supervision:

\theta_S

cannot necessarily represent every behavior encoded in:

\theta_T.

Therefore:

\boxed{ \text{compression is powerful but lossy} }

The source explicitly identifies this as the capacity gap. (Source: Build a DeepSeek Model (From Scratch))

9. Capacity gap

Define conceptually:

\boxed{ \text{capacity gap} = \text{teacher capability} - \text{student's representational capacity} }

This is not intended as a literal scalar formula in the source; it is the intuition.

A student that is too small may have difficulty absorbing:

\text{all reasoning strategies} + \text{all language patterns} + \text{all domain knowledge}.

The result can be uneven performance across tasks. (Source: Build a DeepSeek Model (From Scratch))

10. This explains an important DeepSeek result

The smallest student is:

1.5B.

Teacher:

671B.

So:

\frac{671}{1.5} \approx447.3.

That means the teacher has roughly:

\boxed{447\times}

the parameter count.

Yet the 1.5B student still acquires substantial reasoning capability.

That is why the source describes the result as approximately a 450× compression in parameter count. (Source: Build a DeepSeek Model (From Scratch))

11. Now move to the actual DeepSeek-R1 results

The source reports:

\boxed{ \text{DeepSeek-R1-Distill-Qwen-1.5B} }

AIME 2024:

\boxed{28.9\%}

while GPT-4o is reported at:

\boxed{9.3\%}.

(Source: Build a DeepSeek Model (From Scratch))

This is the headline result in the supplied chapter.

12. Numerical — absolute improvement over GPT-4o

28.9-9.3 = \boxed{19.6}

percentage points.

So the distilled 1.5B model exceeds the reported GPT-4o AIME score by:

\boxed{19.6\text{ percentage points}}.

13. Numerical — relative score ratio

\frac{28.9}{9.3} \approx3.108.

So the reported AIME score is about:

\boxed{3.1\times}

the GPT-4o score.

This is a benchmark-score ratio, not a claim that the student is “3.1 times smarter.”

14. Parameter ratio versus benchmark ratio

This distinction is important.

The source discusses the student as roughly:

450\times

smaller by parameter count.

But the performance ratio on AIME relative to GPT-4o is only around:

3.1\times.

These are measuring entirely different quantities.

Therefore:

\boxed{ \text{parameter compression ratio} \neq \text{performance ratio} }

16. First major observation: performance generally scales with student size

Consider AIME:

28.9 \rightarrow 55.5 \rightarrow 69.7 \rightarrow 72.6

as Qwen student size increases:

1.5B \rightarrow 7B \rightarrow 14B \rightarrow 32B.

The source describes this as smooth scaling. (Source: Build a DeepSeek Model (From Scratch))

17. Numerical — scaling increments

From 1.5B to 7B:

55.5-28.9 = \boxed{26.6}

points.

From 7B to 14B:

69.7-55.5 = \boxed{14.2}

points.

From 14B to 32B:

72.6-69.7 = \boxed{2.9}

points.

Notice the diminishing gains.

18. Why are gains diminishing?

The supplied chapter does not present a formal scaling-law equation here, so we should not invent one.

But the reported numbers show:

\boxed{ \text{larger student helps, but each additional size increment produces smaller gains} }

in this reported series.

This is an empirical observation from the table, not a universal law.

Correction: Math-versus-code scores use different benchmarks. Their uneven reported performance does not establish that math is intrinsically more compressible.

Complete grounded review

19. Second major observation: math compresses especially well

Look at the 1.5B model:

\text{MATH-500}=83.9\%.

But:

\text{LiveCodeBench}=16.9\%.

Huge difference.

The source explicitly interprets math as a particular strength of these distilled models and coding as the weakest area for the smallest student. (Source: Build a DeepSeek Model (From Scratch))

20. Numerical — 1.5B math vs coding

83.9-16.9 = \boxed{67.0}

percentage points.

So the 1.5B student's reported math score exceeds its coding score by:

\boxed{67\text{ points}}.

21. What does this tell us about distillation?

It tells us:

\boxed{ \text{distillation quality is task-dependent} }

You cannot assume:

\text{excellent math transfer} \Rightarrow \text{equally excellent coding transfer}.

The student's capacity interacts with the complexity and breadth of the domain.

The chapter explicitly links the coding weakness of the tiny model to its limited capacity for the large space of syntax, APIs, and architectural patterns. (Source: Build a DeepSeek Model (From Scratch))

22. Third major observation: teacher still has a clear lead

Teacher AIME:

79.8\%.

Best reported distilled student:

72.6\%.

Difference:

\boxed{7.2\text{ percentage points}}.

So even a 32B student gets close, but does not fully reproduce the teacher.

(Source: Build a DeepSeek Model (From Scratch))

23. Numerical — fraction of teacher score

\frac{72.6}{79.8}\times100 \approx \boxed{91.0\%}.

Again, this means:

the benchmark score is about 91% of the teacher's score.

It does not mean that the 32B model has 91% of the teacher's knowledge.

24. Fourth major observation: architecture/base model matters

Compare:

\text{Qwen-7B}=55.5\%

with:

\text{Llama-8B}=50.4\%.

Although the Llama model is slightly larger:

50.4<55.5.

The source highlights that Qwen-based students consistently outperform comparable Llama-based variants in these results, and emphasizes the importance of the underlying base model. (Source: Build a DeepSeek Model (From Scratch))

25. Numerical — Qwen-7B vs Llama-8B

55.5-50.4 = \boxed{5.1}

percentage points.

So an 8B model is not automatically superior to a 7B model.

26. Why does the base model matter?

The student already contains pretrained knowledge before distillation.

Let:

S_0=\text{pretrained student}.

Distillation produces:

S_1.

So:

\boxed{ S_1=f(S_0,\text{teacher data}) }

Conceptually, not a literal closed-form function.

If:

S_0

already has useful mathematical representations, it may absorb teacher reasoning more effectively.

The source makes this point explicitly. (Source: Build a DeepSeek Model (From Scratch))

27. Fifth observation: distillation can beat direct RL on the same architecture

This is arguably the most important experiment.

DeepSeek compares:

\boxed{\text{Qwen2.5-32B trained by large-scale RL}}

against:

\boxed{\text{Qwen2.5-32B trained by distillation}}

on the same architectural base.

The source reports that the RL setup used:

>10,000

48. Final exam-ready answers

Why does distillation outperform hard-label training?

Because the teacher provides richer information about alternative predictions and their relationships, allowing the student to learn structure that hard labels do not explicitly reveal. (Source: Build a DeepSeek Model (From Scratch))

Why does distillation not exactly match the teacher?

Because the student has limited representational capacity; the capacity gap causes some teacher knowledge to be lost. (Source: Build a DeepSeek Model (From Scratch))

Why can a 32B distilled model outperform a 32B RL-trained model?

Because the distilled student imitates successful reasoning strategies already discovered by a stronger teacher instead of having to rediscover them through exploration. (Source: Build a DeepSeek Model (From Scratch))

Why is the improvement task-dependent?

Because different domains require different amounts and types of knowledge; the source reports especially strong mathematical performance and weaker coding performance for the smallest student. (Source: Build a DeepSeek Model (From Scratch))

Can distillation create capabilities beyond the teacher?

The source's conclusion is generally no: it transfers existing teacher behavior efficiently, while surpassing the teacher's frontier generally requires stronger models or additional training such as RL. (Source: Build a DeepSeek Model (From Scratch))
