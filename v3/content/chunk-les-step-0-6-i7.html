Motivation

Extend scalar differentiation into the shapes used by Transformer projections and attention. Prerequisites: Step 0.1 dimensions and Step 0.4 reverse-mode calculus.

Prerequisites

  • Read the prerequisite chain stated in the original lesson and this review motivation.

Notation and units

  • G=\frac{\partial L}{\partial Y},\qquad \frac{\partial L}{\partial W}=X^\top G,\qquad\frac{\partial L}{\partial X}=GW^\top
  • \frac{\partial L}{\partial W_{kj}}=\sum_{b,t}X_{btk}G_{btj}
  • G_A=G_OV^\top,\qquad G_V=A^\top G_O
  • (G_S)_{ij}=A_{ij}\left((G_A)_{ij}-\sum_r A_{ir}(G_A)_{ir}\right)
  • G_Q=\frac{G_SK}{\sqrt{d_k}},\qquad G_K=\frac{G_S^\top Q}{\sqrt{d_k}}
  • G_X=G_QW_Q^\top+G_KW_K^\top+G_VW_V^\top

Assumptions

  • Scalar loss, row-oriented forward Y=XW, fixed independent X/W for each partial derivative. W is shared across token/batch positions, so parameter gradients sum those contributions. Any averaging factor in the loss is already present in the upstream gradient.

Step-by-step derivation

  1. Write Y_ij=sum_k X_ik W_kj. Then dL/dW_kj=sum_i (dL/dY_ij)X_ik, giving dW=XᵀG. Likewise dX=GWᵀ. These are contractions, not an inversion of XW.
  2. For the inherited half-sum squared error with X=[[1,2],[3,4]], W=I and target [[2,1],[4,3]], Y=X, loss=2, G=[[-1,1],[-1,1]] and dW=[[-4,4],[-6,6]]. Every entry was checked by finite differences.
  3. For the vector example L=w1²+3w2², the gradient is [2w1,6w2]. For the matrix weighted quadratic, coefficients [1,2;3,4] give entrywise gradient [2w11,4w12;6w21,8w22].
  4. At x=(3,4), the inherited Jacobian for [x1²+x2,x1x2] is [[6,1],[4,3]], independently checked for both outputs.
  5. The inherited parameter update gives [[0.98,2.05],[2.99,3.97]]. A 768×64 weight has 49,152 scalar entries and an equally shaped scalar-loss gradient.
  6. For a batch, flatten batch/token positions conceptually and sum X_btᵀG_bt over them. Bias gradients sum the upstream signal over the reused axes. Loss means, masks and unequal lengths must contribute their declared normalization.
  7. Complete attention backward application: with O=AV and half-sum MSE against T, G_O=O−T. Differentiate the product to obtain G_A=G_OVᵀ and G_V=AᵀG_O. For each row, contract the softmax Jacobian to get G_S,ij=A_ij(G_A,ij−sum_r A_ir G_A,ir). Masked entries have A_ij=0 and contribute zero.
  8. For scores QKᵀ/√d_k, G_Q=G_SK/√d_k and G_K=G_SᵀQ/√d_k. Multiply each projection gradient by Xᵀ to obtain the parameter gradient; sum query, key and value contributions for the input gradient.

Corrections and source qualifications

  • heading: 0.6.1; text: Tensor parameters contain scalar entries; scalar scale parameters can also exist. Matrix calculus generalizes scalar differentiation.

Mastery answers and retained exercise context

  1. Q1: ∇_W L has shape (512,64).
  2. Q2: Y and dL/dY have shape (10,64); dL/dW has shape (512,64).
  3. Q3: (512,10)×(10,64)=(512,64).
  4. Q4: Each entry records the sensitivity of the final scalar loss to that query-projection parameter, through all its uses.
  5. Q5: Multiply upstream gradients through value aggregation, softmax, scaled score products and the query projection, preserving shapes and summing branches.
  6. Q6: Backprop computes derivatives; the optimizer is the mechanism that turns them into parameter changes.

Edge cases and remaining gaps

  • The introductory claim that a Transformer does not have scalar parameters is too literal. Tensor parameters consist of scalars and models can also expose scalar parameters such as scales; arranging entries as tensors changes bookkeeping, not calculus.
  • The displayed forward dependency diagram X→W_Q→Q is a schematic. X and W_Q are both operands of the multiply node; X does not cause W_Q.
  • For a scalar loss, reverse-mode obtains vector-Jacobian products without storing all full Jacobians. A vector-valued output requires an upstream vector or an explicitly requested Jacobian.
  • Q and K commonly use equal head dimensions; V can have a different value width. The shorthand Q,K,V with one common d_k is an architecture choice.
  • This completes the written foundation numerical reconciliation and adds missing contraction assumptions; PyTorch backend execution and all inherited citation attributions remain separately tracked.

Connections and progression

  • The same contractions determine LoRA adapter gradients, input sensitivity, attention training and accumulation across tokens/microbatches.

Inherited foundation review — Matrix calculus: explicit contractions and gradient accumulation

Read this qualification together with the original lesson. Checked fixtures and source support are recorded below; the full course remains under review.

Motivation, prerequisites and assumptions

Extend scalar differentiation into the shapes used by Transformer projections and attention. Prerequisites: Step 0.1 dimensions and Step 0.4 reverse-mode calculus.

Scalar loss, row-oriented forward Y=XW, fixed independent X/W for each partial derivative. W is shared across token/batch positions, so parameter gradients sum those contributions. Any averaging factor in the loss is already present in the upstream gradient.

Derivation and worked results

  1. Write Y_ij=sum_k X_ik W_kj. Then dL/dW_kj=sum_i (dL/dY_ij)X_ik, giving dW=XᵀG. Likewise dX=GWᵀ. These are contractions, not an inversion of XW.
  2. For the inherited half-sum squared error with X=[[1,2],[3,4]], W=I and target [[2,1],[4,3]], Y=X, loss=2, G=[[-1,1],[-1,1]] and dW=[[-4,4],[-6,6]]. Every entry was checked by finite differences.
  3. For the vector example L=w1²+3w2², the gradient is [2w1,6w2]. For the matrix weighted quadratic, coefficients [1,2;3,4] give entrywise gradient [2w11,4w12;6w21,8w22].
  4. At x=(3,4), the inherited Jacobian for [x1²+x2,x1x2] is [[6,1],[4,3]], independently checked for both outputs.
  5. The inherited parameter update gives [[0.98,2.05],[2.99,3.97]]. A 768×64 weight has 49,152 scalar entries and an equally shaped scalar-loss gradient.
  6. For a batch, flatten batch/token positions conceptually and sum X_btᵀG_bt over them. Bias gradients sum the upstream signal over the reused axes. Loss means, masks and unequal lengths must contribute their declared normalization.
  7. Complete attention backward application: with O=AV and half-sum MSE against T, G_O=O−T. Differentiate the product to obtain G_A=G_OVᵀ and G_V=AᵀG_O. For each row, contract the softmax Jacobian to get G_S,ij=A_ij(G_A,ij−sum_r A_ir G_A,ir). Masked entries have A_ij=0 and contribute zero.
  8. For scores QKᵀ/√d_k, G_Q=G_SK/√d_k and G_K=G_SᵀQ/√d_k. Multiply each projection gradient by Xᵀ to obtain the parameter gradient; sum query, key and value contributions for the input gradient.
  9. A complete CPU trace uses X=[[1,2],[3,4],[5,6]], Wq=[[0.1,0.2],[0.3,0.4]], Wk=[[-0.2,0.1],[0.1,0.3]], Wv=[[0.4,-0.1],[0.2,0.3]] and T=[[1,0],[0,1],[1,1]], with causal mask, no dropout and half-sum MSE. It gives output [[0.8,0.5],[1.6848515052,0.7949505017],[2.9257457506,1.2085819169]] and loss 3.4613865017. The companion prints Q,K,V,A and all gradients. All three parameter matrices and the entire input gradient were independently checked by finite differences.

Edge cases and limitations

  • The introductory claim that a Transformer does not have scalar parameters is too literal. Tensor parameters consist of scalars and models can also expose scalar parameters such as scales; arranging entries as tensors changes bookkeeping, not calculus.
  • The displayed forward dependency diagram X→W_Q→Q is a schematic. X and W_Q are both operands of the multiply node; X does not cause W_Q.
  • For a scalar loss, reverse-mode obtains vector-Jacobian products without storing all full Jacobians. A vector-valued output requires an upstream vector or an explicitly requested Jacobian.
  • Q and K commonly use equal head dimensions; V can have a different value width. The shorthand Q,K,V with one common d_k is an architecture choice.
  • This completes the written foundation numerical reconciliation and adds missing contraction assumptions; PyTorch backend execution and all inherited citation attributions remain separately tracked.

Why this matters

Every parameter matrix needs a gradient with the same shape. Deriving it once prevents transpose mistakes throughout Q/K/V and LoRA.

Prerequisites: Matrix multiplication and shape contracts, Transpose versus reshape, Chain rule and scalar gradients

Symbols, shapes and assumptions

Let Y=XW and L=½ΣᵢⱼYᵢⱼ². X is m×n, W is n×p, and dL/dY=Y. This fixture is a squared-error teaching loss, not the language-model CE loss.

Derivation or mechanism

  1. Changing W[r,j] affects Y[i,j] through X[i,r]. Sum Y[i,j]X[i,r] over i.
  2. Collect these entries as XᵀY.
  3. Changing X[i,r] affects Y[i,j] through W[r,j]. Sum over j to obtain YWᵀ.
\nabla_W L=X^\top Y,\qquad \nabla_X L=YW^\top

Worked numerical

With the F01 matrices, Y=[[2,3],[5,5]]. Thus ∇W=[[17,18],[24,26]] and ∇X=[[-1,7],[0,12.5]]. For example, ∂L/∂W₁₁=1×2+3×5=17. The checker perturbs all eight X/W entries separately and compares their loss changes.

Edge cases and limits

  • A transpose is dictated by index contraction, not inserted until shapes happen to match.
  • If W is stored in the opposite library orientation, convert the formula accordingly.

Connections

  • F09 updates W.
  • Later attention backpropagation and low-rank updates reuse this contraction rule.

Why this matters

This explains why next-token CE training pushes the correct logit up and competing logits down.

Prerequisites: Stable softmax and log-softmax, Entropy, cross-entropy, KL, and support, Chain rule and scalar gradients

Symbols, shapes and assumptions

For one-hot target y and τ=1, p=softmax(z). The loss is -log p_target. A mean over multiple valid positions introduces its own denominator.

Derivation or mechanism

  1. Differentiate the softmax quotient: ∂pᵢ/∂zⱼ=pᵢ(δᵢⱼ-pⱼ).
  2. Write L=-z_target+log Σ exp(z).
  3. Differentiate to obtain ∂L/∂zⱼ=pⱼ-yⱼ.
J_{ij}=p_i(\delta_{ij}-p_j)
\nabla_z L=p-y

Worked numerical

For logits [log 1,log 2,log 3], p=[1/6,1/3,1/2]. With target ID 2, CE=log 2≈0.693147181 and gradient=[1/6,1/3,-1/2]. The gradients sum to zero, consistent with invariance to adding a common logit offset.

Edge cases and limits

  • For temperature-scaled logits, the derivative with respect to the unscaled logits gains a 1/τ factor.
  • Passing softmax probabilities into a logits-based CE API applies a different computation.

Connections

  • T01 masks and averages token losses.
  • KD uses soft targets and must specify whether the teacher is fixed.

STEP 0.6 — TENSOR / MATRIX CALCULUS

Plan node: I0 · chat order #7

From scalar derivatives → vector gradients → matrix gradients → Transformer gradients

This is the last mathematical foundation step before we start the Transformer itself.

So far we learned:

\frac{dL}{dw}

for a scalar parameter.

But a Transformer does not have scalar parameters. It has matrices and tensors such as:

W_Q,\;W_K,\;W_V,\;W_O,\;W_1,\;W_2

and activations such as:

X,Q,K,V,A,O

Therefore we need to understand:

What does it mean to differentiate a scalar loss with respect to a matrix?

Correction: Tensor parameters contain scalar entries; scalar scale parameters can also exist. Matrix calculus generalizes scalar differentiation.

Complete grounded review

0.6.1 First: the key idea

Suppose:

L=f(W)

where L is a scalar but W is a matrix.

For example:

W= \begin{bmatrix} w_{11}&w_{12}\\ w_{21}&w_{22} \end{bmatrix}

Then W actually contains four parameters:

w_{11},w_{12},w_{21},w_{22}

Therefore the gradient must contain four derivatives:

\boxed{ \nabla_W L= \begin{bmatrix} \frac{\partial L}{\partial w_{11}}& \frac{\partial L}{\partial w_{12}}\\ \frac{\partial L}{\partial w_{21}}& \frac{\partial L}{\partial w_{22}} \end{bmatrix} }

So:

A matrix gradient has the same shape as the matrix parameter.

This is the mental model we will use throughout Transformers.

0.6.2 Why this matters for Transformers

Remember:

Q=XW_Q

from our earlier lessons.

The book implements attention through matrix multiplication, including operations such as QK^T and then softmax normalization. (Source: Build a Large Language Model (From Scratch))

Suppose the final loss is:

L

We eventually need:

\boxed{ \frac{\partial L}{\partial W_Q} }

because W_Q is a learnable parameter.

The chain is:

W_Q \rightarrow Q \rightarrow QK^T \rightarrow A \rightarrow O \rightarrow \text{Transformer} \rightarrow \text{logits} \rightarrow L

So the gradient must travel backward through matrix operations.

0.6.3 Start with a scalar example

Suppose:

y=wx

and:

x=3

Then:

y=3w

Therefore:

\frac{\partial y}{\partial w}=3

Simple.

Now let's increase the number of parameters.

0.6.4 Vector parameter

Suppose:

\mathbf w= \begin{bmatrix} w_1\\ w_2 \end{bmatrix}

and:

L=w_1^2+3w_2^2

Then:

\frac{\partial L}{\partial w_1}=2w_1

and:

\frac{\partial L}{\partial w_2}=6w_2

Therefore:

\boxed{ \nabla_{\mathbf w}L= \begin{bmatrix} 2w_1\\ 6w_2 \end{bmatrix} }

Again:

\boxed{ \text{gradient shape}=\text{parameter shape} }

0.6.5 Matrix parameter

Now:

W= \begin{bmatrix} w_{11}&w_{12}\\ w_{21}&w_{22} \end{bmatrix}

Suppose:

L= w_{11}^2 + 2w_{12}^2 + 3w_{21}^2 + 4w_{22}^2

Then:

\frac{\partial L}{\partial w_{11}}=2w_{11}
\frac{\partial L}{\partial w_{12}}=4w_{12}
\frac{\partial L}{\partial w_{21}}=6w_{21}
\frac{\partial L}{\partial w_{22}}=8w_{22}

Thus:

\boxed{ \nabla_WL= \begin{bmatrix} 2w_{11}&4w_{12}\\ 6w_{21}&8w_{22} \end{bmatrix} }

Nothing magical happened.

We simply differentiated every element.

0.6.6 The crucial idea: scalar loss, many parameters

A neural network normally has:

\boxed{ L\in\mathbb R }

but:

\theta

can contain millions or billions of parameters.

Conceptually:

\theta= \{\theta_1,\theta_2,\ldots,\theta_n\}

The gradient is:

\nabla_\theta L = \left[ \frac{\partial L}{\partial\theta_1}, \dots, \frac{\partial L}{\partial\theta_n} \right]

When those parameters are arranged into matrices/tensors, the gradients are arranged into corresponding matrices/tensors.

0.6.7 A very important notation distinction

You may encounter:

\frac{\partial L}{\partial W}

and:

\nabla_WL

For our purposes, both mean:

the collection of partial derivatives of the scalar loss with respect to every element of W.

So you can mentally read:

\boxed{ \nabla_WL = \text{"how should every element of W change?"} }

0.6.8 Now the important case: matrix multiplication

Consider:

Y=XW

where:

X\in\mathbb R^{n\times d}

and:

W\in\mathbb R^{d\times m}

therefore:

Y\in\mathbb R^{n\times m}

This is exactly the type of operation used throughout a Transformer.

For example:

Q=XW_Q

0.6.9 Let's make it tiny

Take:

X= \begin{bmatrix} x_1&x_2 \end{bmatrix}

and:

W= \begin{bmatrix} w_1\\ w_2 \end{bmatrix}

Then:

Y=XW

is:

y=x_1w_1+x_2w_2

Suppose:

L=\frac12(y-t)^2

We want:

\frac{\partial L}{\partial W}

0.6.10 First derivative

Start with:

L=\frac12(y-t)^2

Therefore:

\frac{\partial L}{\partial y}=y-t

Now:

y=x_1w_1+x_2w_2

so:

\frac{\partial y}{\partial w_1}=x_1

and:

\frac{\partial y}{\partial w_2}=x_2

By the chain rule:

\frac{\partial L}{\partial w_1} = \frac{\partial L}{\partial y} \frac{\partial y}{\partial w_1}

Therefore:

\frac{\partial L}{\partial w_1} = (y-t)x_1

Similarly:

\frac{\partial L}{\partial w_2} = (y-t)x_2

Thus:

\boxed{ \nabla_WL = (y-t) \begin{bmatrix} x_1\\ x_2 \end{bmatrix} }

or:

\boxed{ \nabla_WL=X^T\frac{\partial L}{\partial y} }

This is the basic pattern behind gradients of linear layers.

0.6.11 The beautiful pattern

Forward:

\boxed{ Y=XW }

Backward:

\boxed{ \frac{\partial L}{\partial W} = X^T \frac{\partial L}{\partial Y} }

and:

\boxed{ \frac{\partial L}{\partial X} = \frac{\partial L}{\partial Y}W^T }

These formulas are extremely useful.

Don't memorize them blindly.

Understand the principle:

The backward pass reverses the matrix multiplication while preserving compatible dimensions.

0.6.12 Check the dimensions

Suppose:

X\in\mathbb R^{n\times d}

and:

W\in\mathbb R^{d\times m}

then:

Y=XW

has:

Y\in\mathbb R^{n\times m}

Now:

\frac{\partial L}{\partial Y} \in \mathbb R^{n\times m}

For:

\frac{\partial L}{\partial W} = X^T \frac{\partial L}{\partial Y}

we have:

X^T\in\mathbb R^{d\times n}

and:

\frac{\partial L}{\partial Y} \in\mathbb R^{n\times m}

therefore:

\boxed{ \frac{\partial L}{\partial W} \in\mathbb R^{d\times m} }

Exactly the same shape as W.

That shape check is one of the best ways to catch errors.

0.6.13 Apply this directly to Q=XW_Q

Suppose:

X\in\mathbb R^{n\times d}
W_Q\in\mathbb R^{d\times d_k}

Then:

Q=XW_Q

and:

Q\in\mathbb R^{n\times d_k}

During backpropagation:

\frac{\partial L}{\partial W_Q} = X^T \frac{\partial L}{\partial Q}

Shapes:

X^T: d\times n
\frac{\partial L}{\partial Q}: n\times d_k

Therefore:

\boxed{ \frac{\partial L}{\partial W_Q} : d\times d_k }

which matches:

W_Q:d\times d_k

Perfect.

0.6.14 But where does \partial L/\partial Q come from?

This is where the chain rule returns.

We have:

Q \rightarrow QK^T \rightarrow \frac{QK^T}{\sqrt{d_k}} \rightarrow \text{softmax} \rightarrow A \rightarrow AV \rightarrow L

Therefore:

\frac{\partial L}{\partial Q}

is itself obtained by backpropagating through all those operations.

So:

\boxed{ W_Q \rightarrow Q \rightarrow S \rightarrow A \rightarrow O \rightarrow L }

and the backward path is:

\boxed{ L \rightarrow O \rightarrow A \rightarrow S \rightarrow Q \rightarrow W_Q }

0.6.15 Matrix multiplication in attention

Recall:

S=QK^T

where:

Q,K\in\mathbb R^{n\times d_k}

Therefore:

K^T\in\mathbb R^{d_k\times n}

and:

S\in\mathbb R^{n\times n}

The book explicitly constructs all pairwise attention scores using matrix multiplication QK^T. (Source: Build a Large Language Model (From Scratch))

Each element is:

\boxed{ S_{ij}=q_i^Tk_j }

So:

Row i asks: how compatible is query q_i with every key?

0.6.16 Why QK^T produces n\times n

This is worth understanding deeply.

Suppose:

n=4

tokens and:

d_k=3

Then:

Q= 4\times3

and:

K= 4\times3

Therefore:

K^T= 3\times4

Thus:

QK^T: (4\times3)(3\times4) = 4\times4

The resulting matrix contains:

4\times4=16

pairwise query-key scores.

0.6.17 Now add scaling

Attention uses:

S= \frac{QK^T}{\sqrt{d_k}}

Then:

A=\operatorname{softmax}(S)

Then:

O=AV

The book explains this progression from dot-product scores to scaled softmax attention weights and then weighted value aggregation. (Source: Build a Large Language Model (From Scratch))

0.6.18 What happens during backward propagation?

Suppose:

L=L(O)

We first obtain:

\frac{\partial L}{\partial O}

Then propagate through:

O=AV

giving gradients for:

A

and:

V

Then propagate through:

A=\operatorname{softmax}(S)

giving:

\frac{\partial L}{\partial S}

Then:

S=\frac{QK^T}{\sqrt{d_k}}

gives gradients for:

Q

and:

K

Finally:

Q=XW_Q

gives:

\frac{\partial L}{\partial W_Q}

This is the exact computational chain we needed matrix calculus to understand.

0.6.20 Numerical example: gradient of a matrix

Let's make a tiny linear layer:

X= \begin{bmatrix} 1&2\\ 3&4 \end{bmatrix}

and:

W= \begin{bmatrix} 1&0\\ 0&1 \end{bmatrix}

Then:

Y=XW=X

Suppose the target is:

T= \begin{bmatrix} 2&1\\ 4&3 \end{bmatrix}

and define:

L=\frac12\sum_{ij}(Y_{ij}-T_{ij})^2

Then:

Y-T= \begin{bmatrix} -1&1\\ -1&1 \end{bmatrix}

Therefore:

\frac{\partial L}{\partial Y} = \begin{bmatrix} -1&1\\ -1&1 \end{bmatrix}

Now:

\frac{\partial L}{\partial W} = X^T \frac{\partial L}{\partial Y}

We have:

X^T= \begin{bmatrix} 1&3\\ 2&4 \end{bmatrix}

Therefore:

\frac{\partial L}{\partial W} = \begin{bmatrix} 1&3\\ 2&4 \end{bmatrix} \begin{bmatrix} -1&1\\ -1&1 \end{bmatrix}

giving:

\boxed{ \frac{\partial L}{\partial W} = \begin{bmatrix} -4&4\\ -6&6 \end{bmatrix} }

Notice the shape:

2\times2

same as W.

0.6.21 Why does the gradient depend on the input?

Look at:

\boxed{ \frac{\partial L}{\partial W} = X^T\frac{\partial L}{\partial Y} }

This tells us something important.

A weight doesn't learn in isolation.

Its update depends on:

  1. the input that passed through it
  2. how wrong the output was

So conceptually:

\boxed{ \text{weight gradient} = \text{input} \times \text{error signal} }

This is a very useful intuition for neural networks.

0.6.22 Tensor calculus: why a Transformer makes this bigger

In a real Transformer, we don't just have:

X\in\mathbb R^{n\times d}

We usually have batches:

\boxed{ X\in\mathbb R^{B\times n\times d} }

where:

  • B = batch size
  • n = sequence length
  • d = hidden dimension

Then attention may have:

Q,K,V \in \mathbb R^{B\times H\times n\times d_k}

where:

  • H = number of heads
  • d_k = dimension per head

Raschka's implementation similarly uses batched tensor shapes involving batch, heads, tokens, and head dimension. (Source: Build a Large Language Model (From Scratch))

0.6.23 Does the mathematics change?

No.

The fundamental principle is still:

\boxed{ \text{differentiate every element and propagate the chain rule} }

The only difference is that there are many dimensions and repeated operations.

PyTorch's automatic differentiation handles this bookkeeping.

0.6.24 Why automatic differentiation is so important

Imagine manually calculating:

\frac{\partial L}{\partial W_Q}

for a 70-billion-parameter model.

Obviously impossible by hand.

Instead, the framework constructs a computation graph and automatically applies the chain rule.

Conceptually:

forward operations
      ↓
computation graph
      ↓
loss
      ↓
automatic differentiation
      ↓
gradients for tensors
      ↓
optimizer
      ↓
updated parameters

This is why understanding the mathematics is important even though we don't manually derive every gradient in code.

0.6.25 Jacobian — one more concept

We need one more piece of vocabulary.

Suppose:

\mathbf y=f(\mathbf x)

where both are vectors:

\mathbf x\in\mathbb R^n

and:

\mathbf y\in\mathbb R^m

Then the Jacobian is:

\boxed{ J= \frac{\partial\mathbf y}{\partial\mathbf x} }

containing all derivatives:

J_{ij} = \frac{\partial y_i}{\partial x_j}

So:

J\in\mathbb R^{m\times n}

0.6.26 Example of a Jacobian

Let:

y_1=x_1^2+x_2
y_2=x_1x_2

Then:

\frac{\partial y_1}{\partial x_1}=2x_1
\frac{\partial y_1}{\partial x_2}=1
\frac{\partial y_2}{\partial x_1}=x_2
\frac{\partial y_2}{\partial x_2}=x_1

Therefore:

\boxed{ J= \begin{bmatrix} 2x_1&1\\ x_2&x_1 \end{bmatrix} }

You do not need to manually calculate Jacobians throughout our Transformer course.

But you need to understand:

A Jacobian describes how a vector of outputs changes with respect to a vector of inputs.

0.6.27 Why don't we usually see giant Jacobian matrices in PyTorch?

Because explicitly constructing them would often be extremely inefficient.

For neural networks we usually care about:

\frac{\partial L}{\partial\theta}

where:

L

is a scalar.

Automatic differentiation can compute the needed vector-Jacobian products efficiently without materializing every possible derivative.

This is one reason reverse-mode autodiff is so useful for neural-network training.

You should now have this hierarchy:

\boxed{ \text{How does the loss change when this quantity changes?} }

0.6.29 The Transformer version

Now we can finally understand the mathematical meaning of:

\boxed{ \frac{\partial L}{\partial W_Q} }

It means:

For every element of W_Q, how much would the final loss change if that element were changed slightly, while accounting for all downstream computations?

And similarly:

\frac{\partial L}{\partial W_K}

means:

How does every element of the key projection affect the final loss?

and:

\frac{\partial L}{\partial W_V}

means:

How does every element of the value projection affect the final loss?

0.6.30 Why the gradient has the same shape as the parameter

Suppose:

W_Q\in\mathbb R^{768\times64}

Then there are:

768\times64=49,152

individual parameters.

Therefore:

\boxed{ \nabla_{W_Q}L\in\mathbb R^{768\times64} }

There is one gradient value corresponding to every parameter.

Then the optimizer performs:

W_Q \leftarrow W_Q-\eta\nabla_{W_Q}L

element by element.

0.6.31 One complete numerical mini-example

Suppose:

W_Q= \begin{bmatrix} 1&2\\ 3&4 \end{bmatrix}

and suppose backpropagation produces:

\nabla_{W_Q}L= \begin{bmatrix} 0.2&-0.5\\ 0.1&0.3 \end{bmatrix}

with:

\eta=0.1

Then:

W_Q^{new} = W_Q-0.1\nabla_{W_Q}L

Therefore:

W_Q^{new} = \begin{bmatrix} 1&2\\ 3&4 \end{bmatrix} - \begin{bmatrix} 0.02&-0.05\\ 0.01&0.03 \end{bmatrix}

giving:

\boxed{ W_Q^{new} = \begin{bmatrix} 0.98&2.05\\ 2.99&3.97 \end{bmatrix} }

That is literally a tiny piece of what happens during Transformer training.

0.6.32 The entire Transformer training mathematics

Now we can finally connect everything.

Forward

Input:
X
Projection:
Q=XW_Q
K=XW_K
V=XW_V
Attention scores:
S=\frac{QK^T}{\sqrt{d_k}}
Causal masking:
S'=S+M
Attention distribution:
A=\operatorname{softmax}(S')
Attention output:
O=AV
Transformer layers:
O \rightarrow \text{residual/normalization/FFN/etc.}
Output:
z
Probability:
p=\operatorname{softmax}(z)
Loss:
L=-\log p_{\text{target}}

Backward

L \rightarrow p \rightarrow z \rightarrow \text{Transformer layers} \rightarrow O \rightarrow A,V \rightarrow S \rightarrow Q,K \rightarrow W_Q,W_K,W_V

producing:

\nabla_{W_Q}L
\nabla_{W_K}L
\nabla_{W_V}L

and gradients for every other learnable parameter.

Update

\boxed{ \theta \leftarrow \theta-\eta\nabla_\theta L }

This is the complete mathematical skeleton of Transformer learning.

0.6.33 VERY IMPORTANT: forward mathematics vs backward mathematics

Your lecture material is primarily focused on the forward architecture of Transformers.
