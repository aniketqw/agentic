Motivation

Read numerical values from their bit fields before reasoning about precision, range, underflow or low-precision training.

Prerequisites

  • Binary positional fractions and integer exponents.
  • Sign bit and powers of two.

Notation and units

  • S: sign bit; E: stored exponent; M: integer fraction field.
  • binary16 has 5 exponent bits, 10 fraction bits and bias15.

Assumptions

  • IEEE binary16 encoding; all-one exponent represents infinity/NaN. This is not an E4M3FN decoder.
  • The code models representable values, not whether a particular GPU flushes subnormals.

Step-by-step derivation

  1. For 1<=E<=30 decode (-1)^S*(1+M/1024)*2^(E-15). The normal leading1 is implicit.
  2. For E=0 decode (-1)^S*M*2^-24. M=0 gives signed zero; preserve its sign rather than evaluating an integer signed product that loses it.
  3. For E=31, M=0 represents signed infinity; M>0 represents NaN. Neither is a normal value.
  4. The largest finite value is (2-2^-10)*2^15=65504. The smallest positive normal is 2^-14, and smallest positive subnormal 2^-24.
  5. At a fixed normal exponent, spacing is 2^(E-15-10). Subnormal spacing stays 2^-24, so relative precision worsens near zero. BF16 increases exponent range relative to FP16 while using fewer fraction bits.

Separate numeric format from model quantization

A floating-point format allocates bits to sign, exponent, and fraction. Weight quantization maps model values to a lower-precision representation using scales or codebooks. Both concern representation, but a floating-point decoder and a weight-quantization algorithm are different operations. These pages explain the representation before the later QLoRA/GPTQ lessons use it.

b=2^{e-1}-1,\quad F=\sum_{k=1}^{m}f_k2^{-k},\quad x=(-1)^S2^{E-b}(1+F)

Here e is the exponent-bit count, m the fraction-bit count, E the stored exponent integer, b the bias, S the sign bit, and F the fractional part. The normal formula applies only to 1 ≤ E ≤ 2^e−2 for the IEEE-style formats used here. It must not be blindly extended to FP8 variants with different reserved patterns.

Decode the slide’s FP16 value from the fields

FP16 has e=5, m=10, b=15. The source pattern has S=0, E=10000₂=16, and fraction bits 1001001000. Thus F=1/2+1/16+1/128=.5703125. The decoded result is 2^(16−15)(1+.5703125)=3.140625. The value of π differs by about .00096765; the representation rounds to a nearby available value rather than storing arbitrary decimals.

x_{\max}=(2-2^{-m})2^{(2^e-2)-b},\qquad x_{\min,\mathrm{normal}}=2^{1-b}

For the maximum normal value, set every fraction bit to 1 and choose the largest usable exponent. For the minimum positive normal, use the smallest normal exponent and a zero fraction. FP16 therefore gives (2−2^-10)2^15=65504 and 2^-14≈6.103515625×10^-5. BF16 shares FP32’s exponent width but has fewer fraction bits, so broad range and fine precision must not be conflated.

Correction: The new decoder explicitly preserves signed zero with math.copysign. All65536 binary16 patterns are compared with struct.unpack, including the sign of zero; this checks representation, not GPU subnormal execution.

Complete grounded review

Subnormals remove the implicit leading one

x_{\mathrm{sub}}=(-1)^S2^{1-b}F,\quad E=0,\ F\ne0,\qquad x_{\min,\mathrm{sub}}=2^{1-b-m}

The exponent stays at the smallest-normal exponent while the leading 1 disappears. FP16’s smallest positive subnormal is 2^-24≈5.960464478×10^-8. With E=0,F=0 the value is signed zero. With an all-ones exponent and zero fraction it is an infinity; a nonzero fraction denotes NaN. The normal formula is not valid for those reserved cases.

Qualification to slide 7: adjacent subnormal values are separated by a constant absolute increment, 2^-24 in FP16. Moving to the next fraction integer does not generally halve the value. Removing one particular highest set bit can halve a power-of-two value; the general spacing is linear. Relative precision degrades near zero. Hardware may flush subnormals in some modes, so the representation’s available values and an actual kernel’s behavior are separate questions.

"""Verified bit/scale/error examples, not a production quantization kernel."""
import math
import struct

def decode_fp16(bits):
    sign = -1 if bits >> 15 else 1
    exponent = (bits >> 10) & 31
    fraction = (bits & 1023) / 1024
    if exponent == 0:
        return sign * 2 ** -14 * fraction
    if exponent == 31:
        return sign * math.inf if fraction == 0 else math.nan
    return sign * 2 ** (exponent - 15) * (1 + fraction)

def quadratic(error, h):
    return sum(error[i] * h[i][j] * error[j]
               for i in range(len(error)) for j in range(len(error)))

def main():
    pi_bits = (16 << 10) | int('1001001000', 2)
    for bits in [pi_bits, 0x7bff, 0x0400, 0x0001, 0x8000]:
        value = decode_fp16(bits)
        reference = struct.unpack('>e', bits.to_bytes(2, 'big'))[0]
        assert value == reference
    assert decode_fp16(pi_bits) == 3.140625
    assert decode_fp16(0x7bff) == 65504
    assert decode_fp16(1) == 2 ** -24
    assert math.isinf(decode_fp16(0x7c00))
    assert math.isnan(decode_fp16(0x7e00))
    assert math.copysign(1, decode_fp16(0x8000)) == -1
    # Unit scales: x approximately sx*qx; w approximately sw*qw.
    accumulator, sx, sw, sy = 200, 0.02, 0.05, 0.01
    real = sx * sw * accumulator
    requantized = round((sx * sw / sy) * accumulator)
    assert math.isclose(real, 0.2) and requantized == 20
    # Toy metric tradeoff, not the deck's 64-weight GPTQ experiment.
    h = [[100.0, 0.0], [0.0, 1.0]]
    naive, weighted = [0.1, 0.1], [0.01, 0.3]
    assert sum(v*v for v in weighted) > sum(v*v for v in naive)
    assert quadratic(weighted, h) < quadratic(naive, h)
    # Exact best second error after the first coordinate is fixed.
    hc, first_error = [[1.0, 0.9], [0.9, 1.0]], 0.1
    second_error = -hc[1][0] * first_error / hc[1][1]
    assert math.isclose(quadratic([first_error, second_error], hc), 0.0019)
    print('FP16 pi:', decode_fp16(pi_bits), 'max:', decode_fp16(0x7bff))
    print('FP16 smallest normal:', 2 ** -14, 'smallest subnormal:', 2 ** -24)
    print('real accumulator:', real, 'requantized:', requantized)
    print('toy output errors:', quadratic(naive, h), quadratic(weighted, h))
    print('compensation error:', second_error)

if __name__ == '__main__':
    main()
