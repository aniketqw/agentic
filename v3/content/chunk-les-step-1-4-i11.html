Maintain a common-width representation while allowing each branch to write a learned update.

Step-by-step derivation

  1. Write h=x+Attn(Norm(x)) and y=h+FFN(Norm(h)); the identity contribution is the original input to each sublayer.
  2. Elementwise example [2,4,1]+[.5,-1,2]=[2.5,3,3]. New contributions may cancel old values; algebraic inclusion is not recoverability.
  3. For y=x+F(x), J_y=I+J_F. In backprop, g_x=g_y+J_F^T g_y, so an identity gradient path is present.

  5. Telescoping across blocks yields r_L=r_0+sum a_l+sum m_l, but every update is computed using earlier modified states.
  6. Attention moves context across positions; FFN transforms feature vectors independently after contextualization; normalization prepares branch inputs and output projection returns to common width.

Why this matters

A sublayer adds an update to a continuing representation, rather than replacing that representation outright.

Prerequisites: Matrix multiplication and shape contracts, Chain rule and scalar gradients

Symbols, shapes and assumptions

For y=x+f(x), the shapes must agree. The Jacobian is I+Jf. The identity term offers a direct path but does not guarantee that every gradient is large or nonzero.

Derivation or mechanism

  1. Compute a sublayer update of the same shape.
  2. Add it componentwise to the stream.
  3. Differentiate both branches and sum their contributions.
y=x+f(x),\qquad J_y=I+J_f

Worked numerical

For x=[1,2] and update=[0.5,-0.5], y=[1.5,1.5]. If f(x)=2x, the total derivative is 3I. If f(x)=-x, the paths cancel: residual structure alone cannot guarantee a nonzero derivative.

Edge cases and limits

  • The companion prohibits accidental broadcasting.
  • A residual connection does not mean the sublayer changes every token equally.

Connections

  • T12 joins attention and MLP through two residual additions.

Step 1.4 — The Residual Stream

Plan node: I1 · chat order #11

We now know how the model creates a position-aware representation:

\text{text} \rightarrow \text{tokens} \rightarrow \text{IDs} \rightarrow \text{token embeddings} \rightarrow \text{position information}

So we have a matrix:

X\in\mathbb R^{T\times d}

or, with a batch:

X\in\mathbb R^{B\times T\times d}

The next question is:

What happens to this representation as it passes through 12, 24, 48, or hundreds of Transformer blocks?

The answer is the residual stream.

Your Transformer slides make this the central organizing idea of the architecture: attention and MLP sublayers read from the stream and write their updates back into it additively.

1.4.1 First, What Is a "Stream"?

Suppose we have:

The   cat   is   sleeping
 ↓    ↓     ↓      ↓
 d    d     d      d

Each token has a d-dimensional vector.

So for one sequence:

X= \begin{bmatrix} x_1\\ x_2\\ x_3\\ x_4 \end{bmatrix} \in\mathbb R^{4\times d}

Think of every row as a lane.

Token 1 ───────────────────────── lane 1
Token 2 ───────────────────────── lane 2
Token 3 ───────────────────────── lane 3
Token 4 ───────────────────────── lane 4

The collection of these d-dimensional representations is the residual stream.

The important idea from your slide is:

Attention moves information between lanes; MLPs process information within a lane.

This is an extremely useful mental model.

1.4.2 Why Do We Need a Residual Stream?

Imagine a Transformer block simply did:

x_{\text{new}}=F(x)

where F is some complicated neural network.

Then every layer would completely replace the previous representation.

With many layers:

x_1=F_1(x_0)
x_2=F_2(x_1)
x_3=F_3(x_2)

and eventually:

x_L=F_L(\cdots F_2(F_1(x_0)))

This creates a long chain of transformations.

Training becomes harder because gradients have to flow through all those transformations.

Residual connections instead make the layer say:

"Keep what you already know, and add an update."

So:

\boxed{ x_{\text{new}}=x+F(x) }

This is the core residual idea.

1.4.3 The Most Important Equation of This Step

Your slides use:

\boxed{ x\leftarrow x+\operatorname{Attn}(\operatorname{Norm}(x)) }

and then:

\boxed{ x\leftarrow x+\operatorname{MLP}(\operatorname{Norm}(x)) }

For the entire sequence:

\boxed{ X\leftarrow X+\operatorname{Attn}(\operatorname{Norm}(X)) }
\boxed{ X\leftarrow X+\operatorname{MLP}(\operatorname{Norm}(X)) }

Notice the structure:

old representation
       +
new information
       ↓
new representation

That is the residual stream.

1.4.4 Why Is It Called "Residual"?

Suppose we want the layer to produce some ideal transformation:

H(x)

Instead of forcing the layer to learn H(x) directly, write:

H(x)=x+F(x)

Therefore:

F(x)=H(x)-x

So the neural network only has to learn:

\boxed{ \text{What should I add to the current representation?} }

That difference:

H(x)-x

is the residual.

Hence the name:

residual connection / residual block.

Correction: Residual addition includes the old vector algebraically but may cancel it; it does not preserve it as a separately recoverable record.

1.4.5 Tiny Numerical Example

Suppose one token has representation:

x= [2,4,1]

The attention sublayer generates:

a= [0.5,-1,2]

Residual addition gives:

x' = x+a

so:

x' = [2.5,3,3]

The original information was not discarded.

It remains:

[2,4,1]

and attention contributed:

[0.5,-1,2]

Therefore:

\boxed{ \text{new representation} = \text{old representation} + \text{attention update} }

1.4.6 Now Add the MLP

The MLP produces another update:

m=[-0.2,0.4,0.8]

Then:

x''=x'+m

giving:

x''= [2.3,3.4,3.8]

So the block has done:

x \rightarrow x+a \rightarrow x+a+m

Therefore:

\boxed{ x_{\text{out}} = x_{\text{in}} + a + m }

This is the simplest way to understand the residual stream.

1.4.7 The Stream Across Many Layers

Now suppose there are L blocks.

Let:

r_0

be the representation entering the first block.

For block 1:

r_1 = r_0+a_1+m_1

For block 2:

r_2 = r_1+a_2+m_2

Substitute:

r_2 = r_0+a_1+m_1+a_2+m_2

Continue through L blocks:

\boxed{ r_L = r_0+ \sum_{\ell=1}^{L}a_\ell+ \sum_{\ell=1}^{L}m_\ell }

Conceptually, the residual stream contains:

\boxed{ \text{initial embedding} + \text{many learned updates} }

This matches the slide's description that the final representation is the embedding plus the contributions written by the sublayers.

1.4.8 What Does Attention Write?

Attention performs:

\operatorname{Attn}(X)

and produces an update for each position.

Why is this described as:

moving information between lanes?

Because token i's new representation can incorporate information from token j.

For example:

"The animal didn't cross the road because it was tired."
             ↑                       ↑
             └──── attention ────────┘

A token's representation can receive information from other token positions.

So attention performs cross-token communication.

1.4.9 What Does the MLP Write?

The MLP acts independently on each token position.

For token i:

m_i=\operatorname{MLP}(x_i)

It can transform the information stored in that token's vector.

So:

Attention:
token 1 ↔ token 2 ↔ token 3 ↔ token 4

MLP:
token 1 → transformation
token 2 → transformation
token 3 → transformation
token 4 → transformation

The MLP doesn't itself perform the cross-position mixing that attention does.

This is why your slide summarizes the division of labor as:

\boxed{ \text{Attention = between positions} }
\boxed{ \text{MLP = within a position} }

1.4.10 Why Must the Dimensions Match?

We want:

x+F(x)

Addition is only possible when the shapes match.

Suppose:

x\in\mathbb R^d

then:

F(x)\in\mathbb R^d

and therefore:

x+F(x)\in\mathbb R^d

For a sequence:

X\in\mathbb R^{T\times d}

and:

F(X)\in\mathbb R^{T\times d}

so:

X+F(X)\in\mathbb R^{T\times d}

For a batch:

X\in\mathbb R^{B\times T\times d}

and the branch must return:

\mathbb R^{B\times T\times d}

This is why Transformer blocks preserve the model width.

Raschka's implementation demonstrates that a Transformer block can take:

[2,4,768]

and return:

[2,4,768].

1.4.11 Why Does Preserving the Shape Matter?

Suppose:

d=768

Then every block can accept and return:

[B,T,768]

So we can simply do:

Embedding
    ↓
Block 1
    ↓
Block 2
    ↓
Block 3
    ↓
...
    ↓
Block L

without changing the dimensionality between blocks.

Raschka explicitly notes that preserving the input dimensions makes the Transformer architecture stackable and scalable.

1.4.12 The Gradient Problem

Now we get to the main reason residual connections are important.

Suppose a layer is simply:

y=f(x)

Then by the chain rule:

\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \frac{\partial y}{\partial x}

Across many layers, gradients involve repeated multiplication:

\frac{\partial L}{\partial x_0} = \frac{\partial L}{\partial x_L} J_LJ_{L-1}\cdots J_1

where J_i is the Jacobian of layer i.

If these Jacobians tend to shrink gradients, the gradient can become extremely small.

That is the vanishing-gradient problem.

Raschka explicitly introduces shortcut/residual connections as a mechanism to mitigate this issue in deep networks.

Correction: I+J_F supplies an identity gradient route, but J_F=-I can cancel it. Residuals do not guarantee nonvanishing gradients.

1.4.13 What Changes With a Residual Connection?

Now:

y=x+f(x)

Differentiate:

\frac{\partial y}{\partial x} = I+\frac{\partial f(x)}{\partial x}

The key term is:

\boxed{I}

the identity matrix.

That means there is a direct gradient pathway.

So:

\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \left( I+J_f \right)

The network does not have to rely entirely on:

J_f

to transmit the gradient.

There is an identity route.

1.4.14 The Simplest Scalar Demonstration

Suppose:

f(x)=0.1x

Without residual connection:

y=0.1x

so:

\frac{dy}{dx}=0.1

After 20 such layers:

(0.1)^{20}=10^{-20}

That is extremely small.

Now use a residual connection:

y=x+0.1x=1.1x

so:

\frac{dy}{dx}=1.1

After 20 layers:

1.1^{20}\approx6.73

This example is deliberately simplified. Real Transformer Jacobians are much more complicated, and residual connections do not mathematically guarantee that gradients can never vanish. The important point is that the identity pathway makes gradient propagation much easier.

Raschka's experimental example shows exactly the intended training effect: gradient magnitudes across earlier layers remain substantially more stable with shortcut connections than without them.

1.4.15 This Also Helps the Forward Pass

Residual connections are not only useful during backpropagation.

They also make each block behave like:

\boxed{ \text{current representation} + \text{learned refinement} }

rather than:

\text{completely replace representation}

So one way to think about depth is:

Layer 0:
"Here is my initial understanding."

Layer 1:
"Let me add information about relationships."

Layer 2:
"Let me refine those relationships."

Layer 3:
"Let me add another feature."

...

Layer L:
"Here is the final contextual representation."

That is an intuition, not a literal claim that every layer learns one clean human-interpretable feature.

1.4.16 Pre-Norm Architecture in Your Slides

Your Transformer slides use:

\boxed{ x' = x+\operatorname{Attn}(\operatorname{Norm}(x)) }

then:

\boxed{ y = x'+\operatorname{MLP}(\operatorname{Norm}(x')) }

This is commonly called a pre-normalization arrangement because normalization occurs before the sublayer.

Your slide's exact decoder-block summary is:

y=x+\operatorname{MHA}(\operatorname{norm}(x),\text{causal mask})

followed by:

h=\; y+\operatorname{FFN}(\operatorname{norm}(y)).

This ordering matters.

We will study LayerNorm/RMSNorm later as its own topic, but for now understand the flow.

1.4.17 One Complete Transformer Block

Let the input residual stream be:

X^{(\ell)}
Step 1 — Normalize
\tilde X^{(\ell)} = \operatorname{Norm}(X^{(\ell)})
Step 2 — Attention
A^{(\ell)} = \operatorname{Attention}(\tilde X^{(\ell)})
Step 3 — Residual addition
X'^{(\ell)} = X^{(\ell)}+A^{(\ell)}
Step 4 — Normalize again
\tilde X'^{(\ell)} = \operatorname{Norm}(X'^{(\ell)})
Step 5 — MLP
M^{(\ell)} = \operatorname{MLP}(\tilde X'^{(\ell)})
Step 6 — Second residual addition
\boxed{ X^{(\ell+1)} = X'^{(\ell)}+M^{(\ell)} }

So the block is:

             X
             │
             ├───────────────┐
             │               │
           Norm              │
             ↓               │
         Attention           │
             ↓               │
             + <─────────────┘
             │
             ├───────────────┐
             │               │
           Norm              │
             ↓               │
            MLP              │
             ↓               │
             + <─────────────┘
             │
             ↓
             Y

That is the basic unit that gets repeated.

1.4.18 Sequence-Level View

Now use:

X\in\mathbb R^{T\times d}

The attention branch:

\operatorname{Attention}(X) \in\mathbb R^{T\times d}

so:

X+\operatorname{Attention}(X) \in\mathbb R^{T\times d}

Then MLP:

\operatorname{MLP}(X') \in\mathbb R^{T\times d}

and:

X'+\operatorname{MLP}(X') \in\mathbb R^{T\times d}

Therefore a block performs:

\boxed{ T\times d \rightarrow T\times d }

It changes the contents, not the shape.

1.4.19 The Residual Stream Is Shared Across the Architecture

This is an important conceptual phrase from your slides:

Every block reads from and writes back into the same residual stream.

Imagine:

Embedding + Position
        ↓
   Residual Stream
        ↓
 ┌───────────────┐
 │ Transformer 1 │
 └───────────────┘
        ↓
   Residual Stream
        ↓
 ┌───────────────┐
 │ Transformer 2 │
 └───────────────┘
        ↓
   Residual Stream
        ↓
       ...
        ↓
 ┌───────────────┐
 │ Transformer L │
 └───────────────┘
        ↓
   Final Stream

The model is not creating an entirely separate representation space for each block.

The same-width stream is repeatedly refined.

1.4.20 Why This Matters for Interpretability

You will later encounter statements such as:

"The residual stream contains information."

That is because the architecture literally accumulates contributions there.

For example, conceptually:

r_L = r_0 + \Delta_{\text{attn},1} + \Delta_{\text{MLP},1} + \cdots + \Delta_{\text{attn},L} + \Delta_{\text{MLP},L}

This gives a useful way to think about the Transformer:

each sublayer writes an update into a shared representation.

We should not overinterpret this as saying every update corresponds to one human-readable concept. The mathematical structure is what is guaranteed.

1.4.21 Connection to the Output

After all blocks:

H=X^{(L)}

Then the final representation is normalized and projected into vocabulary space:

Z = \operatorname{Norm}(H)W_U

where:

W_U\in\mathbb R^{d\times|V|}

and:

Z\in\mathbb R^{T\times|V|}

Your slides explicitly describe this as taking the final residual-stream representation and projecting it back to vocabulary space for next-token prediction.

So the entire journey is now:

\boxed{ \text{embedding} \rightarrow \text{residual updates} \rightarrow \text{final residual stream} \rightarrow \text{logits} }

1.4.22 Simple PyTorch Residual Block

Let's implement the core idea without attention details yet.

import torch
import torch.nn as nn


class ResidualBlock(nn.Module):
    def __init__(self, d_model):
        super().__init__()

        self.norm = nn.LayerNorm(d_model)

        self.branch = nn.Sequential(
            nn.Linear(d_model, d_model),
            nn.GELU(),
            nn.Linear(d_model, d_model)
        )

    def forward(self, x):
        # Save the original residual stream
        residual = x

        # Transform a normalized copy
        update = self.branch(self.norm(x))

        # Write the update back into the stream
        x = residual + update

        return x


# Example
x = torch.randn(2, 5, 8)

block = ResidualBlock(d_model=8)

y = block(x)

print("Input shape :", x.shape)
print("Output shape:", y.shape)

Output shape:

Input shape : torch.Size([2, 5, 8])
Output shape: torch.Size([2, 5, 8])

Notice:

\boxed{ [2,5,8]\rightarrow[2,5,8] }

The branch changes the information, while the residual addition preserves the stream dimensions.

Raschka's actual Transformer block follows this same residual-addition idea, storing shortcut = x, applying normalization and the sublayer, then adding the original input back.

1.4.23 A Very Common Mistake

Do not think:

"Residual connection means we skip the layer."

Not exactly.

The branch is still computed.

We do:

F(x)

and then:

x+F(x)

So the layer is not skipped in the forward computation.

What is provided is an alternative path for both representation flow and gradients.

That is why the book calls them shortcut/skip connections.

1.4.24 Another Common Mistake

Do not confuse:

\boxed{\text{residual stream}}

with:

\boxed{\text{residual connection}}

They are related but conceptually different.

Residual stream

The evolving representation:

X^{(0)},X^{(1)},\ldots,X^{(L)}
Residual connection

The addition operation:

x_{\text{out}}=x_{\text{in}}+F(x_{\text{in}})

The stream is the thing being carried through the network.

The residual connection is the mechanism used to update it.

1.4.25 Where We Are Now

We have now constructed:

\boxed{ \text{tokens} \rightarrow \text{token IDs} \rightarrow \text{embeddings} \rightarrow \text{position} \rightarrow \text{residual stream} }

Inside a block:

\boxed{ X \rightarrow \operatorname{Norm}(X) \rightarrow \operatorname{Attention} \rightarrow +X \rightarrow \operatorname{Norm} \rightarrow \operatorname{MLP} \rightarrow +X }

The only major piece we haven't yet opened is the attention mechanism itself.

And now we can finally introduce it properly.

1.4.26 Why Q, K, V Are the Next Step

Suppose the residual stream contains:

X= \begin{bmatrix} x_1\\ x_2\\ x_3\\ x_4 \end{bmatrix}

We want token i to ask:

Which other tokens are relevant to me?

For this, the Transformer creates three different views of the same representation:

\boxed{ Q=XW_Q }
\boxed{ K=XW_K }
\boxed{ V=XW_V }

Then:

  • Query = what this token is looking for
  • Key = what each token offers for matching
  • Value = what information each token can provide

And the similarity computation:

\boxed{ QK^T }

creates all pairwise token-to-token relevance scores.

We are now at the exact point where the mathematics from Step 0.1 becomes the core Transformer mechanism.
