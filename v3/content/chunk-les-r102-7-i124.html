Step-by-step derivation

  1. Identify the precise models: GPT-4o-0513, Claude-Sonnet-3.5-1022, QwQ-32B-Preview and named R1 distilled students.
  2. Keep pass@1 separate from consensus; the primary report evaluates long responses with temperature.6, top-p.95 and maximum32768 tokens, often averaging multiple samples.

3. First observation — reasoning scales with student size

Look only at the Qwen distilled models:

1.5B\rightarrow7B\rightarrow14B\rightarrow32B

Their AIME scores are:

28.9\rightarrow55.5\rightarrow69.7\rightarrow72.6.

So the general pattern is:

\boxed{ \text{larger student} \Rightarrow \text{better ability to absorb teacher behavior} }

The source calls this smooth scaling and notes that performance improves steadily with model size. (Source: Build a DeepSeek Model (From Scratch))

4. But something more interesting happens

The 32B model gets:

72.6\%\ \text{AIME}.

The 70B Llama distilled model gets:

70.0\%.

So:

\boxed{ 32B\ \text{Qwen} > 70B\ \text{Llama} }

on the reported AIME result.

Therefore parameter count isn't the only variable.

5. Base model matters

The source compares:

\text{Qwen-7B}=55.5\%

with:

\text{Llama-8B}=50.4\%.

Despite the Llama model being slightly larger, Qwen performs better on AIME. (Source: Build a DeepSeek Model (From Scratch))

This tells us:

\boxed{ \text{final student capability} = f(\text{student size},\text{base-model capability},\text{distillation data}) }

Distillation doesn't erase the student's starting point.

The student already has pretrained knowledge.

The R1 data builds reasoning capability on top of that base.

6. Why does the base matter?

The source specifically attributes some of the Qwen advantage to the characteristics of the Qwen2.5-Math bases used for the smaller variants. (Source: Build a DeepSeek Model (From Scratch))

So imagine two students of approximately similar scale:

Base A
  +
R1 reasoning data
  ↓
Student A

Base B
  +
R1 reasoning data
  ↓
Student B

Even though the teacher data is the same, the students may end up different because their pretrained representations and capabilities differ.

This is a very important lesson:

\boxed{\text{Distillation quality depends on both teacher and student}}

7. The really important experiment — same architecture

Now we get to the most revealing experiment.

The question was:

Suppose I have a Qwen2.5-32B model. Should I train it with large-scale RL, or distill it from a much larger reasoning teacher?

This gives us a controlled comparison because the model architecture is held constant.

DS-R1-Zero-32B

The same 32B base subjected to DeepSeek's RL-from-scratch style.

DS-R1-Distill-32B

The same general 32B architecture trained from R1's generated reasoning data with only SFT. (Source: Build a DeepSeek Model (From Scratch))

So conceptually:

                Qwen2.5-32B base

          ┌────────────┼────────────┐
          ▼            ▼            ▼
       RL path       RL path     Distill path
          │            │            │
       QwQ-32B     R1-Zero-32B   R1-Distill-32B

Difference:

That is an enormous gap.

11. Why is this result so surprising?

Because the two models have essentially the same:

\boxed{\text{architecture}}

same:

\boxed{\text{parameter count}}

same:

\boxed{\text{layer structure}}

same:

\boxed{\text{attention mechanism}}

The major difference is:

\boxed{\text{training procedure}}

One model spends large compute trying to discover reasoning itself.

The other receives demonstrations of reasoning discovered by a much stronger teacher.

(Source: Build a DeepSeek Model (From Scratch))

12. Direct RL is doing exploration

Think about the RL-trained 32B model.

It starts from the base model and must discover useful reasoning strategies through trial and error.

Conceptually:

Problem
   ↓
Generate attempt
   ↓
Reward
   ↓
Update policy
   ↓
Generate another attempt
   ↓
...
   ↓
discover useful strategy

This requires many iterations.

The source says the direct RL experiment involved more than:

\boxed{10,000\ \text{policy-gradient update steps}}

for the 32B comparison. (Source: Build a DeepSeek Model (From Scratch))

13. Distillation skips that discovery phase

The teacher has already performed the difficult exploration.

So the student receives:

Problem
   ↓
Teacher
   ↓
successful reasoning trace
   ↓
Student SFT

The student doesn't have to independently discover:

“This is the right way to break this problem down.”

It is shown the strategy directly.

14. Exploration versus imitation

This is the deepest conceptual lesson from the source:

\boxed{ \text{Exploration requires capacity} }

while:

\boxed{ \text{imitation can be much easier} }

The source argues that a large 671B teacher has enough capacity to explore, fail, recover, and ultimately discover effective strategies through RL.

A smaller student may not have enough capacity to discover those strategies independently.

But once the successful strategy is converted into training examples, the student only has to learn to reproduce it. (Source: Build a DeepSeek Model (From Scratch))

15. Why does this create such a big difference?

We can think of the search space as enormous:

\boxed{\text{possible reasoning trajectories}}

Direct RL must search that space.

Distillation gives the student a filtered subset:

\boxed{\text{successful trajectories}}

Therefore the learning problem changes from:

\text{search}

to:

\text{learn from demonstrations}.

That is why:

\boxed{ \text{Distillation can be dramatically more compute-efficient} }

for small models.

This is the source's interpretation of the experiment. (Source: Build a DeepSeek Model (From Scratch))

16. But don't conclude “RL is useless”

That would be the wrong lesson.

The source explicitly says the conclusion is not that DeepSeek's RL is weak.

Rather, the important observation is that:

\boxed{ 32B\text{ capacity can become a constraint for RL-from-scratch} }

while distillation provides a way around that limitation by transferring strategies discovered by a much larger teacher. (Source: Build a DeepSeek Model (From Scratch))

So the roles are different:

\boxed{ \text{Large RL} \rightarrow \text{discover} }
\boxed{ \text{Distillation} \rightarrow \text{transfer} }

17. Then why do we need a huge teacher at all?

Because someone still needs to discover the strong reasoning strategies.

The large model effectively pays the exploration cost.

Then the resulting behavior becomes reusable training data.

So the overall economic structure becomes:

            Large expensive teacher
                     │
                  RL cost
                     │
                     ▼
            strong reasoning
                     │
             data generation
                     │
                     ▼
             reusable dataset
                /    |    \
               /     |     \
              ▼      ▼      ▼
             1.5B    7B     32B
              SFT    SFT      SFT

The source explicitly highlights this reusability as one of distillation's strongest economic properties. (Source: Build a DeepSeek Model (From Scratch))

18. One teacher can serve many students

This is extremely important operationally.

Suppose you spend heavily to create the R1-generated dataset.

After the dataset exists:

D_{\text{R1}}

you can train:

1.5B,\ 7B,\ 14B,\ 32B,\ 70B,\ldots

students on the same data.

The teacher doesn't need to be rerun during each student's SFT.

The source describes this as a one-time data-generation investment that can support many students. (Source: Build a DeepSeek Model (From Scratch))

19. Scaling behavior

The source observes:

1.5B\rightarrow28.9\%
7B\rightarrow55.5\%
14B\rightarrow69.7\%
32B\rightarrow72.6\%.

So the general relationship is:

\boxed{\text{student capacity}\uparrow \Rightarrow \text{distilled performance}\uparrow}

although the improvement is not linear.

The gains become smaller as the student gets larger.

That's an important intuition:

\text{1.5B}\rightarrow7B

provides a huge improvement, while:

14B\rightarrow32B

provides a smaller improvement.

The source describes the trend as smooth scaling rather than a linear law. (Source: Build a DeepSeek Model (From Scratch))

20. Teacher ceiling

Even the best distilled model does not reach the teacher.

Source:

\text{R1}=79.8\%\ \text{AIME}

versus:

\text{R1-Distill-Qwen-32B}=72.6\%.

So:

\boxed{ \text{distillation is powerful but lossy} }

Some capability is inevitably lost during compression. (Source: Build a DeepSeek Model (From Scratch))

21. Capacity gap

This leads directly to the next concept.

Suppose:

T=\text{very powerful teacher}

and:

S=\text{tiny student}.

The student cannot represent everything the teacher knows.

Therefore:

\boxed{ \text{Teacher capability} > \text{Student capacity} }

creates a:

\boxed{\text{capacity gap}}.

The source uses the 1.5B results to demonstrate this very clearly. (Source: Build a DeepSeek Model (From Scratch))

22. Why math compresses better than coding

The source gives a concrete example.

1.5B model:

83.9\%\ \text{MATH}

but:

16.9\%\ \text{LiveCodeBench}.

(Source: Build a DeepSeek Model (From Scratch))

The source's explanation is that mathematical reasoning often has more structured, recurring solution patterns.

Coding has a much broader space involving:

\text{syntax} + \text{APIs} + \text{design patterns} + \text{error handling} + \text{implementation diversity}.

Thus:

\boxed{ \text{some knowledge compresses more easily than other knowledge} }

23. Knowledge frontier

There is an even deeper limit.

Suppose the teacher can't solve problem X.

Then rejection sampling does not produce a correct successful trace for X.

Therefore the student doesn't magically learn the solution.

So:

\boxed{ \text{distillation cannot transfer what the teacher doesn't possess} }

The source describes this as the knowledge frontier. (Source: Build a DeepSeek Model (From Scratch))

This is why the book says advancing beyond the teacher's capability can still require:

\boxed{\text{stronger base models + large-scale RL}}

rather than distillation alone.

24. This gives us the complete division of labor

Now the whole DeepSeek strategy becomes very elegant.

Large model

Use:

\boxed{\text{scale + RL + exploration}}

to discover powerful behaviors.

Small model

Use:

\boxed{\text{teacher demonstrations + SFT}}

to imitate those behaviors.

So:

\boxed{ \text{Discovery happens at the frontier} }

and:

\boxed{ \text{transfer happens downstream} }

25. Why the 32B experiment is more important than the 1.5B headline

The 1.5B result is exciting because it demonstrates compression.

But the 32B controlled experiment teaches us why compression works.

Because the same architecture gets:

47.0\%

through direct RL,

but:

72.6\%

through distillation.

Thus the experiment isolates:

\boxed{ \text{training method} }

as the major difference.

That's the real scientific lesson.

26. Put the entire argument together

We can now derive the story from first principles:

Large model
   │
   ├── has high capacity
   │
   ▼
RL exploration
   │
   ├── tries many strategies
   ├── fails
   ├── recovers
   └── discovers strong reasoning
   │
   ▼
Successful reasoning traces
   │
   ▼
Rejection sampling
   │
   ▼
High-quality dataset
   │
   ▼
Small pretrained model
   │
   ▼
SFT
   │
   └── learns demonstrated strategies
   ▼
Strong small reasoning model

This is the central mechanism behind the empirical results reported in the chapter. (Source: Build a DeepSeek Model (From Scratch))

27. The entire Chapter 8 in one equation

At a conceptual level:

\boxed{ \underbrace{ \text{Large-scale RL} }_{\text{discover}} \rightarrow \underbrace{ \text{reasoning traces} }_{\text{artifact}} \rightarrow \underbrace{ \text{rejection sampling} }_{\text{select}} \rightarrow \underbrace{ \text{SFT} }_{\text{transfer}} \rightarrow \underbrace{ \text{small model} }_{\text{deploy}} }

This is why the book calls distillation a bridge between frontier-scale intelligence and practical deployment. (Source: Build a DeepSeek Model (From Scratch))

1. Why can a 1.5B model be strong at reasoning?

Because it is learning from high-quality reasoning behavior generated by a much stronger teacher rather than having to discover everything itself. (Source: Build a DeepSeek Model (From Scratch))

2. Why does 32B distillation beat 32B direct RL?

The source reports 72.6\% AIME for the distilled model versus 47.0\% for the RL-trained model, suggesting that small-model RL-from-scratch is constrained by exploration/capacity, while distillation transfers strategies already discovered by the large teacher. (Source: Build a DeepSeek Model (From Scratch))

3. Why doesn't a larger student always win?

Because the student's pretrained base matters too; the source reports Qwen variants outperforming similarly sized Llama variants on the cited reasoning benchmark. (Source: Build a DeepSeek Model (From Scratch))

4. Why does the 1.5B model perform much better on math than coding?

Because the source argues that mathematical reasoning patterns are more compressible than the much broader knowledge and implementation space required for coding. (Source: Build a DeepSeek Model (From Scratch))

5. Can distillation exceed the teacher?

The source's framing is no: distillation transfers the teacher's existing capability and is lossy; pushing beyond the teacher's frontier requires stronger models and/or further large-scale RL. (Source: Build a DeepSeek Model (From Scratch))
