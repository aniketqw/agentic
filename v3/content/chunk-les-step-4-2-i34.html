Motivation

Expose teacher alternative preferences and derive the effect of temperature on forward probabilities and backward gradients.

Prerequisites

  • Softmax/log-softmax
  • Cross-entropy and directed KL
  • Chain rule and masked token reduction

Notation and units

  • Teacher logits v; student logits z; temperature tau>0
  • p_tau=softmax(v/tau), q_tau=softmax(z/tau)
  • alpha: hard-label weight; L=alpha CE(z, y)+(1-alpha)tau² KL(p_tau||q_tau)

Assumptions

  • Teacher detached/frozen
  • Aligned output classes/token vocabulary for direct KL
  • Natural logarithms, so losses are nats
  • One T² multiplication; loss reduction consistent across examples/tokens

Step-by-step derivation

  1. Divide logits by positive tau before stable softmax. Ranking stays unchanged.
  2. Probability ratio q_i/q_j=exp((z_i-z_j)/tau); log-odds shrink linearly with 1/tau.
  3. For finite logits, tau→0 chooses unique argmax; tied maxima share mass. tau→∞ yields uniform probabilities.
  4. Differentiate KL with teacher detached: ∂KL/∂z_i=(q_i-p_i)/tau.
  5. Center logits separately. At high tau, q_i-p_i≈(zcenter_i-vcenter_i)/(Ktau).
  6. Consequently tau²KL→||zcenter-vcenter||²/(2K); useful logit differences can survive even when raw distributions approach uniform. Temperature must be selected empirically, not by a universal 2–5 rule.

Step 4.2 — Temperature Scaling and “Dark Knowledge”

Plan node: I5 · chat order #34

We now reach the mathematical heart of classical knowledge distillation.

The problem from Step 4.1 was:

P_T(w)

at ordinary temperature T=1 is often too peaked.

For example:

[0.865,\ 0.117,\ 0.016,\ 0.002].

The information is technically there, but most of it is concentrated in the top class.

The solution introduced in the chapter is:

\boxed{\text{temperature scaling}}

which makes the teacher's distribution softer and exposes the relationships among alternatives. (Source: Build a DeepSeek Model (From Scratch))

1. Start from ordinary softmax

Given teacher logits:

z=[z_1,z_2,\ldots,z_K],

ordinary softmax is:

\boxed{ p_i= \frac{e^{z_i}} {\sum_j e^{z_j}} }

where:

  • z_i = logit for class/token i
  • p_i = probability assigned to class/token i
  • K = number of classes/tokens.

This is exactly the softmax you already learned earlier for LLM next-token prediction.

2. Add temperature

Temperature introduces one parameter:

\boxed{T>0}.

Instead of:

p_i= \frac{e^{z_i}} {\sum_j e^{z_j}},

we compute:

\boxed{ q_i(T) = \frac{e^{z_i/T}} {\sum_j e^{z_j/T}} }

The procedure is:

\boxed{ z \rightarrow \frac{z}{T} \rightarrow \text{softmax} }

The chapter gives exactly this formulation. (Source: Build a DeepSeek Model (From Scratch))

3. What does T actually do?

Do not think of temperature as “adding randomness.”

That interpretation is incomplete.

Temperature first changes the shape of the probability distribution.

T=1

Normal softmax:

q_i=p_i.
T>1

Divide logits by a larger number:

\frac{z_i}{T}

so the differences between logits become smaller.

Result:

\boxed{\text{flatter distribution}}
0<T<1

Differences become larger.

Result:

\boxed{\text{sharper distribution}}

The supplied chapter explicitly describes T>1 as softening the distribution. (Source: Build a DeepSeek Model (From Scratch))

4. The most useful mathematical interpretation

Look at the ratio of two probabilities.

Starting from:

q_i= \frac{e^{z_i/T}}{\sum_j e^{z_j/T}}

and:

q_k= \frac{e^{z_k/T}}{\sum_j e^{z_j/T}}.

Divide:

\frac{q_i}{q_k} = \frac{e^{z_i/T}}{e^{z_k/T}}

so:

\boxed{ \frac{q_i}{q_k} = e^{(z_i-z_k)/T} }

This equation is extremely important.

It tells us exactly what temperature does to relative preference.

5. Example of probability ratios

Suppose:

z_1=5,\qquad z_2=3.

Then:

z_1-z_2=2.

At T=1:

\frac{q_1}{q_2} = e^2 \approx7.39.

At T=2:

\frac{q_1}{q_2} = e^{2/2} = e \approx2.72.

At T=4:

\frac{q_1}{q_2} = e^{2/4} = e^{0.5} \approx1.65.

So increasing T compresses the teacher's preferences.

That is the mathematical meaning of “softening.”

6. Temperature does NOT change ranking

Suppose:

z_1>z_2>z_3.

For positive T:

\frac{z_1}{T}> \frac{z_2}{T}> \frac{z_3}{T}.

Softmax is monotonic in the logits.

Therefore:

\boxed{ \arg\max_i q_i(T) = \arg\max_i z_i }

for every positive T.

So temperature changes:

\boxed{\text{how strongly the model prefers the winner}}

but not:

\boxed{\text{who the winner is}}.

The supplied decoding slides make this same point explicitly: temperature changes distribution sharpness but not token ranking. (Source: decoding-sampling-slides)

7. This is why temperature is useful for distillation

Suppose the teacher says:

\text{Cat}>\text{Dog}>\text{Fox}>\text{Bird}.

At T=1, maybe:

[0.865,0.117,0.016,0.002].

The ordering exists, but:

0.016

and:

0.002

are extremely small.

At larger T, the same ordering remains:

\text{Cat}>\text{Dog}>\text{Fox}>\text{Bird}

but the differences become easier for the student to learn.

That's what the chapter means by exposing dark knowledge. (Source: Build a DeepSeek Model (From Scratch))

8. Full numerical example from the chapter

Teacher logits:

\boxed{ z=[5.0,3.0,1.0,-1.0] }

Corresponding classes:

[\text{cat},\text{dog},\text{fox},\text{bird}].

We will calculate:

T=1, \quad T=3, \quad T=10.

The chapter uses exactly these logits and temperatures. (Source: Build a DeepSeek Model (From Scratch))

9. Case 1 — T=1

We have:

z/T=[5,3,1,-1].

Exponentiate:

e^5\approx148.41
e^3\approx20.09
e^1\approx2.72
e^{-1}\approx0.37.

Sum:

148.41+20.09+2.72+0.37 = 171.59.

Normalize:

q= \left[ \frac{148.41}{171.59}, \frac{20.09}{171.59}, \frac{2.72}{171.59}, \frac{0.37}{171.59} \right]

giving:

\boxed{ q=[0.865,0.117,0.016,0.002] }

as reported in the chapter. (Source: Build a DeepSeek Model (From Scratch))

10. Interpret T=1

The teacher says:

\boxed{ 86.5\%\text{ cat} }
11.7\%\text{ dog}
1.6\%\text{ fox}
0.2\%\text{ bird}.

The top choice is obvious.

But the student has difficulty extracting the detailed relationship among:

\text{dog},\text{fox},\text{bird}.

That is the problem.

11. Case 2 — T=3

Now:

\frac zT = \left[ \frac53,\frac33,\frac13,-\frac13 \right].

Therefore:

\boxed{ z/T=[1.667,1.000,0.333,-0.333] }

The chapter then exponentiates:

e^{1.667}\approx5.30
e^1\approx2.72
e^{0.333}\approx1.40
e^{-0.333}\approx0.72.

Sum:

5.30+2.72+1.40+0.72 = 10.14.

Normalize:

q= \left[ \frac{5.30}{10.14}, \frac{2.72}{10.14}, \frac{1.40}{10.14}, \frac{0.72}{10.14} \right].

Therefore:

\boxed{ q=[0.523,0.268,0.138,0.071] }

This is the chapter's central numerical example. (Source: Build a DeepSeek Model (From Scratch))

12. Look what happened

At T=1:

[0.865,0.117,0.016,0.002].

At T=3:

[0.523,0.268,0.138,0.071].

The ranking is unchanged:

\boxed{ \text{cat}>\text{dog}>\text{fox}>\text{bird} }

but the alternatives are now visible.

The teacher is telling the student:

\boxed{ \text{cat is most likely} }

but also:

\boxed{ \text{dog is substantially more plausible than fox} }

and:

\boxed{ \text{fox is substantially more plausible than bird} }

That relational information is what the chapter calls dark knowledge. (Source: Build a DeepSeek Model (From Scratch))

13. Why does this help the student?

With hard labels:

[1,0,0,0]

the student gets:

Cat is correct.

With T=3:

[0.523,0.268,0.138,0.071]

the student gets:

Cat is most likely, dog is somewhat plausible, fox is less plausible, bird is least plausible.

Thus:

\boxed{ \text{one training example contains relational information} }

instead of only the identity of the correct class.

14. Case 3 — T=10

Now:

z/T = [0.5,0.3,0.1,-0.1].

Softmax gives approximately:

\boxed{ [0.329,0.270,0.221,0.181] }

according to the chapter. (Source: Build a DeepSeek Model (From Scratch))

Now the distribution is very flat.

15. Why is T=10 too high?

Compare:

\text{cat}=0.329

with:

\text{dog}=0.270.

The distinction is still there.

But compare the entire distribution:

[0.329,0.270,0.221,0.181].

It is approaching:

[0.25,0.25,0.25,0.25].

So the teacher is now becoming almost uninformative.

The chapter describes this as revealing so much information that the meaningful structure gets diluted. (Source: Build a DeepSeek Model (From Scratch))

16. The three regimes

We therefore have:

Low temperature
T\approx1

or below:

\boxed{\text{too sharp}}
Moderate temperature
T\approx2-5

in the chapter's discussion:

\boxed{\text{useful / Goldilocks zone}}
Very high temperature
T\gg5

:

\boxed{\text{too flat}}

The chapter explicitly describes a useful middle range around T=2–5, with the precise best value being task/model-dependent. (Source: Build a DeepSeek Model (From Scratch))

17. Limit T\to0^+

Let's derive an important mathematical limit.

Suppose:

z_1>z_2>\cdots>z_K.

As:

T\to0^+,

the largest logit dominates:

e^{z_1/T}\gg e^{z_2/T}.

Therefore:

\boxed{ q\rightarrow[1,0,\ldots,0] }

assuming a unique maximum.

So:

\boxed{ T\to0^+ \Rightarrow \text{one-hot distribution} }

This is why low temperature produces a very sharp output.

18. Limit T\to\infty

For very large T:

\frac{z_i}{T}\rightarrow0.

Therefore:

e^{z_i/T}\rightarrow1.

So:

q_i \rightarrow \frac1K.

Hence:

\boxed{ T\to\infty \Rightarrow \text{uniform distribution} }

For four classes:

\boxed{ q\rightarrow[0.25,0.25,0.25,0.25] }

This is exactly the qualitative behavior described in the chapter. (Source: Build a DeepSeek Model (From Scratch))

19. A very useful identity: subtracting the same constant

Remember from softmax:

\operatorname{softmax}(z) = \operatorname{softmax}(z-c)

for any constant c.

This remains true with temperature:

\boxed{ \operatorname{softmax}(z/T) = \operatorname{softmax}((z-c)/T) }

because:

e^{(z_i-c)/T} = e^{-c/T}e^{z_i/T}

and the common factor cancels.

This is why numerical implementations can safely compute:

\boxed{ q_i= \frac{ e^{(z_i-\max z)/T} }{ \sum_j e^{(z_j-\max z)/T} } }

to avoid overflow.

That is the same numerical-stability principle you learned earlier for ordinary softmax.

20. Temperature and entropy

There is another useful interpretation.

Entropy:

\boxed{ H(P) = -\sum_iP_i\log P_i }

measures uncertainty/spread.

As temperature rises:

T\uparrow \Rightarrow H(q_T)\uparrow

for a nonuniform original distribution.

So:

\boxed{ T\text{ higher} \Rightarrow \text{higher entropy} }

until the distribution approaches uniformity.

For K classes, the maximum entropy is:

\boxed{ H_{\max}=\log K }

which occurs at:

P_i=\frac1K.

21. Numerical entropy example

At T=10:

P=[0.329,0.270,0.221,0.181].

Entropy:

H = -\sum_i p_i\ln p_i.

Approx:

H\approx 0.366+0.354+0.333+0.309
\approx \boxed{1.36\text{ nats}}

whereas uniform four-class entropy is:

\log4 \approx \boxed{1.386\text{ nats}}.

So the T=10 distribution is already very close to maximum entropy.

22. The crucial distinction: decoding temperature vs distillation temperature

You've already learned temperature during text generation.

The formula is identical:

q_i= \frac{e^{z_i/T}} {\sum_j e^{z_j/T}}.

But the purpose is different.

During decoding

We use temperature to control the distribution from which we sample the next token.

\boxed{ T\rightarrow\text{generation diversity} }
During classical distillation

We use temperature to reveal the structure in the teacher's output distribution.

\boxed{ T\rightarrow\text{richer teaching signal} }

Same mathematics.

Different purpose.

23. This distinction matters for exams

Suppose the question says:

“Why does the teacher use T>1 during distillation?”

Don't answer:

“To make generation more random.”

The better answer is:

\boxed{ T>1\text{ softens teacher probabilities so that relative probabilities of alternative classes/tokens become visible.} }

The goal is to expose:

\boxed{\text{dark knowledge}}

to the student.

24. Another powerful derivation: log-odds

From:

\frac{q_i}{q_j} = e^{(z_i-z_j)/T},

take \log:

\log\frac{q_i}{q_j} = \frac{z_i-z_j}{T}.

Thus:

\boxed{ \text{log-odds} = \frac{\text{logit difference}}{T} }

This makes the role of temperature incredibly clear.

T=1

Full logit difference.

T=2

Half the logit difference.

T=4

Quarter of the logit difference.

Therefore:

\boxed{ T\text{ compresses relative logit differences} }

25. Why teacher logits are particularly valuable

Suppose teacher logits are:

[5,3,1,-1].

The raw differences are:

5-3=2
3-1=2
1-(-1)=2.

The teacher has a very clear ordering structure.

The softmax at T=1 hides much of it through exponentiation.

Temperature reduces the magnitude of those differences before exponentiation.

So:

\boxed{ \text{temperature does not invent information} }

It makes information already present in the logits more visible in the resulting probability distribution.

That's the correct interpretation of “dark knowledge.”

At:

At:

32. Why high temperature eventually becomes useless

Suppose:

T\rightarrow\infty.

Then:

q_i\rightarrow\frac1K.

All classes become equally likely.

Therefore the teacher's information disappears.

So we have:

\boxed{ T\text{ too low} \Rightarrow \text{dark knowledge hidden} }

and:

\boxed{ T\text{ too high} \Rightarrow \text{dark knowledge washed out} }

Therefore:

\boxed{ T\text{ should be intermediate} }

33. Important gradient insight

Now connect this to optimization.

Student soft distribution:

q_i = \operatorname{softmax}(z_i^S/T).

For softmax, the derivative with respect to student logit z_j^S has the temperature factor:

\boxed{ \frac{\partial q_i}{\partial z_j^S} = \frac1Tq_i(\delta_{ij}-q_j) }

where:

\delta_{ij} = \begin{cases} 1,&i=j\\ 0,&i\ne j. \end{cases}

The explicit 1/T comes from the fact that the logits are first divided by T.

34. Why does the chapter mention 1/T^2?

This is the next extremely important idea.

The soft distillation loss compares:

P_T(T)

and:

P_S(T).

At large T, both distributions become flatter.

Therefore:

P_S(T)-P_T(T)

also becomes smaller.

At the same time, the chain rule contributes an explicit:

\frac1T.

So the gradient magnitude becomes approximately:

\boxed{ \frac1{T^2} }

relative to the corresponding T=1-scale.

The chapter explicitly derives this point and states that the difference between the soft distributions itself shrinks with T, giving another 1/T factor. (Source: Build a DeepSeek Model (From Scratch))

35. Why this creates a problem

Suppose:

T=3.

Then:

T^2=9.

Without correction, the soft-target gradient would become much smaller.

If:

T=10,

then:

T^2=100.

The soft loss's gradient becomes dramatically weaker.

That would be disastrous because we deliberately increased T to reveal useful information.

So we need compensation.

That brings us directly to the next step.

36. The T^2 correction

The classical distillation soft loss is therefore multiplied by:

\boxed{T^2}.

Conceptually:

\boxed{ L_{\text{soft, corrected}} = T^2 D_{KL}(P_T^T\|P_S^T) }

where:

P_T^T = \operatorname{softmax}(z_T/T)

and:

P_S^T = \operatorname{softmax}(z_S/T).

The purpose is not to change the teacher distribution again.

The purpose is:

\boxed{ \text{restore the soft-loss gradient magnitude} }

after temperature softening.

The chapter explicitly explains this T^2 compensation. (Source: Build a DeepSeek Model (From Scratch))

37. Numerical understanding of T^2

Suppose:

T=3

and:

D_{KL}=0.0199.

Then:

T^2D_{KL} = 9(0.0199)
= \boxed{0.1791}.

The supplied chapter gives approximately:

\boxed{0.179}

for its example. (Source: Build a DeepSeek Model (From Scratch))

So the soft loss is:

\boxed{0.179}.

38. This is a crucial distinction

Temperature has two linked effects:

Forward effect
\boxed{ T\uparrow \Rightarrow \text{softer distribution} }
Backward compensation
\boxed{ T\uparrow \Rightarrow \text{soft gradient shrinks} \Rightarrow \times T^2 }

Therefore:

\boxed{ \text{temperature controls information exposure} }

while:

\boxed{ T^2\text{ keeps its optimization influence useful} }

43. Exam traps for this step

Trap 1

“Higher T changes the teacher's top class.”

\boxed{\text{False}}

Ranking stays unchanged for T>0.

Trap 2

“Temperature adds information.”

\boxed{\text{False}}

It makes existing information in the logits easier to observe through the probability distribution.

Trap 3

“T=10 is always better because it reveals more information.”

\boxed{\text{False}}

At very high T, the distribution approaches uniformity.

Trap 4

“T^2 makes the teacher distribution softer.”

\boxed{\text{False}}

Division by T softens the distribution.

Multiplication by T^2 compensates the gradient magnitude of the soft-loss term.

Trap 5

“DeepSeek-R1 distilled models use temperature-scaled KL distillation.”

\boxed{\text{False}}

The supplied chapter explicitly distinguishes R1's text-based SFT distillation from classical KD. (Source: Build a DeepSeek Model (From Scratch))
