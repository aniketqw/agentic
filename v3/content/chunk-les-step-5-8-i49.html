Step-by-step derivation

  1. Track correctness separately from total shaped reward; an auxiliary format reward can increase while genuine task accuracy falls.
  2. For V-token probabilities entropy lies in [0,ln V]. V=7 cannot have entropy above 1.945910149 nats; units and vocabulary must be fixed before thresholds are interpreted.
  3. Normalized advantages have near-zero group mean by construction. With negligible epsilon their std is fixed by the chosen ddof; very large std is not an independent ordinary healthy/unstable metric under that exact normalization.
  4. All-equal reward groups give zero policy-advantage gradient. KL, optimizer weight decay, stored momentum and other minibatch groups may still change parameters.
  5. R=correct+w*format permits wrong formatted outputs to collect w. Conditional shaping correct*(1+w*format) gives wrong outputs zero in the 0/1 convention.
  6. Reward rising, held-out accuracy falling, entropy collapsing and response length shrinking suggests reward gaming or distribution collapse; verify extraction, leakage and length truncation before naming a unique cause.

Step 5.8 — Reading and Debugging GRPO Training Dynamics

Plan node: I6 · chat order #49

We have finished the mathematical update itself. Now we need to answer a different question:

How do we know whether GRPO training is actually working?

This is important because a GRPO run can produce a decreasing/increasing loss while the reasoning ability itself gets worse. The source therefore shifts from the algorithm to training diagnostics and failure modes in Chapter 7. (Source: Build a Reasoning Model (From Scratch))

5.8.1 First principle: RL training is noisy

In ordinary supervised learning, we often expect something like:

L\downarrow

and:

\text{accuracy}\uparrow.

With GRPO, the source explicitly warns that the loss itself is less informative and is mainly a sanity check. Some fluctuations are expected, while large spikes are concerning. (Source: Build a Reasoning Model (From Scratch))

So do not use:

\boxed{\text{GRPO loss alone}}

as your definition of success.

Instead, look at several signals together.

5.8.2 The four basic metrics

The source's training analysis plots:

\boxed{\text{loss}}
\boxed{\text{reward\_avg}}
\boxed{\text{avg\_response\_len}}
\boxed{\text{eval\_acc}}

The evaluation accuracy is measured on MATH-500 in the source experiment. (Source: Build a Reasoning Model (From Scratch))

Let's understand each one.

5.8.3 Metric 1 — Average reward

Suppose a group contains:

R=[1,1,0,0].

Then:

R_{\text{avg}} = \frac{1+1+0+0}{4} = 0.5.

So:

\boxed{\text{reward\_avg}=0.5}

means half the sampled responses received reward 1 in this particular binary-reward setup.

The source says that an average reward of:

\boxed{1.00}

means all sampled responses are correct.

But there is a subtle consequence:

R_i=1\quad\forall i

means:

A_i=0\quad\forall i.

Therefore the relative learning signal disappears. The source says that when average reward reaches 1.00, further training is unlikely to be useful and early stopping can save resources. (Source: Build a Reasoning Model (From Scratch))

5.8.4 Why reward increasing is usually good

Suppose:

0.20\rightarrow0.35\rightarrow0.50\rightarrow0.70.

That generally means the sampled responses are receiving better verifier outcomes.

So initially:

\boxed{\text{reward}\uparrow}

is a healthy sign.

But now comes the important RL lesson:

\boxed{ \text{reward}\uparrow \not\Rightarrow \text{generalization}\uparrow }

The source actually shows a case where evaluation accuracy later declines even though reward stays high or relatively stable. (Source: Build a Reasoning Model (From Scratch))

5.8.5 Metric 2 — Average response length

Suppose the model generates:

100,\;150,\;220,\;300

tokens over successive stages.

Then the average response length is increasing.

Why is this interesting?

Because reasoning models may benefit from producing enough intermediate reasoning.

The source observes that response length should initially increase alongside improving accuracy in its training run. (Source: Build a Reasoning Model (From Scratch))

So initially:

\boxed{ \text{response length}\uparrow + \text{accuracy}\uparrow }

can be a healthy pattern.

5.8.6 But longer is not automatically better

This is critical.

Suppose:

\text{accuracy}=40\%\rightarrow42\%

but:

\text{response length}=200\rightarrow2000.

That does not mean the model learned ten times more reasoning.

It may simply be generating unnecessarily long responses.

Therefore response length is a diagnostic, not the optimization objective.

5.8.7 Metric 3 — Evaluation accuracy

This is perhaps the most important external sanity check.

Training reward is generated from the training process.

Evaluation accuracy asks:

Does the updated model actually solve unseen evaluation problems?

The source computes this using MATH-500. (Source: Build a Reasoning Model (From Scratch))

For example:

\text{eval\_acc} = \frac{\text{number correct}}{500}.

If:

375

out of 500 are correct:

\text{eval\_acc} = \frac{375}{500} = 0.75 = 75\%.

5.8.8 Why evaluation every step is expensive

The source notes that evaluation accuracy is not tracked at every step by default because doing so substantially slows training.

Instead, it can be computed periodically, such as at checkpoints. (Source: Build a Reasoning Model (From Scratch))

This gives us an important engineering tradeoff:

\boxed{ \text{more frequent evaluation} \rightarrow \text{better observability} \rightarrow \text{higher training cost} }

5.8.9 Metric 4 — Loss

The source specifically tells us to interpret GRPO loss differently from ordinary pretraining loss.

A rough conceptual expectation is:

\boxed{\text{loss should remain reasonably stable}}

rather than:

\boxed{\text{loss must monotonically decrease}}.

Large spikes are more concerning than small fluctuations. (Source: Build a Reasoning Model (From Scratch))

5.8.10 Why does the loss behave differently?

Because the training target itself is changing.

In supervised learning:

(x,y)

is fixed.

In GRPO:

x \rightarrow \text{sample responses} \rightarrow \text{verify} \rightarrow \text{advantages} \rightarrow \text{update policy}

and then the model changes, which changes future samples.

Therefore the training process is much more dynamic.

5.8.11 The first failure pattern: reward rises, then stalls

Consider:

0.1\rightarrow0.3\rightarrow0.5\rightarrow0.7\rightarrow0.72\rightarrow0.72.

Possible interpretation:

The model has improved, but is approaching the point where most sampled responses are already successful.

As reward approaches:

1.0,

the relative advantage signal becomes weaker because successful rollouts become more homogeneous.

The source explicitly points out that when all sampled responses are correct, the training signal disappears. (Source: Build a Reasoning Model (From Scratch))

5.8.12 The second failure pattern: reward rises, evaluation accuracy falls

This is much more serious.

Example:

Step       Reward      Eval Accuracy
------------------------------------
0          0.20        30%
100        0.45        45%
200        0.65        55%
300        0.72        52%
400        0.73        44%

A naive interpretation would be:

Reward increased, so training improved.

But the evaluation tells us:

55\%\rightarrow44\%.

The model got worse on the external task.

The source reports this kind of behavior in its unclipped training analysis: evaluation accuracy initially improves and later declines, indicating instability/problems in the training process. (Source: Build a Reasoning Model (From Scratch))

5.8.13 Why can this happen?

The source discusses instability as one likely explanation, while noting that harder later training examples alone would not explain the evaluation decline because evaluation uses the same fixed MATH-500 examples each time. (Source: Build a Reasoning Model (From Scratch))

So conceptually:

\boxed{ \text{training signal improves} }

while:

\boxed{ \text{general task performance deteriorates} }

is possible.

That is exactly why external evaluation is essential.

5.8.14 The third failure pattern: response length suddenly decreases

The format-reward experiment gives an especially useful example.

The source observes:

\boxed{ \text{accuracy drops sharply} }

while average response length decreases before later recovering. (Source: Build a Reasoning Model (From Scratch))

The source associates this decline in evaluation accuracy with the shorter responses produced after that point. (Source: Build a Reasoning Model (From Scratch))

This gives a useful diagnostic pattern:

reward ──────────────── relatively stable
accuracy ────────╲
response length ───────╲

So when accuracy falls, response length is one of the first things worth checking.

5.8.15 The fourth failure pattern: large loss spikes

Suppose:

L: \quad -0.3,-0.2,-0.4,-0.1,-5.2,-0.2

The source's interpretation is that occasional fluctuations are expected, but increasingly large spikes are concerning. (Source: Build a Reasoning Model (From Scratch))

This can indicate unstable updates.

That is one motivation for introducing:

\boxed{\text{clipped policy ratios}}

later in Chapter 7.

5.8.16 Now connect diagnostics to clipping

The source's clipped-ratio training run is more stable than the earlier run.

It reports:

  • no visible drop in average reward around the problematic later region,
  • no sudden decline in evaluation accuracy,
  • fewer worrying loss spikes.

(Source: Build a Reasoning Model (From Scratch))

So we can think of clipping as:

\boxed{\text{update stabilization mechanism}}

while the metrics act as:

\boxed{\text{instrument panel}}

You need both.

5.8.17 Advanced metric — Advantage mean and standard deviation

Recall:

A_i= \frac{R_i-\mu_R}{\sigma_R+\epsilon}.

The source tracks two summary statistics:

\boxed{\operatorname{mean}(A)}

and:

\boxed{\operatorname{std}(A)}.

(Source: Build a Reasoning Model (From Scratch))

Because the advantages are group-normalized, the mean is expected to be approximately zero.

The more interesting quantity for training dynamics is often:

\boxed{\operatorname{std}(A)}

because it tells us how much relative distinction exists between sampled responses.

5.8.18 Why advantage standard deviation matters

Imagine:

R=[0.5,0.51,0.50,0.51].

The rewards are almost identical.

Then:

R_i-\mu_R

are tiny.

So the group contains little relative information.

Contrast:

R=[1,1,0,0].

Now there is a strong distinction between good and bad rollouts.

Therefore intuitively:

\boxed{ \text{larger reward separation} \rightarrow \text{stronger relative learning signal} }

The source uses advantage statistics specifically to inspect these training dynamics. (Source: Build a Reasoning Model (From Scratch))

5.8.19 The extreme case

If:

R=[1,1,1,1],

then:

\mu_R=1

and:

R_i-\mu_R=0.

Therefore:

\boxed{A=[0,0,0,0]}.

Similarly:

R=[0,0,0,0]

also gives:

\boxed{A=[0,0,0,0]}.

The source explicitly emphasizes this behavior. (Source: Build a Reasoning Model (From Scratch))

5.8.20 Advanced metric — Entropy

Now we look at:

\boxed{ H(P)=-\sum_xP(x)\log P(x) }

for each generated token distribution.

The source calculates token-level entropy and then averages it across the generated answer tokens. (Source: Build a Reasoning Model (From Scratch))

5.8.21 Numerical entropy example

Suppose a vocabulary has only two possible tokens:

P=[0.9,0.1].

Then:

H = -(0.9\ln0.9+0.1\ln0.1).

Using:

\ln0.9\approx-0.1053

and:

\ln0.1\approx-2.3026,

we get:

H\approx0.325.

So the model is relatively confident.

5.8.22 Uniform distribution

For two tokens:

P=[0.5,0.5].

Then:

H = -(0.5\ln0.5+0.5\ln0.5)
=\ln2 \approx0.693.

Thus:

\boxed{\text{more uncertainty}\rightarrow\text{higher entropy}}

5.8.23 Source's rough entropy interpretation

The source gives rough rules of thumb:

0\text{–}0.5

→ very low entropy, highly confident.

1\text{–}2

→ moderate entropy.

High entropy approaching:

\log(|V|)

means probabilities are spread across many tokens. (Source: Build a Reasoning Model (From Scratch))

For the source's toy vocabulary:

|V|=7.

Maximum entropy:

H_{\max}=\ln7\approx1.9459.

5.8.24 Why entropy is useful in reasoning RL

Suppose:

H: 1.8\rightarrow1.5\rightarrow1.2\rightarrow0.8.

The model is becoming increasingly confident.

That can be healthy.

But suppose:

1.8\rightarrow1.3\rightarrow0.2

very rapidly.

That may indicate:

\boxed{\text{entropy collapse}}

where the policy becomes too deterministic too quickly.

The source explicitly identifies a sudden collapse to very low entropy as a warning sign of unstable training. (Source: Build a Reasoning Model (From Scratch))

5.8.25 Important distinction: low entropy is not automatically bad

A reasoning model eventually becoming more confident can be desirable.

The source actually says:

entropy should gradually decrease as the model becomes more confident.

The problem is sudden collapse, not merely decreasing entropy. (Source: Build a Reasoning Model (From Scratch))

So:

\boxed{ \text{gradual entropy decrease} \approx \text{potentially healthy} }

whereas:

\boxed{ \text{rapid entropy collapse} \approx \text{warning} }

5.8.26 Put the advanced metrics together

Now imagine this training history:

Step Reward Eval Acc Resp. Len Entropy
0 0.20 30% 180 1.80
100 0.40 42% 240 1.55
200 0.60 51% 310 1.30
300 0.68 54% 360 1.10
400 0.70 45% 180 0.30

Look carefully.

At step 400:

R\approx0.70

still looks good.

But:

\text{Eval Acc}:54\%\rightarrow45\%

and:

\text{Length}:360\rightarrow180

and:

H:1.10\rightarrow0.30.

That is a much stronger warning than reward alone.

5.8.27 This is why metrics must be interpreted jointly

Never say:

“Reward increased, therefore training succeeded.”

Instead ask:

\boxed{ \begin{aligned} &\text{Did reward improve?}\\ &\text{Did evaluation accuracy improve?}\\ &\text{Is response length sensible?}\\ &\text{Are loss spikes controlled?}\\ &\text{Are advantages providing useful variation?}\\ &\text{Is entropy changing gradually?} \end{aligned} }

That is the correct GRPO-debugging mindset.

5.8.28 Now the most interesting source experiment: format reward

So far the reward was primarily:

\boxed{\text{answer correctness}}

For example:

R_{\text{correct}}= \begin{cases} 1 & \text{correct}\\ 0 & \text{wrong} \end{cases}

The source then adds an auxiliary signal:

\boxed{\text{format reward}}.

(Source: Build a Reasoning Model (From Scratch))

5.8.29 What is the format reward?

The experiment wants the model to structure reasoning as:

<think>
reasoning...
</think>

\boxed{answer}

The source defines:

R_{\text{format}}= \begin{cases} 1 & \text{<think> appears before </think>}\\ 0 & \text{otherwise}. \end{cases}

(Source: Build a Reasoning Model (From Scratch))

5.8.30 Total reward with format

The source uses:

\boxed{ R= R_{\text{RLVR}} + w_fR_{\text{format}} }

where:

w_f=\text{format\_reward\_weight}.

(Source: Build a Reasoning Model (From Scratch))

Suppose:

R_{\text{correct}}=1

and:

R_{\text{format}}=1

with:

w_f=1.

Then:

R=1+1=2.

5.8.31 Why was this experiment done?

Because the researchers/book want to make the output structure explicit:

\boxed{ \text{reasoning} \rightarrow \text{final answer} }

The <think> markers separate those parts.

But now we have created a new problem:

What happens if the model learns to optimize format rather than correct reasoning?

And this is exactly what the source investigates.

5.8.32 The surprising result

In the source's format-reward run:

  • the model improves initially;
  • later evaluation accuracy becomes worse;
  • average reward stays approximately constant;
  • shorter response lengths correlate with the later accuracy decline.

(Source: Build a Reasoning Model (From Scratch))

This is a beautiful RL example of:

\boxed{\text{reward design matters}}

5.8.33 Why can this happen?

Suppose:

R_{\text{correct}}\in\{0,1\}

and:

R_{\text{format}}\in\{0,1\}.

With:

w_f=1,

consider these two responses:

Response A

Correct + correct format:

R=1+1=2.
Response B

Wrong + correct format:

R=0+1=1.

Therefore even a wrong answer gets positive reward.

The model receives reinforcement for:

\boxed{\text{format adherence}}

without necessarily receiving reinforcement for:

\boxed{\text{correctness}}.

The source gives this as one possible explanation for the observed degradation. (Source: Build a Reasoning Model (From Scratch))

5.8.34 This is a reward-hacking-like phenomenon

Conceptually:

What we want:

correct reasoning
      +
correct answer
      +
proper format

but our reward says:

correctness reward + format reward

The model can discover that format is an easier source of guaranteed reward.

Therefore:

\boxed{ \text{easy reward component} \rightarrow \text{can dominate harder reward component} }

This is one of the most important lessons from this experiment.

5.8.35 Proposed solution 1 — reduce format weight

The source suggests reducing:

w_f: 1.0\rightarrow0.1.

Then:

Correct + correctly formatted
R=1+0.1=1.1.
Wrong + correctly formatted
R=0+0.1=0.1.

The correctness signal now dominates much more strongly. (Source: Build a Reasoning Model (From Scratch))

5.8.36 Proposed solution 2 — conditional format reward

Instead of always granting the format reward, use:

\boxed{ R_{\text{format,new}} = R_{\text{format}} \cdot R_{\text{correct}} }

Therefore:

Correct + correct format
1\times1=1.
Wrong + correct format
1\times0=0.

So:

\boxed{\text{wrong answers receive no format bonus}}

The source gives precisely this conditional implementation. (Source: Build a Reasoning Model (From Scratch))

5.8.37 This creates a cleaner reward structure

Without conditioning:

R= R_c+w_fR_f.

With conditioning:

\boxed{ R= R_c+w_fR_fR_c }

or equivalently:

R= R_c(1+w_fR_f).

This means:

R_c=0 \Rightarrow R=0.

Thus the auxiliary reward cannot rescue an incorrect answer.

5.8.38 Numerical comparison

Take:

w_f=1.
Case 1: Correct + formatted
R_c=1,\quad R_f=1.

Unconditional:

R=2.

Conditional:

R=1+(1)(1)(1)=2.

No difference.

Case 2: Wrong + formatted
R_c=0,\quad R_f=1.

Unconditional:

R=1.

Conditional:

R=0.

Huge difference.

That is the entire motivation for the conditional reward.

5.8.39 Important tokenizer issue

There is another subtle implementation point.

The base model initially does not have <think> as one token in the source experiment.

The tokenizer encodes:

<think>

into several subword tokens.

The reasoning tokenizer instead has dedicated IDs:

\boxed{151667}

for <think> and:

\boxed{151668}

for </think>. (Source: Build a Reasoning Model (From Scratch))

The source says that simply training the base model with these new tokens would perform poorly because the base model has not previously encountered them in this form. (Source: Build a Reasoning Model (From Scratch))

5.8.40 Why this matters conceptually

A reward function can only reinforce behavior that the model can meaningfully represent.

If your tokenizer/model setup has no learned familiarity with a new special token, merely writing:

R_{\text{format}}=1

does not magically give the model a pretrained concept of that token.

So:

\boxed{ \text{reward design} + \text{tokenization/model support} }

must be considered together.

5.8.45 Exam numerical — advantage collapse

Given:

R=[1,1,1,1].

Mean:

\mu=1.

Therefore:

R_i-\mu=0.

Thus:

\boxed{A_i=0\;\forall i}.

Consequently:

\boxed{L_{\text{PG}}=0}.

No relative update occurs for that group. (Source: Build a Reasoning Model (From Scratch))

5.8.46 Exam numerical — diagnose the run

Suppose:

\text{reward}:0.3\rightarrow0.7
\text{eval accuracy}:45\%\rightarrow35\%
\text{response length}:500\rightarrow150
\text{entropy}:1.2\rightarrow0.2.

What should you conclude?

Not:

“Reward improved, so training succeeded.”

The stronger diagnosis is:

\boxed{ \text{possible instability / collapse} }

because reward improved while external accuracy dropped, response length sharply shortened, and entropy collapsed.

This interpretation is consistent with the source's observed failure patterns. (Source: Build a Reasoning Model (From Scratch))

5.8.47 The deepest idea from this step

There are three levels of success:

Level 1 — The optimizer is numerically running

Gradients exist and parameters change.

Level 2 — The reward improves

The verifier likes the sampled behavior more.

Level 3 — Actual reasoning ability improves

External evaluation improves.

The real objective is:

\boxed{ \text{Level 3} }

not merely Level 2.

5.8.48 Step 5.8 master summary

Remember this diagnostic sequence:

\boxed{ \text{Reward} \rightarrow \text{Accuracy} \rightarrow \text{Length} \rightarrow \text{Advantage stats} \rightarrow \text{Entropy} \rightarrow \text{Stability} }

And for reward engineering:

\boxed{ R=R_{\text{correct}}+w_fR_{\text{format}} }

can be problematic when the auxiliary reward is too strong.

A safer source-proposed variant is:

\boxed{ R = R_{\text{correct}} + w_fR_{\text{format}}R_{\text{correct}} }

so that format cannot compensate for incorrectness. (Source: Build a Reasoning Model (From Scratch))
