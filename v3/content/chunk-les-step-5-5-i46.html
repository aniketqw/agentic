Step-by-step derivation

  1. Store detached log probabilities from the policy that actually generated the data. Re-evaluate the same action under the current policy.
  2. Compute r=exp(logp_new-logp_old), avoiding direct products of tiny probabilities.
  3. Form min(rA,clip(r,1-epsilon,1+epsilon)A) as a maximized surrogate, then negate it for a minimized loss.
  4. When A>0, r above 1+epsilon receives no additional beneficial incentive. When A<0, r below 1-epsilon receives no additional beneficial incentive.
  5. Clipping does not enforce a hard bound on actual probability ratios or KL. Shared parameters and other loss terms can move the ratio outside the interval.
  6. Epsilon=10 gives [-9,11]; since ratios are nonnegative the lower clipping threshold is inactive. This is weak asymmetric practical control, not [1/11,11].

Continuation · checked fixture R02 — Clipped surrogate and advantage sign

Checked continuation mechanism and declared fixture; this is not certification of every inherited claim.

Discourage some large policy changes while retaining a useful reward gradient.

Prerequisites: Group advantages and standard-deviation conventions, Conditional sequence probability and log likelihood

Notation and assumptions

Ratio=current/old probability on fixed sampled actions. Maximization objective uses min(rA,clip(r)A); minimization negates it.

Derivation and mechanism

  1. Compute ratio by exponentiating a difference of log probabilities.
  2. Clamp ratio to[1-epsilon,1+epsilon].
  3. Multiply both original and clamped ratios by A, take the smaller, then apply declared token/sequence reduction.
J=\min(rA,\operatorname{clip}(r,1-\epsilon,1+\epsilon)A)

Worked example

epsilon.2: r1.5,A2→min3,2.4=2.4. r.5,A-2→min-1,-1.6=-1.6. r1.5,A-2→-3. Blindly clipping the ratio alone gives the wrong last value.

Limitations

  • Clipping is not a hard trust-region or KL guarantee.
  • Sequence ratios, geometric-mean ratios and token ratios are different objectives.

Connections to later concepts

  • R03 measures drift against a reference, whereas the clipped ratio compares the current policy with an old rollout policy.

Step 5.5 — Why Plain Policy Gradient Is Not Enough: Policy Ratios and Clipping

Plan node: I6 · chat order #46

We now move from the simplified Chapter 6 objective to the stabilized GRPO formulation introduced in Chapter 7.

The source's sequence is:

\text{plain policy gradient} \rightarrow \text{old/current policy comparison} \rightarrow \text{policy ratio} \rightarrow \text{clipping} \rightarrow \text{clipped GRPO loss}.

The reason for this extra machinery is simple:

\boxed{\text{Do not let one update change the policy too aggressively.}}

The source explicitly motivates clipped policy ratios as a way to limit overly large updates and improve training stability. (Source: Build a Reasoning Model (From Scratch); rl-grpo-slides)

1. What was wrong with our previous loss?

We previously had:

L_{\text{PG}} = -\frac{1}{N} \sum_i A_i\log\pi_\theta(o_i\mid q).

This says:

  • positive advantage → increase probability;
  • negative advantage → decrease probability.

That is correct.

But there is a problem.

Suppose the model sees one lucky high-reward rollout and, after an update, its probability changes enormously.

For example:

\pi_{\text{old}}(o)=0.01

but after one update:

\pi_{\text{new}}(o)=0.5.

Then:

\frac{\pi_{\text{new}}}{\pi_{\text{old}}} = 50.

That is a massive change.

The source describes exactly this concern: a sampled rollout can receive disproportionately large influence if its probability under the updated policy becomes much larger or smaller than under the old policy. (Source: Build a Reasoning Model (From Scratch))

2. The key idea: compare old and new policies

We therefore introduce two policies.

Old policy
\boxed{\pi_{\theta_{\text{old}}}}

This is the policy that generated the rollout.

Current policy
\boxed{\pi_\theta}

This is the policy we are currently optimizing.

Now ask:

How much has the current policy changed its probability for this exact sampled response?

That gives us the policy ratio.

3. Policy ratio

For a rollout o_i:

\boxed{ r_i(\theta) = \frac{\pi_\theta(o_i\mid q)} {\pi_{\theta_{\text{old}}}(o_i\mid q)} }

Interpretation:

If
r_i=1

then:

\pi_\theta(o_i\mid q) = \pi_{\theta_{\text{old}}}(o_i\mid q)

so the policy has not changed its probability.

If
r_i>1

the current model considers the rollout more likely.

If
r_i<1

the current model considers it less likely.

The source defines the ratio in implementation through old and new sequence log probabilities. (Source: Build a Reasoning Model (From Scratch))

4. Why do we calculate this with log probabilities?

Directly computing:

\frac{\pi_{\text{new}}}{\pi_{\text{old}}}

for long sequences is inconvenient.

But:

\log\frac{p_{\text{new}}}{p_{\text{old}}} = \log p_{\text{new}} - \log p_{\text{old}}.

Therefore:

\boxed{ r_i = \exp( \log p_i^{\text{new}} - \log p_i^{\text{old}} ) }

This is exactly how the source implements it:

log_ratio = new_logps - old_logps
ratio = torch.exp(log_ratio)

(Source: Build a Reasoning Model (From Scratch))

5. Simple numerical example

Suppose:

\log p_{\text{old}}=-3

and:

\log p_{\text{new}}=-2.

Then:

\log r = -2-(-3) = 1.

Therefore:

r=e^1\approx2.718.

So:

\boxed{r\approx2.72}

means the current policy assigns about 2.72 times as much probability to that response.

6. Another example: policy becomes less likely

Suppose:

\log p_{\text{old}}=-2

and:

\log p_{\text{new}}=-4.

Then:

\log r=-4-(-2)=-2

and:

r=e^{-2}\approx0.1353.

Thus:

\boxed{r\approx0.135}

The new policy assigns only about 13.5% of the old probability.

7. Why is the ratio dangerous?

Suppose:

A=+1.

A good rollout should be reinforced.

If:

r=1.2,

the reinforcement is moderate.

But if:

r=100,

the same rollout can dominate the update.

Similarly, if a bad rollout has:

A=-1

and:

r=0.001,

the update can become disproportionately strong.

The source describes clipping as a “seatbelt” that prevents one noisy sample from dominating the update. (Source: rl-grpo-slides)

Complete grounded review

8. The clipping operation

We restrict the ratio to:

[1-\epsilon,1+\epsilon].

So:

\boxed{ r_{\text{clip}} = \operatorname{clip}(r,1-\epsilon,1+\epsilon) }

For example, if:

\epsilon=0.2,

then:

1-\epsilon=0.8

and:

1+\epsilon=1.2.

Therefore:

r=1.5

becomes:

1.2.

And:

r=0.5

becomes:

0.8.

9. Why “1 ± epsilon”?

Because:

r=1

means:

\text{new policy}=\text{old policy}

for that rollout.

Therefore the clipping region is centered around no change:

1.

We permit some movement:

1-\epsilon \le r\le 1+\epsilon

but suppress extreme movement.

10. Important: clipping itself is not the final objective

We don't simply replace:

r

with:

\operatorname{clip}(r).

We combine both through the clipped policy objective.

The source uses:

unclipped = ratio * adv
clipped = clipped_ratio * adv
obj = torch.minimum(unclipped, clipped)

and then:

clipped_pg_loss = -torch.mean(obj)

(Source: Build a Reasoning Model (From Scratch))

Mathematically:

\boxed{ L_{\text{clip}} = - \mathbb E \left[ \min \left( rA, \operatorname{clip}(r,1-\epsilon,1+\epsilon)A \right) \right] }

This is the PPO-style clipped structure used in the source's GRPO extension.

11. Why do we use minimum?

This is the subtle part.

We want clipping to prevent a beneficial-looking update from becoming too beneficial in magnitude.

Consider a positive advantage:

A>0.

Suppose:

r=2

and:

\epsilon=0.2.

Then:

rA=2A

while:

r_{\text{clip}}A=1.2A.

Taking:

\min(2A,1.2A)=1.2A.

So the update gets capped.

12. What about a negative advantage?

Suppose:

A<0.

Take:

A=-1

and:

r=0.5.

With:

\epsilon=0.2,

the clipped ratio is:

0.8.

Then:

rA=(0.5)(-1)=-0.5

and:

r_{\text{clip}}A=(0.8)(-1)=-0.8.

Now:

\min(-0.5,-0.8)=-0.8.

The more restrictive term is selected.

This sign behavior is why the objective uses:

\boxed{\min(rA,\operatorname{clip}(r)A)}

rather than simply clipping r everywhere.

Now return to our four rollouts.

The source has:

[-7.9243,-20.1546,-16.6130,-23.3677]
Old logprobs
[-10.9243,-20.3546,-14.6130,-23.3677].

(Source: Build a Reasoning Model (From Scratch))

For rollout 1:

\log r_1 = -7.9243-(-10.9243) = 3.

r_1=e^3.

Thus:

\boxed{r_1=20.0855}

15. Second ratio

\log r_2 = -20.1546-(-20.3546) = 0.2.

Therefore:

r_2=e^{0.2}.

So:

\boxed{r_2=1.2214}.

\log r_3 = -16.6130-(-14.6130) = -2.

Therefore:

r_3=e^{-2}
\boxed{r_3=0.1353}.

\boxed{ r=[20.0855,1.2214,0.1353,1.0] }

18. Now apply clipping

The source uses:

\epsilon=10.

Therefore:

1+\epsilon=11

and:

1-\epsilon=-9.

Since ratios cannot be negative, the meaningful upper restriction here is:

r\le11.

Thus:

20.0855\rightarrow11

while:

1.2214\rightarrow1.2214
0.1353\rightarrow0.1353
1.0\rightarrow1.0.

So:

\boxed{ r_{\text{clip}} = [11,1.2214,0.1353,1.0] }

exactly as in the source. (Source: Build a Reasoning Model (From Scratch))

19. Why does the first rollout get clipped?

Because:

20.0855>11.

That means the new policy has increased its probability for that sampled rollout enormously relative to the old policy.

The clipping mechanism says:

\boxed{ \text{“That is too large for one update.”} }

So instead of using:

20.0855,

we use:

11.

20. Why didn't the other ratios change?

Because:

1.2214<11
0.1353>-9

and:

1.0<11.

Thus they are already inside the allowed clipping range.

The source notes that only the first ratio gets clipped in this example. (Source: Build a Reasoning Model (From Scratch))

21. Now combine ratios with advantages

Recall:

A= [0.8659,0.8659,-0.8659,-0.8659].

Calculate:

\text{unclipped}=rA

and:

\text{clipped}=r_{\text{clip}}A.

For rollout 1:

r_1A_1 = 20.0855(0.8659) \approx17.392.

Clipped:

11(0.8659) = 9.5249.

Therefore:

\min(17.392,9.5249) = \boxed{9.5249}.

So the enormous 20.09 multiplier is not allowed to dominate.

22. Rollout 2

1.2214(0.8659) \approx1.0576.

Since it was not clipped:

\boxed{1.0576}.

23. Rollout 3

Here:

A_3=-0.8659

and:

r_3=0.1353.

Therefore:

0.1353(-0.8659) \approx \boxed{-0.1172}.

The clipped value is identical because the ratio was already inside the range.

24. Rollout 4

1(-0.8659) = \boxed{-0.8659}.

Again no clipping.

25. Final clipped objective terms

We therefore have approximately:

\boxed{ [9.5249,\;1.0576,\;-0.1172,\;-0.8659] }

and:

L_{\text{clip}} = -\frac14 (9.5249+1.0576-0.1172-0.8659).

The source reports:

\boxed{ L_{\text{clip}}\approx-2.3998 }

compared with the previous:

\boxed{ L_{\text{PG}}=-2.5764. }

(Source: Build a Reasoning Model (From Scratch))

26. What did clipping actually accomplish?

Without clipping, rollout 1 contributed:

17.392

to the objective.

With clipping:

9.5249.

Therefore the contribution was deliberately reduced.

This is the key effect:

\boxed{ \text{large policy change} \rightarrow \text{limited influence} }

27. The best intuition

Imagine four students solving the same problem.

One student happens to give a correct answer.

The model update begins strongly favoring that student's exact response.

But what if the probability increase is caused by a noisy, accidental update?

Without clipping:

\text{one sample} \rightarrow \text{huge update}.

With clipping:

\text{one sample} \rightarrow \text{bounded influence}.

That is why the source compares clipping to a safety mechanism for preventing overly aggressive policy movement. (Source: rl-grpo-slides)

28. Why is it called “proximal”?

The goal is to keep the new policy reasonably close to the policy that produced the data.

Conceptually:

\boxed{ \pi_{\text{new}} \approx \pi_{\text{old}} }

rather than:

\pi_{\text{new}} \gg \pi_{\text{old}}.

The source connects this mechanism directly to PPO's clipped policy-ratio idea. (Source: Build a Reasoning Model (From Scratch))

29. Important source detail: DeepSeek-R1 used weak clipping

The source reports:

\boxed{\epsilon=10}

for DeepSeek-R1 in this context.

That is much wider than a conventional PPO example such as:

\epsilon=0.1.

The source explicitly contrasts these: \epsilon=10 provides weak clipping, whereas 0.1 gives much tighter control. (Source: Build a Reasoning Model (From Scratch))

So don't blindly memorize:

\epsilon=0.2

as “the GRPO value.”

The important concept is:

\boxed{ \text{epsilon controls how much policy movement is tolerated} }

and the source-specific example uses 10.

30. Why old logprob must be stored

Suppose we generated a rollout under:

\pi_{\theta_{\text{old}}}.

Later the model changes.

If we don't keep:

\log p_{\text{old}},

we can't compute:

r= \exp(\log p_{\text{new}}-\log p_{\text{old}}).

Therefore, rollout generation and optimization are connected by stored old-policy information.

The source describes exactly this workflow: generate a fixed rollout set, compute old logprobs, compute new logprobs under the changing model, then update. (Source: Build a Reasoning Model (From Scratch))

31. Large-scale DeepSeek-R1 workflow

The source describes a larger-scale procedure:

  1. Make a copy of the current model as the reference/old policy.
  2. Generate a large rollout pool.
  3. Hold the rollouts fixed.
  4. Split them into minibatches.
  5. Calculate old logprobs.
  6. Calculate new logprobs under the changing policy.
  7. Update the current model.
  8. Later refresh the reference model.

The source reports an example with:

\boxed{8192}

responses and:

\boxed{16}

minibatches. (Source: Build a Reasoning Model (From Scratch))

32. Why hold rollouts fixed?

Because then:

\pi_{\text{old}}

has a clear meaning.

The response was actually generated by that fixed policy.

We can then ask:

\boxed{ \text{How much did the current policy move away from the policy that generated this data?} }

That gives us a meaningful importance ratio.

A=2, \qquad r=1.8, \qquad \epsilon=0.2.

Unclipped:

rA=1.8(2)=3.6.

Clipped:

1.2(2)=2.4.

Therefore:

\min(3.6,2.4) = \boxed{2.4}.

The huge update is limited.

38. Level 3 negative-advantage numerical

Given:

A=-2, \quad r=0.5, \quad \epsilon=0.2.

Clipped ratio:

0.8.

Unclipped:

0.5(-2)=-1.

Clipped:

0.8(-2)=-1.6.

Therefore:

\min(-1,-1.6) = \boxed{-1.6}.

This negative-advantage case is exactly why you should not casually reason about clipping without considering the sign of A.

39. Level 4 numerical

Suppose:

B=4,\quad G=8,\quad T=256.

Then:

A\in\mathbb R^{4\times8}.

Old logprobs:

[4,8,256].

New logprobs:

[4,8,256].

Ratios:

[4,8,256].

After token-wise loss reduction, the final policy loss is:

\boxed{\text{one scalar}}.

40. The most important distinction so far

We now have three different quantities:

Reward
\boxed{R_i}

answers:

Was the rollout successful?

Advantage
\boxed{A_i}

answers:

Was this rollout better or worse than the other rollouts for this prompt?

Policy ratio
\boxed{r_i}

answers:

How much did the current policy change its probability relative to the old policy?

These are not interchangeable.

41. Put all three together

The learning signal is:

A_i.

The current-vs-old policy movement is:

r_i.

The clipped objective combines them:

\boxed{ \min(r_iA_i,\operatorname{clip}(r_i)A_i) }

This one expression is the bridge between:

\boxed{\text{relative reward}}

and:

\boxed{\text{stable policy update}}.

42. The hierarchy of objectives

We have now built three increasingly sophisticated levels:

Level 1 — basic RL idea
\boxed{ R\log\pi }
Level 2 — relative GRPO signal
\boxed{ A\log\pi }
Level 3 — clipped objective
\boxed{ \min(rA,\operatorname{clip}(r)A) }

Then the next step adds another constraint:

\boxed{\text{KL regularization against a reference model}}

which prevents the policy from drifting too far from a chosen reference distribution.

The source introduces that in Chapter 7 immediately after clipped ratios. (Source: Build a Reasoning Model (From Scratch))

Step 5.5 master equations

Policy ratio
\boxed{ r_i(\theta) = \frac{\pi_\theta(o_i\mid q)} {\pi_{\theta_{\mathrm{old}}}(o_i\mid q)} }
Log-prob implementation
\boxed{ r_i = \exp( \log p_i^{\text{new}} - \log p_i^{\text{old}} ) }
Clipped ratio
\boxed{ r_i^{\text{clip}} = \operatorname{clip} (r_i,1-\epsilon,1+\epsilon) }
Clipped policy objective
\boxed{ L_{\text{clip}} = - \mathbb E \left[ \min \left( r_iA_i,\, r_i^{\text{clip}}A_i \right) \right] }

The source's actual worked example gives:

\boxed{ r_{\text{clip}}=[11,1.2214,0.1353,1.0] }

and:

\boxed{ L_{\text{clip}}=-2.3998 }

compared with:

\boxed{ L_{\text{PG}}=-2.5764. }
