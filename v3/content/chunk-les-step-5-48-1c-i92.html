Motivation

Understand why later-horizon losses modify earlier MTP modules and the shared base representation.

Prerequisites

  • Causal next-token likelihood
  • Embedding and output projections
  • Softmax cross entropy
  • Chain rule and sequence masking

Notation and units

  • S: total available tokens; T: input tokens when extra target supplied
  • k>=1: additional prediction module; D: module count
  • d: hidden width; V: vocabulary size; lambda: auxiliary loss weight
  • h_i^k: representation at base position i and depth k

Assumptions

  • All toy numerical inputs and normalization conventions are stated explicitly.
  • The teaching companion requires NumPy and runs on CPU; it claims no production backend execution.
  • Teacher-forced conditioning ends strictly before every scored target; attention/document masks preserve causality.

Step-by-step derivation

  1. For h^k=f_k(h^(k-1), e_k), a loss L_j sends a vector-Jacobian product through every f_k with k<=j, unless an implementation detaches that path.
  2. Parameters of module k receive sum over j>=k of lambda/D times their path derivatives. Shared embeddings/output parameters sum contributions from every occurrence.
  3. For scalar surrogate h1=a*h0, h2=b*h1 and half squared losses, dL/da=c[(h1-y)h0+(h2-y)b*h0], dL/db=c(h2-y)h1, where c=lambda/2.
  4. Repeated small Jacobian factors can shrink gradient magnitude. Long paths do not prove planning or beneficial learning; those are empirical questions.

Step 5.48.1C — Backpropagation Through the DeepSeek MTP Chain

Plan node: A3 · chat order #92

↩ Back to main text: Step 1.1 — What Exactly Is a Language Model? · Step 2.5 — Putting the Decoding Strategies Together

We now reach the part that explains why the causal MTP architecture actually changes learning.

Forward pass told us:

h^0\rightarrow h^1\rightarrow h^2\rightarrow h^3

with losses:

L_1,\;L_2,\;L_3.

Now we ask:

When L_3 is wrong, which part of the model gets corrected?

The answer is the heart of causal MTP:

\boxed{ L_3 \rightarrow MTP_3 \rightarrow MTP_2 \rightarrow MTP_1 \rightarrow \text{main Transformer}. }

That follows from the recurrent hidden-state dependency described by the source. The source explicitly says each refined hidden state becomes the input to the next MTP module, and that the resulting losses provide a richer, multi-faceted gradient signal. (Source: Build a DeepSeek Model (From Scratch))

5.48.1C.1 First recall the forward chain

For three prediction depths:

h^0 \rightarrow h^1 \rightarrow h^2 \rightarrow h^3.

More explicitly:

h^1=f_1(h^0,e_1)
h^2=f_2(h^1,e_2)
h^3=f_3(h^2,e_3)

where:

  • f_1 = MTP-1 module,
  • f_2 = MTP-2 module,
  • f_3 = MTP-3 module,
  • e_k = relevant future-token embedding.

Each produces logits:

z_1=W_{out}h^1
z_2=W_{out}h^2
z_3=W_{out}h^3.

And losses:

L_1=\operatorname{CE}(z_1,y_1)
L_2=\operatorname{CE}(z_2,y_2)
L_3=\operatorname{CE}(z_3,y_3).

The source describes this sequential computation and the summed depth-wise losses. (Source: Build a DeepSeek Model (From Scratch))

5.48.1C.2 The total objective

The source implementation gives:

\boxed{ L_{\text{total}} = L_{\text{main}} + \frac{\lambda}{D} \sum_{k=1}^{D}L_k }

so for D=3:

\boxed{ L_{\text{total}} = L_{\text{main}} + \frac{\lambda}{3}(L_1+L_2+L_3). }

(Source: Build a DeepSeek Model (From Scratch))

Define:

\alpha=\frac{\lambda}{D}.

Then:

L_{\text{total}} = L_{\text{main}} + \alpha L_1 + \alpha L_2 + \alpha L_3.

5.48.1C.3 First understand ordinary backpropagation

For a simple network:

x \rightarrow f \rightarrow g \rightarrow L

the chain rule gives:

\boxed{ \frac{\partial L}{\partial x} = \frac{\partial L}{\partial g} \frac{\partial g}{\partial f} \frac{\partial f}{\partial x}. }

The important principle is:

\boxed{ \text{later loss can affect earlier layers}. }

MTP simply makes the dependency chain longer and richer.

5.48.1C.4 A loss at MTP-1

Consider:

L_1.

It depends on:

h^1.

And:

h^1=f_1(h^0,e_1).

Therefore:

\frac{\partial L_1}{\partial h^0} = \frac{\partial L_1}{\partial h^1} \frac{\partial h^1}{\partial h^0}.

So:

\boxed{ L_1\rightarrow MTP_1\rightarrow h^0. }

Nothing surprising yet.

5.48.1C.5 Now the important one: MTP-2

MTP-2 loss depends on:

h^2.

But:

h^2=f_2(h^1,e_2).

And:

h^1=f_1(h^0,e_1).

Therefore:

\frac{\partial L_2}{\partial h^0} = \frac{\partial L_2}{\partial h^2} \frac{\partial h^2}{\partial h^1} \frac{\partial h^1}{\partial h^0}.

So the gradient from L_2 travels through:

\boxed{ MTP_2 \rightarrow MTP_1 \rightarrow \text{main Transformer}. }

This is the first major difference from independent heads.

5.48.1C.6 Now MTP-3

We have:

h^3=f_3(h^2,e_3)
h^2=f_2(h^1,e_2)
h^1=f_1(h^0,e_1).

Therefore:

\boxed{ \frac{\partial L_3}{\partial h^0} = \frac{\partial L_3}{\partial h^3} \frac{\partial h^3}{\partial h^2} \frac{\partial h^2}{\partial h^1} \frac{\partial h^1}{\partial h^0}. }

The gradient travels through all three MTP modules.

So:

\boxed{ L_3 \rightarrow MTP_3 \rightarrow MTP_2 \rightarrow MTP_1 \rightarrow h^0. }

This is the mathematical meaning of causal latent refinement.

The source itself does not spell out these Jacobian equations, so this gradient derivation is a mathematical consequence of the architecture described in the source. The source does explicitly state that the refined hidden state from one module becomes the input to the next and that the resulting objective provides a richer gradient signal. (Source: Build a DeepSeek Model (From Scratch))

5.48.1C.7 Why this is different from independent heads

Suppose we instead had:

h^0\rightarrow Head_1
h^0\rightarrow Head_2
h^0\rightarrow Head_3.

Then:

L_3

would affect Head 3 and h^0, but it would not pass through Head 2 and Head 1.

Graphically:

                 h⁰
              /   |   \
             ▼    ▼    ▼
            H1   H2   H3
            │    │    │
           L1   L2   L3

DeepSeek causal MTP is:

                 h⁰
                  │
                  ▼
                 MTP1
                  │
                 h¹
                  │
                  ▼
                 MTP2
                  │
                 h²
                  │
                  ▼
                 MTP3
                  │
                 h³

So:

\boxed{ L_3\text{ can train MTP1 and MTP2 indirectly}. }

That is the structural reason the causal design differs from independent prediction heads. (Source: Build a DeepSeek Model (From Scratch))

5.48.1C.8 All losses reaching the main hidden state

Now combine all three paths.

The total loss is:

L= L_{\text{main}}+\alpha L_1+\alpha L_2+\alpha L_3.

Therefore:

\frac{\partial L}{\partial h^0} = \frac{\partial L_{\text{main}}}{\partial h^0} + \alpha\frac{\partial L_1}{\partial h^0} + \alpha\frac{\partial L_2}{\partial h^0} + \alpha\frac{\partial L_3}{\partial h^0}.

And:

\frac{\partial L_1}{\partial h^0} = \frac{\partial L_1}{\partial h^1} \frac{\partial h^1}{\partial h^0}
\frac{\partial L_2}{\partial h^0} = \frac{\partial L_2}{\partial h^2} \frac{\partial h^2}{\partial h^1} \frac{\partial h^1}{\partial h^0}
\frac{\partial L_3}{\partial h^0} = \frac{\partial L_3}{\partial h^3} \frac{\partial h^3}{\partial h^2} \frac{\partial h^2}{\partial h^1} \frac{\partial h^1}{\partial h^0}.

So the main Transformer receives:

\boxed{ \text{main-loss gradient} + \text{depth-1 gradient} + \text{depth-2 gradient} + \text{depth-3 gradient}. }

This is the mathematical meaning of the source's statement about a “rich, multi-faceted gradient signal.” (Source: Build a DeepSeek Model (From Scratch))

5.48.1C.9 Which modules receive which gradients?

This is an excellent exam question.

MTP-1 parameters

They receive gradient from:

\boxed{ L_1+L_2+L_3 }

because all three losses depend, directly or indirectly, on h^1.

MTP-2 parameters

They receive gradient from:

\boxed{ L_2+L_3 }
MTP-3 parameters

They receive gradient from:

\boxed{ L_3 }
Main Transformer

It receives:

\boxed{ L_{\text{main}}+L_1+L_2+L_3 }

through their respective paths.

This is a derived consequence of the causal computation graph.

5.48.1C.11 Numerical gradient-routing example

Let's simplify every derivative to scalar values just to understand the chain rule.

Suppose:

\frac{\partial L_3}{\partial h^3}=2

and:

\frac{\partial h^3}{\partial h^2}=0.5
\frac{\partial h^2}{\partial h^1}=0.8
\frac{\partial h^1}{\partial h^0}=0.6.

Then:

\frac{\partial L_3}{\partial h^0} = 2\times0.5\times0.8\times0.6.

Calculate:

2\times0.5=1
1\times0.8=0.8
0.8\times0.6 = \boxed{0.48}.

Therefore:

\boxed{ \frac{\partial L_3}{\partial h^0}=0.48. }

This is a toy scalar illustration; real neural-network gradients are vectors/Jacobians or efficiently computed vector-Jacobian products.

5.48.1C.12 Now include all three MTP losses

Suppose:

\alpha=0.1.

And suppose the gradients with respect to h^0 are:

\frac{\partial L_1}{\partial h^0}=0.50
\frac{\partial L_2}{\partial h^0}=0.40
\frac{\partial L_3}{\partial h^0}=0.48

and:

\frac{\partial L_{\text{main}}}{\partial h^0}=1.20.

Then:

\frac{\partial L_{\text{total}}}{\partial h^0} = 1.20 + 0.1(0.50) + 0.1(0.40) + 0.1(0.48).

Therefore:

1.20+0.05+0.04+0.048 = \boxed{1.338}.

So the main representation is receiving a combined training signal.

5.48.1C.13 Why this can improve long-range learning

Standard NTP gives:

h_t\rightarrow x_{t+1}.

The hidden state is optimized primarily through the immediate next-token objective.

Causal MTP creates:

h_t \rightarrow x_{t+1}

and through refinement:

h_t \rightarrow x_{t+2}

and:

h_t \rightarrow x_{t+3}.

Therefore the representation at h^0 receives training pressure from multiple horizons.

The source interprets this as helping the model learn longer-range coherence, forecasting, and planning. (Source: Build a DeepSeek Model (From Scratch))

5.48.1C.14 A very important misconception

Do not say:

“MTP makes the model predict the future perfectly three tokens ahead.”

That is not what the loss means.

It means:

\boxed{ \text{the training objective contains prediction tasks at multiple future depths}. }

The model is still learning probability distributions:

P(t_{i+k}\mid \text{available representation})

and can make mistakes.

MTP changes what the model is trained to optimize, not the guarantee of prediction accuracy.

5.48.1C.15 Another important misconception

Do not say:

“The model backpropagates through the sampled token.”

The architecture described by the source uses the ground-truth future token embedding during training. (Source: Build a DeepSeek Model (From Scratch))

So the differentiable path is through:

h^{k-1}

and the corresponding embedding representation, rather than through a discrete sampling operation.

5.48.1C.16 Gradient also reaches the embedding matrix

This is another useful implementation detail.

The source uses:

future_token_embeds = self.get_embedding(future_token_ids)

(Source: Build a DeepSeek Model (From Scratch))

Therefore, during training, gradients can flow into the shared embedding parameters through the future-token embedding path.

At the same time, the source ties the LM-head weights to the embedding weights:

self.shared_lm_head.weight = self.shared_embed.weight

(Source: Build a DeepSeek Model (From Scratch))

So the shared embedding/output weight can receive gradient contributions from multiple paths.

This is an implementation-level consequence rather than a separate MTP principle.

5.48.1C.17 Think of the gradient as multiple teaching signals

For h^0:

                  Main loss
                     │
                     ▼
                    h⁰
                  ▲ ▲ ▲
                 /  |  \
                /   |   \
              L1    L2    L3

The deeper losses are not merely extra numbers added to the final scalar.

They create different computational paths through the network.

Therefore:

\boxed{ \text{one representation} \leftarrow \text{multiple future-oriented correction signals}. }

That is much closer to what the source means by denser or richer supervision. (Source: Build a DeepSeek Model (From Scratch))

5.48.1C.18 Why the early module gets more gradient sources

For D=4:

h^0\rightarrow MTP_1\rightarrow MTP_2\rightarrow MTP_3\rightarrow MTP_4.

Then:

MTP_4

is directly involved only in:

L_4.

But:

MTP_1

lies on paths for:

L_1,L_2,L_3,L_4.

Therefore:

\boxed{ \text{early MTP modules receive supervision from more horizons}. }

This is one mathematical interpretation of why deeper future-prediction objectives can influence earlier representations.

5.48.1C.19 But more gradient is not automatically better

Important caution.

More training signals do not mathematically guarantee better performance.

There can be:

  • conflicting gradients,
  • optimization difficulty,
  • computational cost,
  • sensitivity to the MTP loss weight \lambda.

The source presents MTP as beneficial and reports improved data efficiency/forecasting, but these are empirical claims rather than a theorem that “more losses always improve a model.” (Source: Build a DeepSeek Model (From Scratch))

So:

\boxed{ \text{richer supervision}\neq\text{guaranteed improvement}. }

5.48.1C.20 Why \lambda matters

Recall:

L= L_{\text{main}} + \frac{\lambda}{D} \sum_kL_k.

Suppose:

\lambda=0.

Then:

L=L_{\text{main}}.

MTP contributes nothing to optimization.

At the other extreme, if \lambda is made very large, MTP losses can dominate the objective.

Thus:

\boxed{ \lambda \text{ controls how strongly MTP influences training}. }

In the source verification implementation:

\lambda=0.1.

(Source: Build a DeepSeek Model (From Scratch))

5.48.1C.21 Exam numerical: effect of \lambda

Suppose:

D=4

and:

L_1=0.5,\quad L_2=0.6,\quad L_3=0.7,\quad L_4=0.8.

Then:

\sum L_k=2.6.

With:

\lambda=0.2,

the MTP contribution is:

\frac{0.2}{4}(2.6) = 0.05\times2.6 = \boxed{0.13}.

If:

L_{\text{main}}=0.9,

then:

\boxed{ L_{\text{total}}=1.03. }

5.48.1C.22 Exam numerical: identify gradient paths

Suppose:

D=3.

Which losses can update the parameters of MTP-2?

Answer:

\boxed{ L_2,L_3. }

Why?

Because:

L_2\rightarrow MTP_2

and:

L_3\rightarrow MTP_3\rightarrow MTP_2.

But:

L_1

does not pass through MTP-2.

Therefore:

\boxed{ \nabla_{\theta_2}L_{\text{total}} \text{ contains contributions from }L_2,L_3, }

plus any scaling by \lambda/D.

5.48.1C.23 Exam numerical: gradient path through a chain

Suppose:

\frac{\partial L_3}{\partial h^3}=3
\frac{\partial h^3}{\partial h^2}=0.4
\frac{\partial h^2}{\partial h^1}=0.5
\frac{\partial h^1}{\partial h^0}=0.2.

Then:

\frac{\partial L_3}{\partial h^0} = 3(0.4)(0.5)(0.2).

Therefore:

3(0.4)=1.2
1.2(0.5)=0.6
0.6(0.2) = \boxed{0.12}.

5.48.1C.24 One subtle issue: vanishing gradients

The scalar example also reveals something important.

If every derivative factor is less than 1, their product can become small.

For example:

0.5^5=0.03125.

Therefore, longer chains can introduce gradient attenuation.

Real Transformers use residual connections, normalization, carefully chosen initialization, and other mechanisms to make deep optimization practical.

This is general deep-learning reasoning, not an explicit claim made by the MTP section of the source.

The source itself does not discuss vanishing/exploding gradients in its MTP treatment, so this point should be treated as supporting mathematical context rather than source-derived content.

5.48.1C.25 The most important comparison

Independent MTP heads
h^0\rightarrow H_1\rightarrow L_1
h^0\rightarrow H_2\rightarrow L_2
h^0\rightarrow H_3\rightarrow L_3

Gradient:

L_3\rightarrow H_3\rightarrow h^0.
DeepSeek causal MTP
h^0\rightarrow MTP_1\rightarrow h^1
h^1\rightarrow MTP_2\rightarrow h^2
h^2\rightarrow MTP_3\rightarrow h^3.

Gradient:

L_3 \rightarrow MTP_3 \rightarrow MTP_2 \rightarrow MTP_1 \rightarrow h^0.

Therefore:

\boxed{ \text{DeepSeek causal MTP couples the prediction depths through hidden states.} }

That is the key distinction.

5.48.1C.26 Why this matters for “planning”

The source repeatedly frames MTP as helping the model with longer-range coherence and forecasting/planning. (Source: Build a DeepSeek Model (From Scratch))

The mathematical intuition is:

\boxed{ h^0 \text{ is no longer trained only for the immediate next token}. }

It is also indirectly trained so that its refined descendants:

h^1,h^2,h^3,\ldots

can support increasingly distant future predictions.

So the representation must contain information useful beyond the immediate next step.

That is the connection:

\boxed{ \text{multi-horizon supervision} \rightarrow \text{future-aware representations}. }

5.48.1C.28 What the optimizer ultimately sees

The optimizer does not receive:

L_1,L_2,L_3

as three separate optimization steps.

It receives a single objective:

\boxed{ L_{\text{total}} = L_{\text{main}} + \frac{\lambda}{D} \left(L_1+L_2+\cdots+L_D\right). }

Automatic differentiation then computes the gradient of this scalar with respect to all model parameters.

Thus:

\boxed{ \theta \leftarrow \theta-\eta\nabla_\theta L_{\text{total}}. }

where:

  • \theta = all trainable parameters,
  • \eta = learning rate.

The source's implementation adds the weighted MTP loss to the main loss before returning the total loss. (Source: Build a DeepSeek Model (From Scratch))
