Motivation

Adapt the candidate count to the probability mass rather than a fixed count.

Prerequisites

  • Normalized probabilities
  • Sorting
  • Cumulative sums

Notation and units

  • Nucleus minimal sorted prefix with cumulative mass >=p
  • Threshold p in (0,1]
  • Retained mass is actual prefix sum, not threshold itself

Assumptions

  • Stable tie policy
  • Temperature applied before measuring mass
  • Normalize any prior top-k filter before top-p if top-p is defined relative to that filtered distribution

Adapt the retained token count to the distribution rather than fixing it.

Prerequisites: Top-k support and renormalization

Notation and assumptions

Mass threshold p in (0,1]. Descending sort; keep the token that first reaches or crosses the threshold.

Derivation and mechanism

  1. Accumulate sorted probabilities.
  2. Stop when total reaches p.
  3. Renormalize using accumulated mass, which may exceed p.

Worked example

For [.5,.3,.15,.05], threshold.75 retains [.5,.3], total.8. Correct new distribution [.625,.375,0,0] divides by.8, not.75. At threshold.8, the same two tokens suffice.

Limitations

  • Rounded displayed PMFs can differ from the full-precision boundary.
  • Temperature before top-p changes the selected support.

Connections to later concepts

  • Q01-style rounding of displayed probabilities can change a nucleus boundary; retain full precision during accumulation.

Step 2.4 — Top-p / Nucleus Sampling

Plan node: I2 · chat order #24

We have now seen:

\boxed{\text{Greedy}}
\boxed{\text{Beam search}}
\boxed{\text{Temperature}}
\boxed{\text{Top-k sampling}}

The problem with top-k was:

k is fixed.

Whether the model is extremely confident or highly uncertain, we always keep exactly k candidates.

Top-p solves this by making the candidate set adaptive to the probability distribution.

Your decoding slides define top-p, also called nucleus sampling, as truncating by cumulative probability rather than by count. (Source: decoding-sampling-slides)

2.4.1 The Core Idea

Suppose the model predicts:

P= [0.50,0.20,0.15,0.08,0.04,0.03].

Instead of saying:

"Keep the top 3."

we say:

"Keep enough of the most probable tokens so that their cumulative probability reaches at least p."

For example:

p=0.90.

Accumulate:

0.50

then:

0.50+0.20=0.70

then:

0.70+0.15=0.85

then:

0.85+0.08=0.93.

We have crossed 0.90.

Therefore the nucleus is:

\boxed{ \{1,2,3,4\} }

containing 4 tokens.

Notice:

\boxed{k\text{ is not specified}.}

The distribution itself determines how many tokens survive.

2.4.2 Why Do We Need Top-p?

Recall the weakness of top-k.

Consider two distributions.

Distribution A — very confident
[0.90,0.05,0.02,0.01,0.01,0.01]
Distribution B — uncertain
[0.20,0.18,0.17,0.15,0.12,0.10,0.08]

Suppose:

k=3.

Top-k gives:

A
[0.90,0.05,0.02]
B
[0.20,0.18,0.17]

But in B, many additional tokens are also plausible.

Top-p adapts automatically.

So:

\boxed{ \text{Top-k adapts to rank count} }

while:

\boxed{ \text{Top-p adapts to probability mass}. }

2.4.3 Definition

Let the token probabilities be sorted in descending order:

q_{(1)}\ge q_{(2)}\ge\cdots\ge q_{(V)}.

For a chosen threshold:

p\in(0,1],

we find the smallest set of tokens whose cumulative probability is at least p.

Formally:

\boxed{ V^{(p)} = \arg\min_{S} \left\{ |S|: \sum_{v\in S}q(v)\ge p \right\} }

with the tokens selected from highest probability downward.

The slide expresses the same idea as the smallest set satisfying the cumulative-probability condition. (Source: decoding-sampling-slides)

2.4.4 The Most Important Phrase

Memorize this:

\boxed{ \text{Top-p = smallest set whose cumulative probability }\ge p }

That one sentence solves most conceptual questions.

2.4.5 Step-by-Step Algorithm

Given the model probabilities:

q_1,q_2,\ldots,q_V
Step 1

Sort tokens by probability:

q_{(1)}\ge q_{(2)}\ge\cdots\ge q_{(V)}.
Step 2

Compute cumulative sums:

c_j=\sum_{i=1}^{j}q_{(i)}.
Step 3

Find the first j such that:

c_j\ge p.
Step 4

Keep those j tokens.

Step 5

Remove the rest.

Step 6

Renormalize probabilities over the retained tokens.

So:

\boxed{ \text{sort} \rightarrow \text{cumulative sum} \rightarrow \text{stop at }p \rightarrow \text{filter} \rightarrow \text{renormalize} \rightarrow \text{sample} }

2.4.6 Why Do We Sort?

Because top-p wants the most probable tokens first.

Suppose:

P=[0.10,0.50,0.05,0.35].

We must sort:

[0.50,0.35,0.10,0.05].

Otherwise a random ordering could cause us to include low-probability tokens before high-probability ones.

So:

\boxed{ \text{Top-p operates on probabilities ordered from largest to smallest}. }

2.4.8 The Nucleus Does Not Need to Sum Exactly to p

This is a very important exam point.

We wanted:

p=0.90.

But our cumulative probability became:

0.9266.

Not:

0.9000.

Why?

Because we cannot usually include a fraction of a token.

Therefore top-p takes the smallest complete set that crosses the threshold.

So:

\boxed{ \text{cumulative probability can exceed }p. }

It does not have to equal p.

2.4.9 Renormalization

After filtering we retain:

[0.8062,0.0662,0.0542].

Their sum is:

0.9266.

But probabilities must sum to 1.

Therefore:

P'_i=\frac{P_i}{0.9266}.

For FRANCE:

P'(\text{FRANCE}) = \frac{0.8062}{0.9266} \approx0.8701.

For EUROPE:

P'(\text{EUROPE}) = \frac{0.0662}{0.9266} \approx0.0714.

For THE:

P'(\text{THE}) = \frac{0.0542}{0.9266} \approx0.0585.

Thus:

\boxed{ [0.8701,\;0.0714,\;0.0585,\;0]. }

These are the renormalized values shown on the slide. (Source: decoding-sampling-slides)

2.4.10 Why Renormalization Is Necessary

Before filtering:

\sum_iP_i=1.

After filtering:

\sum_{i\in Nucleus}P_i=0.9266.

But sampling requires:

\sum_iP_i'=1.

Therefore:

\boxed{ P_i'= \frac{P_i} {\sum_{j\in Nucleus}P_j} }

for retained tokens.

The removed tokens receive:

\boxed{0}.

2.4.14 Top-p Is Adaptive

We can state the key idea mathematically:

\boxed{ |V^{(p)}| \text{ depends on the shape of the probability distribution}. }

For a flat distribution:

|V^{(p)}|

This is why nucleus sampling is often described as an adaptive candidate set.

2.4.17 This Is Why Top-p Is Different From Top-k

Top-k:

\boxed{|S|=k}

Top-p:

\boxed{ \sum_{i\in S}P_i\ge p }

with S chosen minimally.

Therefore:

\boxed{ \text{Top-k asks "how many?"} }

while:

\boxed{ \text{Top-p asks "how much probability mass?"} }

This is probably the single most important comparison for this section.

2.4.18 What Does p=0.90 Actually Mean?

It does not mean:

keep exactly 90% of the vocabulary.

It means:

keep the smallest set of highest-probability tokens whose total probability mass is at least 90%.

For example, if vocabulary size is:

50,000,

top-p might retain:

5

tokens in one context and:

500

in another.

So:

\boxed{ p\text{ is a probability-mass threshold, not a vocabulary percentage}. }

2.4.19 Very Important: Top-p Uses Probabilities

Top-k can be naturally described using logits because selecting the largest logits gives the same ranking as selecting the largest probabilities.

But top-p requires cumulative probability mass.

So the clean conceptual pipeline is:

\boxed{ z \rightarrow softmax \rightarrow sort probabilities \rightarrow cumulative sum \rightarrow top-p filter \rightarrow renormalize \rightarrow sample }

The source slide describes top-p directly using the probability distribution. (Source: decoding-sampling-slides)

2.4.20 Where Does Temperature Fit?

Recall temperature:

q_i(T) = \frac{e^{z_i/T}} {\sum_j e^{z_j/T}}.

Top-p is usually applied to the resulting probability distribution.

So conceptually:

\boxed{ \text{logits} \rightarrow \text{temperature} \rightarrow \text{softmax} \rightarrow \text{top-p} \rightarrow \text{renormalize} \rightarrow \text{sample} }

The precise implementation ordering can vary, but the mathematical role is clear:

  • temperature changes the distribution;
  • top-p chooses the probability-mass nucleus.

For exam questions, follow the ordering specified in the question/source.

2.4.21 Temperature Can Change the Top-p Candidate Set

This is different from top-k.

For positive T, temperature preserves the ranking.

But it changes the probability values.

Since top-p depends on cumulative probability, temperature can therefore change how many tokens are needed to reach p.

This is an important distinction:

\boxed{ \text{Temperature does not change top-k membership} }

but:

\boxed{ \text{Temperature can change top-p membership}. }

Why?

Because top-k only cares about ranking.

Top-p cares about cumulative probabilities.

2.4.24 The Renormalization Formula

Let the nucleus be:

V^{(p)}.

Then:

\boxed{ q'(v)= \begin{cases} \dfrac{q(v)} {\sum_{u\in V^{(p)}}q(u)}, &v\in V^{(p)}\\[8pt] 0, &\text{otherwise} \end{cases} }

This is exactly the mathematical structure displayed in the decoding slide. (Source: decoding-sampling-slides)

2.4.25 Why Does the Source Say "Nucleus"?

The retained tokens collectively form a high-probability core of the distribution.

That core is called the:

\boxed{\text{nucleus}}.

Instead of exploring the entire vocabulary, sampling occurs inside this high-probability region.

Smaller p:

\boxed{\text{smaller candidate set}}

usually.

Larger p:

\boxed{\text{larger candidate set}}

usually.

p=0.90

might keep 3–10 tokens.

could keep many tokens.

The exact count depends on the distribution.

2.4.33 A Very Powerful Mental Model

Imagine 100,000 vocabulary tokens.

Top-k says:

"Give me the best 50."

No matter what the model thinks.

Top-p says:

"Give me enough of the best tokens to cover 90% of the probability mass."

Thus the second strategy asks the model's uncertainty to determine the candidate count.

2.4.34 Connection to Temperature

Now the whole picture becomes:

Low temperature

Distribution becomes sharp.

Top-p nucleus often becomes:

\boxed{\text{small}}

because a few tokens contain most of the probability.

High temperature

Distribution becomes flatter.

Top-p nucleus often becomes:

\boxed{\text{larger}}

because more tokens are needed to reach the same probability mass.

This is one reason temperature and top-p interact strongly.

2.4.35 Top-p + Sampling

Suppose after top-p we obtain:

P'=[0.70,0.20,0.10].

Top-p does not mean:

\text{choose }0.70\text{ token}.

Instead we sample:

y_t\sim P'.

So:

\boxed{ 70\%\rightarrow\text{first token} }
20\%\rightarrow\text{second}
10\%\rightarrow\text{third}.

This maintains stochasticity.

2.4.36 Top-p Does Not Mean "Top Probability"

Another common misunderstanding:

\boxed{ \text{Top-p}\neq\text{pick the single token with highest probability}. }

That would be greedy decoding.

Instead:

\boxed{ \text{Top-p defines the allowed candidate set}. }

Sampling then chooses from that set.

Then:

\boxed{ \text{append token} \rightarrow \text{run again}. }

2.4.43 Exam-Level Conceptual Question

Question

Why can temperature change the top-p candidate set but not the positive-temperature top-k candidate set?

Answer

For T>0, temperature divides every logit by the same positive number, so ranking does not change:

z_i>z_j \Rightarrow \frac{z_i}{T}>\frac{z_j}{T}.

Therefore top-k membership remains unchanged.

However, temperature changes the probability magnitudes after softmax. Since top-p depends on the cumulative probability mass, changing those probabilities can change how many tokens are required to cross p.

Hence:

\boxed{ \text{Top-k depends on ranking} }

while:

\boxed{ \text{Top-p depends on probability mass}. }

2.4.44 Exam-Level Conceptual Question

Why is top-p usually more adaptive than top-k?

Because the candidate count is not fixed.

Top-p chooses:

\boxed{ \text{the smallest candidate set that covers a chosen probability mass}. }

Therefore the number of candidates can increase when the distribution becomes flatter and decrease when it becomes sharper.

2.4.45 Another Important Connection — Entropy

We previously introduced entropy:

H(P)=-\sum_iP_i\log P_i.

High entropy means the distribution is relatively spread out.

Low entropy means it is concentrated.

Therefore, intuitively:

\boxed{ \text{high entropy} \Rightarrow \text{top-p may need more tokens} }

while:

\boxed{ \text{low entropy} \Rightarrow \text{top-p may need fewer tokens}. }

This is not an explicit additional formula in the decoding slide, but it follows directly from the cumulative-probability definition.

2.4.46 Top-k and Top-p Together

They can both be applied.

For example:

k=50

and:

p=0.90.

Conceptually:

  1. Limit to a maximum candidate pool with top-k.
  2. Within that distribution, apply the nucleus threshold.
  3. Sample.

The exact order and implementation depend on the decoding system, so in an exam or source-specific question we should follow the stated procedure rather than assume a universal implementation.

2.4.47 What the Slides Recommend

Your decoding slides summarize the typical use cases as:

  • tasks with one/few correct outputs → beam search is often used;
  • tasks with many valid outputs such as chat, stories, brainstorming → temperature + top-k and/or top-p;
  • exact reproducibility → greedy decoding.

(Source: decoding-sampling-slides)

So top-p is part of the stochastic decoding family, not a replacement for beam search in every task.

2.4.48 The Three Most Important Equations So Far

Temperature
\boxed{ q_i(T)= \frac{e^{z_i/T}} {\sum_j e^{z_j/T}} }
Top-k
\boxed{ S_k=\text{indices of the }k\text{ largest logits} }

and:

\boxed{ z_i'= -\infty \quad\text{for }i\notin S_k. }
Top-p
\boxed{ V^{(p)} = \text{smallest set such that } \sum_{v\in V^{(p)}}q(v)\ge p. }

These three equations represent three different controls:

\boxed{ T=\text{reshape} }
\boxed{ k=\text{fixed count} }
\boxed{ p=\text{probability mass}. }

2.4.49 Master Comparison

Think of the decoder asking three different questions:

Temperature

How sharply should I distribute probability?

Top-k

How many of the highest-ranked candidates am I allowed to consider?

Top-p

How much total probability mass should my candidate set contain?

That is the conceptual foundation.

2.4.50 Final Numerical Checklist for Top-p

When you see a top-p numerical in the exam, immediately do:

\boxed{1.\ \text{Sort probabilities descending}}
\boxed{2.\ \text{Compute cumulative sum}}
\boxed{3.\ \text{Stop at the first cumulative}\ge p}
\boxed{4.\ \text{Discard the rest}}
\boxed{5.\ \text{Renormalize}}
\boxed{6.\ \text{Sample from the new distribution}}

Do not stop merely because you are "close" to p.

You stop only when:

\boxed{\text{cumulative}\ge p}.
