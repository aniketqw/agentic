Motivation

Control the distribution used at generation time with operations whose retained support, normalization and representation inputs can be inspected.

Prerequisites

  • Stable softmax, probability normalization and entropy in nats.
  • Temperature, top-k, top-p and cosine similarity.

Notation and units

  • q(v): normalized next-token probability after the declared temperature.
  • b: relative min-p cutoff; Z: retained probability mass.
  • alpha: confidence/similarity tradeoff; z: logit; theta: repetition factor.

Assumptions

  • Every candidate probability is finite and nonnegative and sums to one. Include cutoff equality and break typicality ties by token ID.
  • Hidden vectors used for cosine are nonzero; the fixture computes them explicitly, but does not obtain them from a pretrained model.

Step-by-step derivation

  1. Compute c=b*max(q). Keep each q(v)>=c, then divide surviving probabilities by their actual sum Z. A maximum always survives for 0<b<=1, including every tied maximum when b=1.
  2. Typical sampling computes H=-sum(q*ln(q)), then ranks by abs(-ln(q(v))-H). Accumulate this ranking until the target mass is reached, and normalize by the selected mass rather than the threshold.
  3. Seen positive logits are divided by theta; seen negative logits are multiplied by theta. With theta>1 both changes lower the score; duplicate token IDs are processed once.
  4. Contrastive search scores (1-alpha)*q(v)-alpha*max_context cosine(h_v,h_context) inside its declared candidate set. Our fixture computes scalar dot products and norms before selection.
  5. Beam search accumulates sequence log probabilities across partial hypotheses. It does not measure correctness directly; pruning, stopping and length normalization change the selected sequence. Mirostat feedback updates a control state from observed surprise and a target; its full truncation algorithm remains variant-specific.

Corrections and source qualifications

    Mastery answers and retained exercise context

    1. Why normalize by Z? Because the retained mass need not equal the chosen threshold.
    2. Does b=1 imply one token? No: every tied maximum survives under cutoff equality.
    3. Why multiply a negative seen logit? Division makes it less negative and increases its relative score.
    4. Is typical sampling equivalent to top-p? No: the former ranks surprise deviation, the latter probability.

    Edge cases and remaining gaps

    • No full pretrained generation or quality comparison is executed. Mirostat feedback alone does not implement its candidate truncation.
    • Processor ordering changes the resulting distribution; record temperature, penalties, filter sequence, seed, stop conditions and tokenizer.
    • Required repeated symbols may be suppressed; hidden similarity does not certify factual correctness.

    Connections and progression

    • Prefix distributions reappear in sequence distillation and policy gradients. Inference processing keeps model weights fixed.

    Continuation · checked fixture D05 — Min-p is a relative probability cutoff

    Checked continuation mechanism and declared fixture; this is not certification of every inherited claim.

    Use the top token probability to scale a cutoff.

    Prerequisites: Stable softmax and log-softmax, Nucleus boundary and actual retained mass

    Notation and assumptions

    Ratio a∈[0,1], threshold a·pmax; include tokens at equality in this fixture.

    Derivation and mechanism

    1. Find pmax.
    2. Retain p_i≥a pmax.
    3. Renormalize retained mass. This is not cumulative top-p.
    S=\{i:p_i\ge a\max_jp_j\}

    Worked example

    [.5,.3,.15,.05] with a=.4 gives threshold.2, retains IDs0,1 and mass.8. a0 keeps every token; a1 keeps all tied maxima under this convention.

    • The paper and selected library may choose different minimum-token safeguards.
    • No single setting proves creative quality or factual accuracy.

    Continuation · checked fixture D06 — Locally typical ranking

    Checked continuation mechanism and declared fixture; this is not certification of every inherited claim.

    Rank tokens by how close their surprise is to the distribution entropy.

    Prerequisites: Entropy, cross-entropy, KL, and support, Nucleus boundary and actual retained mass

    Notation and assumptions

    Surprise=-ln p_i; entropy uses nats. Rank by |surprise-H|, then retain enough mass. This fixture fixes tie and boundary conventions.

    Derivation and mechanism

    1. Compute conditional entropy.
    2. Compute each token surprise and its deviation from entropy.
    3. Sort by deviation, accumulate selected mass and renormalize.

    Worked example

    For [.5,.3,.15,.05], entropy≈1.1421. Surprise of ID1≈1.2040 is closer than ID0≈.6931. Typical mass.5 ranks IDs[1,0] and retains their total.8.

    Limitations

    • Locally typical sampling may omit the most probable token at lower mass.
    • Zero-probability outcomes have infinite surprise and need explicit handling.

    Connections to later concepts

    • F05 entropy provides the center for typical surprise; D03 instead ranks by raw probability.

    Continuation · checked fixture D07 — Sign-aware repetition penalty

    Checked continuation mechanism and declared fixture; this is not certification of every inherited claim.

    Lower seen-token scores without accidentally increasing a negative logit.

    Prerequisites: Stable softmax and log-softmax

    Notation and assumptions

    Penalty θ>1 suppresses seen IDs: positive logits divided; negative logits multiplied. Unique-token versus frequency penalties differ.

    Derivation and mechanism

    1. For seen z≥0, use z/θ.
    2. For seen z<0, use θz.
    3. Apply softmax afterwards; all probabilities change through the denominator.

    Worked example

    z=[2,-2,1],seen={0,1},θ2→[1,-4,1]. Literal division gives[1,-1,1], raising the negative logit. The v3 bridge already explains this caveat; this companion now checks it.

    Limitations

    • A penalty can suppress required repeated names or mathematical symbols.
    • θ below1 rewards seen tokens; APIs differ on prompt inclusion.

    Connections to later concepts

    • D10 places the penalty in a processor route. It is an inference heuristic, distinct from changing model weights through RL.

    Checked continuation mechanism and declared fixture; this is not certification of every inherited claim.

    Balance token probability with a penalty for resemblance to previous hidden states.

    Prerequisites: Stable softmax and log-softmax

    Notation and assumptions

    Continuation · checked fixture D09 — Mirostat feedback direction and units

    Checked continuation mechanism and declared fixture; this is not certification of every inherited claim.

    An adaptive decoder uses observed surprise to adjust its sampling threshold.

    Prerequisites: Entropy, cross-entropy, KL, and support

    Notation and assumptions

    Here surprise and target are both in bits; μ is the controller state, η the feedback rate. This checks the feedback step only.

    Derivation and mechanism

    1. Draw using the current adaptive cutoff.
    2. Measure sampled surprise=-log2(probability) under the specified distribution.
    3. Update μ by subtracting η times excess surprise.
    \mu_{new}=\mu-\eta(s_{bits}-\tau_{bits})

    Worked example

    μ8, sampled surprise6bits, target4bits, η.1 gives7.8. Excess surprise reduces the cutoff state. Below-target surprise raises it.

    Limitations

    • Full Mirostat versions differ in how μ controls truncation; only feedback is executed here.
    • Do not mix natural-log entropy with base2 controller values.

    Connections to later concepts

    • F05 establishes entropy units; a Mirostat feedback target in bits requires log2 rather than natural logs.

    Why this belongs after temperature, top-k, and top-p

    A decoder chooses from the model distribution; it does not improve the model weights. The number of plausible next tokens changes with context. A fixed token count, a cumulative probability target, and a threshold relative to the most likely token answer different questions. Keep their definitions separate before combining them.

    Min-p: threshold, retained set, then renormalization

    Let q(v) be the next-token probability after any chosen temperature transformation, and let b be the min-p parameter with 0 < b ≤ 1. Compute the peak, retain every token above its fraction of that peak, and renormalize. This follows slide 17; the conditional distribution below is a derived consequence.

    q_{\max}=\max_v q(v),\quad c=bq_{\max},\quad S=\{v:q(v)\ge c\},\quad q_S(v)=\frac{q(v)\mathbf{1}[v\in S]}{\sum_{u\in S}q(u)}

    The denominator is retained probability mass. It is positive because at least a maximum-probability token survives. At b=1, tied maximum tokens all survive; min-p is not necessarily a unique greedy choice. An implementation must reject an empty vocabulary and invalid probabilities.

    Repetition penalty: watch the sign

    Slide 19 divides an already-seen positive logit by a penalty θ>1. Its “cat” example uses 0.8/1.5=0.5333, reducing the resulting probability from approximately .1558 to .1238. All probabilities are renormalized; unchanged logits can therefore gain probability. Dividing a negative logit by θ makes it less negative and would increase that token’s relative likelihood. A sign-aware penalty instead uses the following derived monotone suppression rule.

    z_i^{\prime}=\begin{cases}z_i/\theta,&i\text{ seen},\ z_i\ge0\\\theta z_i,&i\text{ seen},\ z_i<0\\z_i,&i\text{ unseen}\end{cases}

    For z=-2 and θ=1.5, use -3 rather than -1.333. A penalty operates on token IDs, so a word split into several tokens needs explicit treatment. Legitimate repeated names or formula symbols can be penalized too; this is a heuristic, not a correctness guarantee.

    Why beam search and other strategies solve different problems

    Slide 11 separates sequence probability from human usefulness. Beam search keeps several partial sequences and scores accumulated log probabilities; a high-scoring sequence need not be informative or diverse. Length normalization and task-specific evaluation matter. The slide’s task examples are guidance, not proof that beam search is universally best for code or translation.

    Complete executable companion: decoding_examples.py · Python standard library
    """Small deterministic decoding examples; Python standard library only."""
import math

def softmax(logits, temperature=1.0):
    if not logits or not all(math.isfinite(z) for z in logits):
        raise ValueError('Logits must be a nonempty finite vector.')
    if not math.isfinite(temperature) or temperature <= 0:
        raise ValueError('Use an explicit greedy branch for temperature zero.')
    scaled = [z / temperature for z in logits]
    peak = max(scaled)
    values = [math.exp(z - peak) for z in scaled]
    return [v / sum(values) for v in values]

def renormalize(p, indices):
    total = sum(p[i] for i in indices)
    if not total:
        raise ValueError('The retained set must have positive mass.')
    return [p[i] / total if i in indices else 0.0 for i in range(len(p))]

def validate_probabilities(p):
    if not p or not all(math.isfinite(x) and x >= 0 for x in p):
        raise ValueError('Probabilities must be nonempty, finite, and nonnegative.')
    if not math.isclose(sum(p), 1.0, abs_tol=1e-9):
        raise ValueError('Probabilities must sum to one.')

def min_p(p, base):
    validate_probabilities(p)
    if not 0 < base <= 1:
        raise ValueError('base must be in (0, 1].')
    threshold = base * max(p)
    keep = [i for i, prob in enumerate(p) if prob >= threshold]
    return threshold, keep, renormalize(p, keep)

def top_p(p, target):
    validate_probabilities(p)
    if not 0 < target <= 1:
        raise ValueError('target must be in (0, 1].')
    keep, total = [], 0.0
    for i in sorted(range(len(p)), key=lambda i: (-p[i], i)):
        keep.append(i)
        total += p[i]
        if total >= target:
            break
    return keep, renormalize(p, keep)

def repetition_penalty(logits, seen, penalty):
    if penalty <= 0:
        raise ValueError('penalty must be positive.')
    return [(z / penalty if z >= 0 else z * penalty) if i in seen else z
            for i, z in enumerate(logits)]

def main():
    # Toy distributions, chosen to make every retained token inspectable.
    peaked = [0.80, 0.07, 0.05, 0.04, 0.03, 0.01]
    flat = [0.22, 0.20, 0.18, 0.16, 0.14, 0.10]
    assert min_p(peaked, 0.1)[1] == [0]
    assert len(min_p(flat, 0.1)[1]) == 6
    assert len(top_p(peaked, 0.9)[0]) == 3
    assert len(top_p(flat, 0.9)[0]) == 5
    tied = [0.5, 0.5]
    assert min_p(tied, 1.0)[1] == [0, 1]
    logits = [1.2, 0.8, 2.0, 0.3]
    before, after = softmax(logits), softmax(repetition_penalty(logits, {1}, 1.5))
    assert after[1] < before[1]
    assert repetition_penalty([-2.0, 1.0], {0}, 1.5)[0] == -3.0
    p = [0.7, 0.2, 0.1]
    entropy = -sum(x * math.log(x) for x in p)
    typical_order = sorted(range(len(p)), key=lambda i: abs(-math.log(p[i]) - entropy))
    print('min-p peaked:', min_p(peaked, 0.1))
    print('min-p flat:', min_p(flat, 0.1))
    print('cat probability:', round(before[1], 4), '->', round(after[1], 4))
    print('Typicality order:', typical_order, 'entropy:', round(entropy, 4))

if __name__ == '__main__':
    main()
